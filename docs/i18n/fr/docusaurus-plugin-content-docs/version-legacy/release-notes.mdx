## Gestion des versions {/* #versioning_scheme */}

Tous nos paquets suivent le [versionnage sémantique](<https://semver.org>). Une version majeure est publiée lorsqu’une fonctionnalité rompt la compatibilité avec les versions antérieures ou lorsque la prise en charge de [versions obsolètes](<https://laravel.com/docs/releases>) de Laravel ou de ses paquets officiels prend fin. Les versions mineures et les correctifs ne doivent jamais introduire de changement incompatible.

## Politique de prise en charge {/* #support_policy */}

Tous les projets Lang suivent la [politique de prise en charge de Laravel](<https://laravel.com/docs/releases#support-policy>).

Comme les paquets des projets `Lang` ne sont pas censés contenir de code affectant la sécurité du projet, nous nous appuyons sur les [dates de fin de maintenance prévues](<https://laravel.com/docs/releases#support-policy>) des projets Laravel et sur les versions mineures de [PHP](<https://www.php.net>).

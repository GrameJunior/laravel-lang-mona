---
title: "Réinitialiser les langues"
slug: /usage-reset-locales.html
description: "Réinitialisez les langues d’une application Laravel."
---

Pour rétablir l’état initial des fichiers, exécutez la commande suivante.

```bash
php artisan lang:reset
```

Cette commande retire des fichiers de destination toutes les clés qui ne sont définies ni par les paquets <strong>Laravel Lang</strong>, ni par les [plugins tiers](<./plugins-community.mdx>) installés.

Ce paquet contient les traductions de toutes les clés officielles des projets Laravel suivants.

[Laravel Framework](<https://laravel.com>), [Jetstream](<https://jetstream.laravel.com/>), [Fortify](<https://github.com/laravel/fortify>), [Cashier](<https://laravel.com/docs/billing>), [Breeze](<https://github.com/laravel/breeze>), [Nova, avec Dusk Suite et Log Viewer](<https://nova.laravel.com/>), [Nova](<https://nova.laravel.com/>) (avec [Dusk Suite](<https://github.com/laravel/nova-dusk-suite>) et [Log Viewer](<https://github.com/laravel/nova-log-viewer>)) et [UI](<https://github.com/laravel/ui>).

:::

## Installation {/* #installation */}

:::note

Consultez le [tableau de compatibilité](<#compatibility> "Compatibilité du paquet Lang").

:::

Pour installer le paquet, exécutez la commande suivante.

```bash
composer require --dev laravel-lang/lang:^15.39.1
```

## Utilisation {/* #usage */}

Vous pouvez maintenant [mettre à jour](<./usage-update-locales.mdx> "Mettre à jour les langues d’une application Laravel") les langues existantes avec la commande `lang:update`.

```bash
php artisan lang:update
```

Nous vous recommandons aussi d’ajouter la commande sous `post-update-cmd`, dans le bloc `scripts` du fichier `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Les fichiers de langue sont ainsi actualisés automatiquement après la mise à jour des dépendances, sans avoir à lancer `php artisan lang:update` manuellement.

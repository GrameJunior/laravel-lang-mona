Ce paquet traduit l’interface des kits de démarrage.

Vous pouvez ainsi l’afficher facilement dans la langue de votre application.

:::

## Installation {/* #installation */}

:::note

Consultez le [tableau de compatibilité](<#compatibility> "Compatibilité du paquet Starter Kits").

:::

Pour installer le paquet, exécutez la commande suivante.

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## Utilisation {/* #usage */}

:::note

Pour que les clés de traduction des [kits de démarrage Laravel](<https://laravel.com/starter-kits>) soient publiées correctement, ne modifiez pas le nom de l’application dans la clé \`name\` du fichier \`composer.json\`. Sinon, les traductions des kits ne seront pas installées.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

Vous pouvez maintenant [mettre à jour](<./usage-update-locales.mdx> "Mettre à jour les langues d’une application Laravel") les langues existantes avec la commande `lang:update`.

```bash
php artisan lang:update
```

Nous vous recommandons aussi d’ajouter la commande sous `post-update-cmd`, dans le bloc `scripts` du fichier `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Les fichiers de langue sont ainsi actualisés automatiquement après la mise à jour des dépendances, sans avoir à lancer `php artisan lang:update` manuellement.

## Installation {/* #installation */}

:::note

Consultez le [tableau de compatibilité](<#compatibility> "Compatibilité du paquet Actions").

:::

Pour installer le paquet, exécutez la commande suivante.

```bash
composer require --dev laravel-lang/actions:^1.13.2
```

## Utilisation {/* #usage */}

Vous pouvez maintenant [mettre à jour](<./usage-update-locales.mdx> "Mettre à jour les langues d’une application Laravel") les langues existantes avec la commande `lang:update`.

```bash
php artisan lang:update
```

Nous vous recommandons aussi d’ajouter la commande sous `post-update-cmd`, dans le bloc `scripts` du fichier `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Les fichiers de langue sont ainsi actualisés automatiquement après la mise à jour des dépendances, sans avoir à lancer `php artisan lang:update` manuellement.

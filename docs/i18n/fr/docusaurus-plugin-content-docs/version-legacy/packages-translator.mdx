## Installation {/* #installation */}

:::note

Consultez le [tableau de compatibilité](<#compatibility> "Compatibilité du paquet Translator").

:::

Pour installer le paquet, exécutez la commande suivante.

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Vous pouvez aussi [modifier](<./configuration.mdx#translator>) les paramètres par défaut dans le fichier `config/localization.php`.

## Utilisation {/* #usage */}

:::tip

Si nécessaire, renseignez les identifiants des fournisseurs dans le fichier `config/localization.php`. Les services payants en ont besoin pour fonctionner correctement.

:::

### Traduction par fournisseurs successifs {/* #cyclical_translation */}

Les API de traduction ne couvrent pas toutes les langues nécessaires. Le paquet peut donc chercher un service capable de traduire le texte en un seul appel.

Prenons la configuration suivante.

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

Dans la configuration, Google Translate et DeepL Translate sont actifs et Yandex.Translate est désactivé. Le paramètre `enabled` ne s’applique qu’à la traduction par fournisseurs successifs.

Supposons que Google Translate puisse traduire uniquement en français et DeepL Translate uniquement en allemand. Trois cas se présentent.

<Tabs>

<TabItem value="tab-1" label={"Vers le français"}>

<span id={"procedure-tif"} />

1. Vérifiez si Google Translate prend en charge la langue demandée. C’est le cas.

Le paquet renvoie la traduction de Google Translate.

</TabItem>

<TabItem value="tab-2" label={"Vers l’allemand"}>

<span id={"procedure-tig"} />

1. Vérifiez si Google Translate prend en charge la langue demandée. Ce n’est pas le cas, passez au traducteur suivant.
1. Vérifiez si DeepL Translate prend en charge la langue demandée. C’est le cas.

Le paquet renvoie la traduction de DeepL Translate.

</TabItem>

<TabItem value="tab-3" label={"Vers une langue non prise en charge"}>

<span id={"procedure-tiu"} />

1. Vérifiez si Google Translate prend en charge la langue demandée. Ce n’est pas le cas, passez au traducteur suivant.
1. Vérifiez si DeepL Translate prend en charge la langue demandée. Ce n’est pas le cas, passez au traducteur suivant.

Le paquet renvoie le texte source sans traduction.

</TabItem>

</Tabs>

#### Utiliser la façade {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Utiliser l’injection de dépendances {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Traduction directe {/* #direct_translate */}

#### Avec Google Translate {/* #via_google */}

:::note

Lorsque vous traduisez directement du texte avec [Google Translate](<https://translate.google.com>), le paramètre `enabled` est ignoré.

:::

Pour lancer une traduction directe, utilisez la façade `LaravelLang\Translator\Facades\Translate` ou injectez la classe de service `LaravelLang\Translator\Services\Translate`.

<Tabs>

<TabItem value="tab-1" label={"Avec la façade"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// returns string

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// returns array

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// returns array

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// returns array
```

</TabItem>

<TabItem value="tab-2" label={"Injection du service Translator"}>

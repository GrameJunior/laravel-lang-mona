## Installation {/* #installation */}

:::note

Consultez le [tableau de compatibilité](<#compatibility> "Compatibilité du paquet JSON Fallback").

:::

Par défaut, Laravel <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">ne prend pas en charge</a> les traductions de repli pour les clés JSON. Par exemple, `__('Remember Me')` renvoie `Remember Me` plutôt que `Se souvenir de moi` si le français est la langue de repli.

Pour installer le paquet, exécutez la commande suivante.

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Utilisation {/* #usage */}

:::note

Laravel 11 ne définit pas de section `providers` dans le fichier de configuration `config/app.php`. Vous pouvez l’ajouter à la main.

:::

Après l’installation, ajoutez le fournisseur de services à la section `providers` du fichier de configuration `config/app.php`.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // other service providers
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Les clés JSON renvoient désormais leur valeur dans la langue sélectionnée.

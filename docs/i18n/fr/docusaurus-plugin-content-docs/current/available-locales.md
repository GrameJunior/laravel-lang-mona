---
title: "Langues disponibles"
description: "Retrouvez les codes de langue canoniques pris en charge par Laravel-Lang Mona."
---

Utilisez les codes ci-dessous avec [Artisan](./translations.md) et dans les paramètres de langue de Laravel. Par exemple, exécutez `php artisan lang:add pt_BR` pour installer le portugais du Brésil. La commande peut accepter un [alias configuré](./configure.md#locale-aliases) en entrée et utilise le code canonique dans les fichiers générés.

Pour retrouver la liste dans le code, utilisez [`Locale::values()`](./locales.md#find-supported-and-installed-locales). La couverture des traductions varie selon le pack et la langue.

## Kurulum {/* #installation */}

:::note

Uyumluluk tablosunu [burada](<#compatibility> "JSON Fallback paketi için uyumluluk tablosu") görebilirsiniz.

:::

Laravel, varsayılan olarak JSON anahtarlarında yedek dil çevirilerine <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">izin vermez</a>. Örneğin yedek dil Fransızca olduğunda `__('Remember Me')` çağrısı `Se souvenir de moi` yerine `Remember Me` döndürür.

Kurmak için aşağıdaki konsol komutunu çalıştırın.

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Kullanım {/* #usage */}

:::note

Laravel 11’de `config/app.php` yapılandırma dosyasında `providers` bölümü bulunmaz. Bu bölümü elle ekleyebilirsiniz.

:::

Kurulumdan sonra `config/app.php` ayar dosyasındaki `providers` bölümüne servis sağlayıcısına bir başvuru eklemeniz gerekir.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // Diğer servis sağlayıcılar
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

JSON anahtarları artık seçilen yerel ayara göre doğru değeri döndürür.

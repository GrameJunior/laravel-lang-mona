## Kurulum {/* #installation */}

Paketi aşağıdaki konsol komutuyla kurun.

```bash
composer require laravel-lang/common:^6.9
```

## Yerel ayarları yönetme {/* #managing_locales */}

### Yerel ayar ekleme {/* #add_locales */}

:::note

Desteklenen yerel ayarların listesini [<strong>burada</strong>](<./available-locales-list.mdx>) bulabilirsiniz.

:::

Artık `lang:add` konsol komutuyla yeni yerel ayarlar [ekleyebilirsiniz](<./usage-add-locales.mdx> "Laravel uygulamasına yerel ayar ekleme").

```bash
php artisan lang:add <locale>
```

### Yerel ayarları güncelleme {/* #update_locales */}

Artık mevcut yerel ayarları `lang:update` konsol komutuyla [güncelleyebilirsiniz](<./usage-update-locales.mdx> "Laravel uygulamasındaki yerel ayarları güncelleme").

```bash
php artisan lang:update
```

Çağrıyı `composer.json` dosyasındaki `scripts` bloğunun `post-update-cmd` bölümüne eklemenizi de öneririz.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Böylece yerelleştirme dosyaları, `php artisan lang:update` konsol komutunu elle çalıştırmanız gerekmeden bağımlılık güncellemelerinden sonra otomatik olarak güncellenir.

## Rotalar {/* #routes */}

### Yerelleştirilmiş rota grubuyla {/* #via_localization_group */}

:::note

`localizedRoute` yardımcı işlevi, rotalar <abbr title={"Kullanılabilir metotlar \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" ve \"LocalizationRoute::group\"."}>gruplanmadan</abbr> çağrılırsa yerel ayar bir sorgu parametresi olarak belirtilir. Aşağıdaki örneğe bakın.

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Parametre adını, ad önekini ve yönlendirme seçeneğini `config/localization.php` dosyasının `routes` bölümünde değiştirebilirsiniz.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Bu metot, yerelleştirilmiş rotaların grup öneklerini kolayca yönetmenizi sağlar.

Bu grubun ana ara katmanı `LocalizationByParameterPrefix` ile birlikte `LocalizationByCookie`, `LocalizationByHeader` ve `LocalizationBySession` da devreye girer.

Aşağıdaki üç yöntemden birini kullanabilirsiniz.

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

Uygulama `{locale}` önekiyle ve öneksiz olmak üzere iki tür rota kaydeder. Aşağıdaki örneğe bakın.

| URL | Desen | Ad |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Ad öneki `config/localization.php` dosyasının `routes` bölümünde değiştirilebilir.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

Bu özelliği, [Laravel Idea](<https://laravel-idea.com/>) adlı [PhpStorm](<https://www.jetbrains.com/phpstorm/>) eklentisi destekler.

<img src={require("@site/static/images/packages-route-idea-friendly.png").default} alt={"Laravel Idea’da yerelleştirilmiş rota desteği"} />

:::

## Modeller {/* #models */}

### Çeviri alma {/* #get_translation */}

:::tip

Tüm depolar, [önceden yükleme](<https://laravel.com/docs/eloquent-relationships#eager-loading>) bayrağını üst modele otomatik olarak aktarır. Bu işlemi elle yapmanız gerekmez.

İlişki varsayılan olarak yalnızca temel yerel ayarların (geçerli ve yedek) kayıtlarını içerir. Bazı durumlarda [filtre ayarlarını](<./configuration.mdx#models>) değiştirerek tüm kayıtları yükleyebilirsiniz.

```php
// config/localization.php
config(['localization.models.filter.enabled' => false]);
```

```ini
; .env
LOCALIZATION_FILTER_ENABLED=false
```

Bu durumda öğeler için mevcut tüm yerel ayarlar yüklenir.

:::

Geçerli yerel ayardaki bir özelliğin değerini almak için model özelliğine erişin. Aşağıdaki örneğe bakın.

```php
use App\Models\Article;

$page = Article::first();

$page->title;
```

<abbr title={"\"config/app.php\" dosyasının \"app.locale\" parametresinde belirlenen değer."}>Ana yerel ayarın</abbr> değeri yoksa metot, <abbr title={"\"config/app.php\" dosyasının \"app.fallback_locale\" parametresinde belirlenen değer."}>yedek yerel ayarın</abbr> değerini döndürür.

`getTranslation` metodunu da kullanabilirsiniz.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title');
```

Belirli bir yerel ayardaki değeri almak için yerel ayar kodunu ikinci argüman olarak verin. Aşağıdaki örneğe bakın.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title', 'fr');
// or
$page->getTranslation('title', Locale::French);
```

:::tip

Model veritabanına yazılmamış değişiklikler içerse bile bu metotlar güncel değeri döndürür.

:::

### Çeviri atama {/* #set_translations */}

#### Tek değer {/* #single_value */}

Uygulamanın geçerli yerel ayarına bir çeviri eklemek veya çeviriyi güncellemek için model özelliğine değer atayın. Aşağıdaki örneğe bakın.

```php
use App\Models\Article;

$page = Article::first();

$page->title = 'New value';
```

`setTranslation` metoduyla da yeni değer atayabilirsiniz.

```php
use App\Models\Article;

$page = Article::first();

$page->setTranslation('title', 'New value');
```

Bu yöntemler yeni değeri etkin yerel ayara atar. Değeri belirli bir yerel ayara atamak için kodunu metodun üçüncü parametresi olarak verin. Aşağıdaki örneğe bakın.

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->setTranslation('title', 'New value', 'fr');
// or
$page->setTranslation('title', 'New value', Locale::French);
```

Toplu atama da yapabilirsiniz.

```php
use App\Models\Article;

$page = Article::first();

$page->fill([
    'title' => 'New value',
]);
```

:::note

Bu metotları çağırdığınızda yeni değerler model nesnelerinde saklanır. Değişiklikleri veritabanına yazmak için üst modelde `save` metodunu çağırın. Aşağıdaki örneğe bakın.

```php
$page->save();
```

:::

Modeli oluştururken de değer atayabilirsiniz. Aşağıdaki örneğe bakın.

```php
use App\Models\Article;

$page = Article::first();

Article::create([
    'title' => 'New value',
]);
```

#### Birden çok değer {/* #plural_value */}

Bir özelliğe birkaç yerel ayarın çevirilerini hızlıca atamak için aşağıdaki yöntemlerden birini kullanabilirsiniz.

```php
use App\Models\Article;
use Illuminate\Database\Eloquent\Model;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Models\HasTranslations;

/** @var Model|HasTranslations $post */
$post = Article::first();

$titles = [
    'fr' => 'Mettre à jour & continuer à éditer',
    'en' => 'Update & Continue Editing',
    'de' => 'Aktualisieren & Weiterbearbeiten',
];

$descriptions = collect([
    Locale::French->value => 'Met à jour les informations et continue d\'éditer le message',
    Locale::German->value => 'Aktualisiert die Informationen und bearbeitet den Beitrag weiter',
]);

    // 1. seçenek
foreach ($titles as $locale => $value) {
    $post->setTranslation('title', $value, $locale);
}

foreach ($descriptions as $locale => $value) {
    $post->setTranslation('description', $value, $locale);
}

    // 2. seçenek
$post->setTranslations('title', $titles);
$post->setTranslations('description', $descriptions);
```

Toplu atamada `iterable` nesneler de kullanabilirsiniz. Aşağıdaki örneğe bakın.

```php
$post->fill([
    'title'       => $titles,
    'description' => $descriptions,
]);

Article::create([
    'title'       => $titles,
    'description' => $descriptions,
]);
```

Her alan için aynı yerel ayarları belirtmeniz gerekmez. Örneğin yukarıdaki kod `title` alanına Fransızca, İngilizce ve Almanca değerler, `description` alanına ise yalnızca Fransızca ve Almanca değerler atar.

## JSON çevirilerinde yedek dil {/* #json_fallback */}

:::note

Laravel 11’de `config/app.php` yapılandırma dosyasında `providers` bölümü bulunmaz. Bu bölümü elle ekleyebilirsiniz.

:::

Kurulumdan sonra `config/app.php` ayar dosyasındaki `providers` bölümüne servis sağlayıcısına bir başvuru eklemeniz gerekir.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // Diğer servis sağlayıcılar
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

JSON anahtarları artık seçilen yerel ayara göre doğru değeri döndürür.

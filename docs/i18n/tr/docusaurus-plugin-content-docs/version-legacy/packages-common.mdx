## Kurulum {/* #installation */}

:::note

Uygulamanın yerelleştirilmesi için gerekli tüm bağımlılıkları çok hızlı güncellemeye olanak tanıdığı için bu paketi kullanmanız önerilir.

Uyumluluk tablosunu [burada](<#compatibility> "Common paketi için uyumluluk tablosu") görebilirsiniz.

:::

Paketi [Composer](<https://getcomposer.org>) ile kurabilirsiniz.

```bash
composer require laravel-lang/common:^6.9
```

:::warning

Laravel 10 kullanıyorsanız kurulacak `laravel-lang/lang` paketinin sürümünü elle belirtmeniz gerekir.

```bash
composer require --dev laravel-lang/lang:^15.39.1:^14.0
```

:::

## Kullanım {/* #usage */}

Artık mevcut yerel ayarları `lang:update` konsol komutuyla [güncelleyebilirsiniz](<./usage-update-locales.mdx> "Laravel uygulamasındaki yerel ayarları güncelleme").

```bash
php artisan lang:update
```

Çağrıyı `composer.json` dosyasındaki `scripts` bloğunun `post-update-cmd` bölümüne eklemenizi de öneririz.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Böylece yerelleştirme dosyaları, `php artisan lang:update` konsol komutunu elle çalıştırmanız gerekmeden bağımlılık güncellemelerinden sonra otomatik olarak güncellenir.

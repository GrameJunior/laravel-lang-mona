## Kurulum {/* #installation */}

:::note

Uyumluluk tablosunu [burada](<#compatibility> "Locales paketi için uyumluluk tablosu") görebilirsiniz.

:::

Kurmak için aşağıdaki konsol komutunu çalıştırın.

```bash
composer require laravel-lang/locales:^2.11.0
```

## Kullanım {/* #usage */}

Yerel ayarlarla çalışmak için `LaravelLang\Locales\Facades\Locales` facade’ını kullanabilirsiniz. Bilgileri yerel ayar kodlarının listesi veya DTO nesnelerinin dizisi olarak alabilirsiniz.

### Veri nesneleri {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// Desteklenen yerel ayarlar.
Locales::available(): array // array<LocaleData>

// Kurulu yerel ayarlar.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// Kurulu olmayan yerel ayarlar.
Locales::notInstalled(): array // array<LocaleData>

// Korunan yerel ayarların listesi.
Locales::protects(): array // array<LocaleData>

// İstenen yerel ayar için dil paketi bulunup bulunmadığını kontrol eder.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// Dil paketinin kurulu olup olmadığını kontrol eder.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// Yerel ayarın korunup korunmadığını kontrol eder.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// Yerel ayarı doğrular ve uygun yerel ayarı döndürür.
// İstenen yerel ayar kurulu değilse uygulamada etkin olanı döndürür.
Locales::get(mixed $locale): LocaleData

// Varsayılan yerel ayarın adını alır.
Locales::getDefault(): LocaleData

// Yedek yerel ayarın adını alır.
Locales::getFallback(): LocaleData

// Desteklenen bir yerel ayarın bilgilerini, yoksa uygulamada etkin olanı döndürür.
Locales::info(mixed $locale): LocaleData
```

---
title: "Yerel ayarları sıfırlama"
slug: /usage-reset-locales.html
description: "Laravel uygulamasındaki yerel ayarları sıfırlama"
---

Dosyaları varsayılan durumuna döndürmek için aşağıdaki konsol komutunu kullanın.

```bash
php artisan lang:reset
```

Bunun sonucunda, <strong>Laravel Lang</strong> paketlerinin veya kurulu [üçüncü taraf eklentilerinin](<./plugins-community.mdx>) tanımlamadığı anahtarlar tüm hedef dosyalardan kaldırılır.

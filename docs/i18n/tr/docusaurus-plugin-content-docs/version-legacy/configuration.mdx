## Yapılandırmayı yayımlama {/* #publish */}

İsteğe bağlı olarak aşağıdaki komutla yapılandırma dosyasını yayımlayabilirsiniz.

```bash
php artisan vendor:publish --tag="localization"
```

Yayımlanan `config/localization.php` dosyasının içeriği aşağıdadır.

## Satır içi çeviriler {/* #inline */}

`inline` seçeneği, dil dosyaları güncellenirken hangi dosya türünün kullanılacağını belirler.

- `true`, satır içi dosyaları kullanır.
- `false`, varsayılan dosyaları kullanır.

Aralarındaki farkı aşağıdaki örnekte görebilirsiniz.

```text
The :attribute must be accepted. // default
This field must be accepted. // inline
```

Bu seçenek `config/localization.php` dosyasında bulunur.

```php
return [
    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),
];
```

## Hizalama {/* #alignment */}

`align` seçeneği, yerelleştirme dosyaları işlenirken değerlerin birbirine göre hizalanmasını belirler.

Dosyalar güncellenirken çıktı dosyalarındaki tüm yorumlar otomatik olarak silinir. [var\_export](<https://www.php.net/manual/en/function.var-export.php>) yorumları işleyemez.

Dosyanızın örnek içeriği aşağıdadır.

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Kimlik doğrulama dil satırları
    |--------------------------------------------------------------------------
    |
    | Aşağıdaki dil satırları, kimlik doğrulama sırasında kullanıcıya
    | gösterilen çeşitli mesajlarda kullanılır. Bu satırları uygulamanızın
    | gereksinimlerine göre değiştirebilirsiniz.
    |
    */
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

Güncellenen dosyanın içeriği aşağıdadır.

```php
declare(strict_types=1);

return [
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

`validation.php` dosyasının örnek içeriği aşağıdadır.

<details>
<summary>İçeriği göster</summary>

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Doğrulama dil satırları
    |--------------------------------------------------------------------------
    |
    | Aşağıdaki dil satırları, doğrulayıcı sınıfının kullandığı varsayılan
    | hata mesajlarını içerir. Boyut kuralları gibi bazı kuralların birden
    | çok sürümü vardır. Bu mesajları burada değiştirebilirsiniz.
    |
    */
    'accepted'   => 'The :attribute must be accepted.',
    'active_url' => 'The :attribute is not a valid URL.',

    // Çok sayıda kural

    'uuid' => 'The :attribute must be a valid UUID.',
    /*
    |--------------------------------------------------------------------------
    | Özel doğrulama dil satırları
    |--------------------------------------------------------------------------
    |
    | Burada, satır adlarında "attribute.rule" biçimini kullanarak
    | özniteliklere özel doğrulama mesajları belirleyebilirsiniz. Bu biçim,
    | belirli bir öznitelik kuralı için özel bir dil satırı tanımlamayı kolaylaştırır.
    |
    */
    'custom' => [
        'name' => [
            'required' => 'Custom message 1',
            'string'   => 'Custom message 2',
        ],
    ],
    /*
    |--------------------------------------------------------------------------
    | Özel doğrulama öznitelikleri
    |--------------------------------------------------------------------------
    |
    | Aşağıdaki dil satırları, öznitelik yer tutucusunu okuyucuya daha
    | anlaşılır bir adla değiştirir. Örneğin "email" yerine "E-Mail Address"
    | kullanılabilir. Bu, mesajı daha anlaşılır kılar.
    |
    */
    'attributes' => [
        'name' => 'Foo',
        'bar'  => 'Bar',
        'baz'  => 'Baz',
    ],
];
```

</details>

Güncellemeden sonraki görünüm aşağıdadır.

```php

return [

        'bar'  => 'Bar',
```

```php

```

## Takma adlar {/* #aliases */}

Kodları `de` yerine `de-DE` veya `de_CH` yerine `de-CH` gibi farklı biçimde adlandırmak istiyorsanız [yapılandırma dosyasında](<./configuration.mdx#aliases>) `aliases` tanımlayabilirsiniz.

Bundan sonra ekleme, güncelleme ve silme işlemlerinin tümü, `config/localization.php` yapılandırma dosyasında belirtilen takma adları otomatik olarak kullanır.

```php
declare(strict_types=1);

use LaravelLang\LocaleList\Locale;

return [
    'aliases' => [
        Locale::German->value            => 'de-DE',
        Locale::GermanAustria->value     => 'de-AT',
        Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

`config/localization.php` dosyası zaten varsa dosyaya `aliases` anahtarını ekleyebilir ve istediğiniz takma adları bir veri dizisiyle belirtebilirsiniz.

Bundan sonra yeni yerel ayar eklerken standart kodu veya takma adını kullanabilirsiniz. Aşağıdaki örneğe bakın.

```bash
php artisan lang:add de de_CH
```

Kurulu yerel ayarlar, PHP çevirilerinde dizin adı ve JSON çevirilerinde dosya adı olarak belirtilen takma adları kullanır.

```text
lang
de-CH
de-DE
```

Bu seçenek `config/localization.php` dosyasında bulunur.

```php
return [
    'aliases' => [
        // \LaravelLang\LocaleList\Locale::German->value => 'de-DE',
        // \LaravelLang\LocaleList\Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

## Akıllı noktalama {/* #smart_punctuation */}

Aşağıdaki örneğe bakın.

```json
{
    "Some": "\"It's super-configurable... you can even use additional extensions to expand its capabilities -- just like this one!\""
}
```

Oluşan dosyalar aşağıdadır.

```json
{
    "Some": "“It’s super-configurable… you can even use additional extensions to expand its capabilities – just like this one!”"
}
```

## Rotalar {/* #routes */}

Paketi [yönlendirme](<./packages-routes.mdx> "Rotaları kolayca ve hızlıca yerelleştirme") için kullanırken anahtar adlarının varsayılan değerlerini değiştirebilirsiniz.

Bu seçenek `config/localization.php` dosyasında etkinleştirilir.

```php
use LaravelLang\Config\Constants\RouteName;

return [
    'routes' => [
        'names' => [
            'parameter' => RouteName::Parameter,
            'header'    => RouteName::Header,
            'cookie'    => RouteName::Cookie,
            'session'   => RouteName::Session,
            'column'    => RouteName::Column,
        ],

        'name_prefix' => env('LOCALIZATION_NAME_PREFIX', 'localized.'),
        'redirect_default' => (bool) env('LOCALIZATION_REDIRECT_DEFAULT', false),
        'hide_default' => (bool) env('LOCALIZATION_HIDE_DEFAULT', false),

        'group' => [
            'middlewares' => [
                'default' => [
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
                'prefix' => [
                    LaravelLang\Routes\Middlewares\LocalizationByParameterPrefix::class,
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,

        ],
    ],
];
```

## Modeller {/* #models */}

[Models](<./packages-models.mdx> "Modelleri kolayca ve hızlıca yerelleştirme") paketini kullanırken varsayılan parametre değerlerini tanımlayabilirsiniz.

Bu ayar `config/localization.php` dosyasında bulunur.

```php
return [
    'models' => [
        'suffix' => 'Translation',
        'filter' => [
            'enabled' => (bool) env('LOCALIZATION_FILTER_ENABLED', true),
        ],
        'helpers' => env('VENDOR_PATH', base_path('vendor/_laravel_lang')),
    ],
];
```

`suffix` parametresi, çeviri deposunun ait olduğu modellerin adındaki son eki belirtir.

Aşağıdaki örneğe bakın.

```text
App\Models\Post::class
App\Models\PostTranslation::class
```

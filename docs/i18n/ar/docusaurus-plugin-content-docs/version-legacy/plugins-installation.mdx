:::note

يمكنك أيضًا استعراض قائمة الإضافات [الرسمية](<./plugins-official.mdx>) وإضافات [المجتمع](<./plugins-community.mdx>) المتاحة.

:::

لاستخدام مدير الإضافات، اتبع الخطوتين الآتيتين:

1. ثبّت الحزمة في تطبيقك. استخدم مثلًا `composer require --dev laravel-lang/lang:^15.39.1` أو ثبّت حزمة أخرى.
1. هذا كل شيء 😊

عند تشغيل الأمر `php artisan lang:update`، يتحقّق المدير من الحزم المحدّدة ويحدّث ملفات تطبيقك تلقائيًا.

إذا وُجدت ملفات بالاسم نفسه في حزم مختلفة، مثل `custom.php`، فستُعالج جميع مفاتيح هذه الملفات.

:::tip

لتسهيل التطوير، استخدم [قالب الترجمات](<https://github.com/Laravel-Lang/translations-template>) الجاهز.

:::

نتمنى لك تجربة ممتعة! 😊

:::note

تجد قائمة رموز الإعدادات المحلية المتاحة [هنا](<./available-locales-list.mdx>).

تضم القائمة 128 رمزًا.

:::

لتثبيت الإعدادات المحلية المطلوبة، استدعِ أمر الطرفية `php artisan lang:add <locale>` ومرّر رمزًا واحدًا أو أكثر تفصل بينها مسافات:

```bash
php artisan lang:add fr de de_AT de_CH vi zh_CN
php artisan lang:add fr
```

إذا كانت الملفات المستهدفة موجودة، يُطلب منك تخطّي التثبيت أو استبدال الملفات.

إذا كانت هذه الملفات تحتوي على مفاتيح أضفتها، فيُستحسن تخطّيها، إذ يمكن لأمر `php artisan lang:update` تحديث الملفات دون حذف شيفرتك.

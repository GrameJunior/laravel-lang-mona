## نشر الإعدادات {/* #publish */}

يمكنك نشر ملف الإعداد اختياريًا بالأمر:

```bash
php artisan vendor:publish --tag="localization"
```

فيما يلي محتوى ملف `config/localization.php` المنشور:

## الرسائل التي لا تذكر اسم الحقل {/* #inline */}

يحدد الخيار `inline` نوع الملفات المستخدمة عند تحديث ملفات اللغة.

- تُستخدم الملفات التي لا تذكر اسم الحقل عند ضبطه على `true`.
- تُستخدم الملفات الافتراضية عند ضبطه على `false`.

يمكنك رؤية الفرق بينها هنا:

```text
The :attribute must be accepted. // default
This field must be accepted. // inline
```

يتوفّر هذا الخيار في ملف `config/localization.php`:

```php
return [
    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),
];
```

## المحاذاة {/* #alignment */}

يحدّد الخيار `align` محاذاة القيم بعضها إلى بعض عند معالجة ملفات التوطين.

عند تحديث الملفات، تُحذف جميع التعليقات من الملفات النهائية تلقائيًا لأن [var\_export](<https://www.php.net/manual/en/function.var-export.php>) لا تتعامل مع التعليقات.

مثال على ملفك:

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Authentication Language Lines
    |--------------------------------------------------------------------------
    |
    | The following language lines are used during authentication for various
    | messages that we need to display to the user. You are free to modify
    | these language lines according to your application's requirements.
    |
    */
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

شكل الملف بعد التحديث:

```php
declare(strict_types=1);

return [
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

ومثال على ملف `validation.php`:

<details>
<summary>عرض المحتوى</summary>

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Validation Language Lines
    |--------------------------------------------------------------------------
    |
    | The following language lines contain the default error messages used by
    | the validator class. Some of these rules have multiple versions such
    | as the size rules. Feel free to tweak each of these messages here.
    |
    */
    'accepted'   => 'The :attribute must be accepted.',
    'active_url' => 'The :attribute is not a valid URL.',

    // قواعد أخرى

    'uuid' => 'The :attribute must be a valid UUID.',
    /*
    |--------------------------------------------------------------------------
    | Custom Validation Language Lines
    |--------------------------------------------------------------------------
    |
    | Here you may specify custom validation messages for attributes using the
    | convention "attribute.rule" to name the lines. This makes it quick to
    | specify a specific custom language line for a given attribute rule.
    |
    */
    'custom' => [
        'name' => [
            'required' => 'Custom message 1',
            'string'   => 'Custom message 2',
        ],
    ],
    /*
    |--------------------------------------------------------------------------
    | Custom Validation Attributes
    |--------------------------------------------------------------------------
    |
    | The following language lines are used to swap our attribute placeholder
    | with something more reader friendly such as "E-Mail Address" instead
    | of "email". This simply helps us make our message more expressive.
    |
    */
    'attributes' => [
        'name' => 'Foo',
        'bar'  => 'Bar',
        'baz'  => 'Baz',
    ],
];
```

</details>

سيبدو الملف بعد التحديث على النحو الآتي:

```php
declare(strict_types=1);

return [
    'accepted'   => 'The :attribute must be accepted.',
    'active_url' => 'The :attribute is not a valid URL.',
    'uuid'       => 'The :attribute must be a valid UUID.',
    'custom'     => [
        'name' => [
            'required' => 'Custom message 1',
            'string'   => 'Custom message 2',
        ],
    ],
    'attributes' => [
        'name' => 'Foo',
        'bar'  => 'Bar',
        'baz'  => 'Baz',
    ],
];
```

يتوفّر هذا الخيار في ملف `config/localization.php`:

```php
return [
    'align' => (bool) env('LOCALIZATION_ALIGN', env('LANG_PUBLISHER_ALIGN', true)),
];
```

## الأسماء البديلة {/* #aliases */}

إذا أردت استخدام تسميات مختلفة للرموز، مثل `de-DE` بدلًا من `de` أو `de-CH` بدلًا من `de_CH`، فعرّف `aliases` في [ملف الإعداد](<./configuration.mdx#aliases>).

بعد ذلك، تستخدم عمليات الإضافة والتحديث والحذف كلها الأسماء البديلة المحدّدة في ملف الإعداد `config/localization.php` تلقائيًا:

```php
declare(strict_types=1);

use LaravelLang\LocaleList\Locale;

return [
    'aliases' => [
        Locale::German->value            => 'de-DE',
        Locale::GermanAustria->value     => 'de-AT',
        Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

إذا كان الملف `config/localization.php` موجودًا، فيمكنك إضافة المفتاح `aliases` إليه وتحديد الأسماء البديلة المطلوبة في مصفوفة.

يمكنك بعد ذلك إضافة إعدادات محلية جديدة بتحديد الرمز الأساسي أو الاسم البديل، مثلًا:

```bash
php artisan lang:add de de_CH
```

تستخدم الإعدادات المحلية المثبّتة الأسماء البديلة المحدّدة أسماءً لمجلدات ترجمات PHP وملفات ترجمات JSON:

```text
lang
de-CH
de-DE
```

يتوفّر هذا الخيار في ملف `config/localization.php`:

```php
return [
    'aliases' => [
        // \LaravelLang\LocaleList\Locale::German->value => 'de-DE',
        // \LaravelLang\LocaleList\Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

```json
{
```

```json
{
    "Some": "“It’s super-configurable… you can even use additional extensions to expand its capabilities – just like this one!”"
```

## المسارات {/* #routes */}

عند استخدام الحزمة للتعامل مع [المسارات](<./packages-routes.mdx> "طريقة سهلة وسريعة لتوطين المسارات")، يمكنك تجاوز الأسماء الافتراضية للمفاتيح.

يُفعّل هذا الخيار في ملف `config/localization.php`:

```php
use LaravelLang\Config\Constants\RouteName;

return [
    'routes' => [
        'names' => [
            'parameter' => RouteName::Parameter,
            'header'    => RouteName::Header,
            'cookie'    => RouteName::Cookie,
            'session'   => RouteName::Session,
            'column'    => RouteName::Column,
        ],

        'name_prefix' => env('LOCALIZATION_NAME_PREFIX', 'localized.'),
        'redirect_default' => (bool) env('LOCALIZATION_REDIRECT_DEFAULT', false),
        'hide_default' => (bool) env('LOCALIZATION_HIDE_DEFAULT', false),

        'group' => [
            'middlewares' => [
                'default' => [
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
                'prefix' => [
                    LaravelLang\Routes\Middlewares\LocalizationByParameterPrefix::class,
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
            ],
        ],
    ],
];
```

## النماذج {/* #models */}

يمكنك تحديد القيم الافتراضية للمعاملات عند استخدام حزمة [Models](<./packages-models.mdx> "طريقة سهلة وسريعة لتوطين النماذج").

يتوفّر هذا الإعداد في ملف `config/localization.php`:

```php
return [
    'models' => [
        'suffix' => 'Translation',
        'filter' => [
            'enabled' => (bool) env('LOCALIZATION_FILTER_ENABLED', true),
        ],
        'helpers' => env('VENDOR_PATH', base_path('vendor/_laravel_lang')),
    ],
];
```

يُستخدم المعامل `suffix` لتحديد لاحقة النماذج التي ينتمي إليها مستودع الترجمة.

مثلًا:

```text
App\Models\Post::class
App\Models\PostTranslation::class
```

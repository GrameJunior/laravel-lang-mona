:::warning

يحذف هذا الأمر مجلد الإعداد المحلي بالكامل بكل ملفاته، باستثناء الإعدادين الافتراضي والاحتياطي.

:::

لحذف إعدادات محلية، استخدم الأمر `php artisan lang:rm <locale>` ومرّر رموزها إليه:

```bash
php artisan lang:rm fr de de_AT de_CH vi zh_CN
```

إذا لم تمرّر وسيطات، يظهر سؤال تفاعلي في الطرفية لاختيار الإعدادات المحلية من بين الإعدادات المتاحة.

```bash
php artisan lang:rm
```

يعرض الأمر افتراضيًا رسالة خطأ عند محاولة إزالة إعداد محلي محمي.

الإعدادات المحلية المحمية هي الرموز المضبوطة في المعاملين `locale` و`fallback_locale` في ملف `config/app.php`.

لفرض حذف إعداد محلي محمي، استخدم الخيار `force`:

```bash
php artisan lang:rm en --force
```

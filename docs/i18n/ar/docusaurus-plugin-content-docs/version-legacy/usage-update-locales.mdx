لتحديث الملفات، شغّل أمر الطرفية:

```bash
php artisan lang:update
```

هذا كل ما عليك فعله 🙂

يكتشف هذا الأمر الإعدادات المحلية المثبّتة في التطبيق ويحدّث ملفاتها.

:::tip

قد تزيل بعض الإصدارات الثانوية من Laravel مفاتيح من مستودعاتها، فتختفي من التطبيق. وهذا نادر جدًا.

يضيف أمر تحديث الإعدادات المحلية عبارات الترجمة الجديدة أو يحدّث العبارات الموجودة فقط. لإزالة العبارات غير المستخدمة، استخدم الأمر [`php artisan lang:reset`](<./usage-reset-locales.mdx> "إعادة ضبط الإعدادات المحلية في تطبيق Laravel").

:::

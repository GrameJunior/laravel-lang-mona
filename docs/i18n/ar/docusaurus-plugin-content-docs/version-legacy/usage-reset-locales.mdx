---
title: "إعادة ضبط الإعدادات المحلية"
slug: /usage-reset-locales.html
description: "إعادة الإعدادات المحلية في تطبيق Laravel إلى حالتها الافتراضية."
---

لإعادة الملفات إلى حالتها الافتراضية، استخدم أمر الطرفية:

```bash
php artisan lang:reset
```

تُحذف من جميع الملفات المستهدفة المفاتيح التي لا تعرّفها حزم <strong>Laravel Lang</strong> أو [إضافات الجهات الخارجية](<./plugins-community.mdx>) المثبّتة.

## التثبيت {/* #installation */}

:::note

اطّلع على [جدول التوافق](<#compatibility> "جدول توافق حزمة Locales").

:::

للتثبيت، شغّل أمر الطرفية:

```bash
composer require laravel-lang/locales:^2.11.0
```

## الاستخدام {/* #usage */}

للتعامل مع الإعدادات المحلية، استخدم الواجهة `LaravelLang\Locales\Facades\Locales`. تتيح الحصول على المعلومات في صورة قائمة برموز الإعدادات المحلية أو مصفوفة من كائنات نقل البيانات (DTO).

### كائنات البيانات {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// يسرد الإعدادات المحلية المتاحة.
Locales::available(): array // array<LocaleData>

// يسرد الإعدادات المحلية المثبّتة.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// يسرد الإعدادات المحلية غير المثبّتة.
Locales::notInstalled(): array // array<LocaleData>

// يجلب قائمة الإعدادات المحلية المحمية.
Locales::protects(): array // array<LocaleData>

// يتحقّق من توفر حزم اللغة للإعداد المحلي المطلوب.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// يتحقّق من تثبيت حزمة لغة.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// يتحقّق من حماية الإعداد المحلي.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// يتحقّق من الإعداد المحلي ويعيد الإعداد الصحيح.
// إذا طُلب إعداد محلي غير مثبّت، يعيد الإعداد النشط حاليًا في التطبيق.
Locales::get(mixed $locale): LocaleData

// يجلب اسم الإعداد المحلي الافتراضي.
Locales::getDefault(): LocaleData

// يجلب اسم الإعداد المحلي الاحتياطي.
Locales::getFallback(): LocaleData

// يجلب معلومات عن أي إعداد محلي متاح. وإلا فيعيد الإعداد النشط حاليًا في التطبيق.
Locales::info(mixed $locale): LocaleData
```

### أمثلة {/* #examples */}

```php
use LaravelLang\LocaleList\Direction;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\CountryData;
use LaravelLang\Locales\Data\CurrencyData;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// config('app.locale') // de

return Locales::getDefault(withCountry: true, withCurrency: true);

// من دون اسم بديل
LocaleData {
  +code: "de"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
  +country: CountryData {
    +code: "DE"
    +native: "Deutschland"
    +localized: "Allemagne"
  }

    +native: "Euro"
    +localized: "euro"
  }

    +name: "LeftToRight"
    +value: "ltr"
  }
  +locale: Locale {
    +name: "German"
    +value: "de"
  }
}
```

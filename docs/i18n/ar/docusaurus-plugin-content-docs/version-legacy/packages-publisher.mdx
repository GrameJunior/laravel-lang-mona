## التثبيت {/* #installation */}

:::note

اطّلع على [جدول التوافق](<#compatibility> "جدول توافق حزمة Publisher").

:::

للتثبيت، شغّل أمر الطرفية:

```bash
composer require --dev laravel-lang/publisher:^16.9.0
```

## الاستخدام {/* #usage */}

يمكنك الآن [تحديث](<./usage-update-locales.mdx> "تحديث الإعدادات المحلية في تطبيق Laravel") الإعدادات المحلية القائمة باستخدام أمر الطرفية `lang:update`:

```bash
php artisan lang:update
```

يُستحسن أيضًا إضافة الاستدعاء إلى قسم `post-update-cmd` ضمن كتلة `scripts` في ملف `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

يتيح ذلك تحديث ملفات التوطين تلقائيًا بعد تحديث التبعيات، دون الحاجة إلى تشغيل أمر `php artisan lang:update` يدويًا.

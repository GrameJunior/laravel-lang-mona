## Publicar {/* #publish */}

Puedes publicar el archivo de configuración con el siguiente comando.

```bash
php artisan vendor:publish --tag="localization"
```

Este es el contenido del archivo `config/localization.php` publicado.

## Traducciones en línea {/* #inline */}

La opción `inline` determina qué tipo de archivos se usan al actualizar los archivos de idiomas.

- Con `true` se usan archivos en línea.
- Con `false` se usan los archivos predeterminados.

Aquí se muestra un ejemplo de la diferencia.

```text
The :attribute must be accepted. // default
This field must be accepted. // inline
```

Esta opción está disponible en `config/localization.php`.

```php
return [
    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),
];
```

## Alineación {/* #alignment */}

La opción `align` define cómo se alinean entre sí los valores al procesar los archivos de traducción.

Al actualizar los archivos, se eliminan automáticamente todos los comentarios de los archivos resultantes. [var\_export](<https://www.php.net/manual/en/function.var-export.php>) no puede conservarlos.

Este es un ejemplo del archivo original.

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Mensajes de autenticación
    |--------------------------------------------------------------------------
    |
    | Estas cadenas contienen mensajes que se muestran al usuario
    | durante la autenticación. Puedes modificarlas según
    | los requisitos de tu aplicación.
    |
    */
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

Así quedaría el archivo actualizado.

```php
declare(strict_types=1);

return [
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

Este es un ejemplo de `validation.php`.

## Alias {/* #aliases */}

Si quieres usar códigos con otro formato, como `de-DE` en lugar de `de` o `de-CH` en lugar de `de_CH`, define `aliases` en el [archivo de configuración](<./configuration.mdx#aliases>).

A partir de entonces, todas las operaciones de instalación, actualización y eliminación usarán automáticamente los alias definidos en `config/localization.php`.

```php
declare(strict_types=1);

use LaravelLang\LocaleList\Locale;

return [
    'aliases' => [
        Locale::German->value            => 'de-DE',
        Locale::GermanAustria->value     => 'de-AT',
        Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

Si el archivo `config/localization.php` ya existe, agrega la clave `aliases` e indica los alias que quieras en un arreglo.

Luego puedes agregar nuevas configuraciones regionales indicando tanto el código principal como su alias.

```bash
php artisan lang:add de de_CH
```

Las configuraciones regionales instaladas usarán los alias especificados como nombres de directorios para las traducciones PHP y como nombres de archivos para las traducciones JSON.

```text
lang
de-CH
de-DE
```

Esta opción está disponible en `config/localization.php`.

```php
return [
    'aliases' => [
        // \LaravelLang\LocaleList\Locale::German->value => 'de-DE',
        // \LaravelLang\LocaleList\Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

## Puntuación tipográfica {/* #smart_punctuation */}

Al actualizar las claves de traducción, también puedes habilitar la conversión de comillas, guiones y puntos suspensivos ASCII a sus equivalentes en Unicode.

Considera el siguiente ejemplo.

```json
{
    "Some": "\"It's super-configurable... you can even use additional extensions to expand its capabilities -- just like this one!\""
}
```

Se generarán los siguientes archivos.

```json
{
    "Some": "“It’s super-configurable… you can even use additional extensions to expand its capabilities – just like this one!”"
}
```

Esta opción está disponible en `config/localization.php`.

## Rutas {/* #routes */}

Si usas el paquete de [rutas](<./packages-routes.mdx> "Localizar rutas de forma rápida y sencilla"), puedes reemplazar los valores predeterminados de los nombres de las claves.

Esta opción se habilita en `config/localization.php`.

```php
use LaravelLang\Config\Constants\RouteName;

return [
    'routes' => [
        'names' => [
            'parameter' => RouteName::Parameter,
            'header'    => RouteName::Header,
            'cookie'    => RouteName::Cookie,
            'session'   => RouteName::Session,
            'column'    => RouteName::Column,
        ],

        'name_prefix' => env('LOCALIZATION_NAME_PREFIX', 'localized.'),
        'redirect_default' => (bool) env('LOCALIZATION_REDIRECT_DEFAULT', false),
        'hide_default' => (bool) env('LOCALIZATION_HIDE_DEFAULT', false),

        'group' => [
            'middlewares' => [
                'default' => [
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
                'prefix' => [
                    LaravelLang\Routes\Middlewares\LocalizationByParameterPrefix::class,
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
            ],
        ],
    ],
];
```

## Modelos {/* #models */}

Puedes definir los valores predeterminados de los parámetros al usar el paquete [Models](<./packages-models.mdx> "Localizar modelos de forma rápida y sencilla").

Este ajuste está disponible en `config/localization.php`.

```php
return [
    'models' => [
        'suffix' => 'Translation',
        'filter' => [
            'enabled' => (bool) env('LOCALIZATION_FILTER_ENABLED', true),
        ],
        'helpers' => env('VENDOR_PATH', base_path('vendor/_laravel_lang')),
    ],
];
```

El parámetro `suffix` indica el sufijo de los modelos a los que pertenece el repositorio de traducciones.

Considera el siguiente ejemplo.

```text
App\Models\Post::class
App\Models\PostTranslation::class
```

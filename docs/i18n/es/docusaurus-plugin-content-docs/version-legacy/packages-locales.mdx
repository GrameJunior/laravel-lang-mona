## Instalación {/* #installation */}

:::note

Consulta la [tabla de compatibilidad](<#compatibility> "Tabla de compatibilidad del paquete Locales").

:::

Para instalarlo, ejecuta el siguiente comando de consola.

```bash
composer require laravel-lang/locales:^2.11.0
```

## Uso {/* #usage */}

Puedes utilizar la fachada `LaravelLang\Locales\Facades\Locales` para trabajar con configuraciones regionales. Permite obtener información como una lista de códigos o como un arreglo de objetos DTO.

### Objetos de datos {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// Lista de configuraciones regionales disponibles.
Locales::available(): array // array<LocaleData>

// Lista de configuraciones regionales instaladas.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// Lista de configuraciones regionales sin instalar.
Locales::notInstalled(): array // array<LocaleData>

// Obtiene una lista de configuraciones regionales protegidas.
Locales::protects(): array // array<LocaleData>

// Comprueba si hay paquetes de idioma disponibles para la configuración regional solicitada.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// Comprueba si hay un paquete de idioma instalado.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// Comprueba si la configuración regional está protegida.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// Valida y devuelve la configuración regional correcta.
// Si la configuración regional solicitada no está instalada, devuelve la activa en la aplicación.
Locales::get(mixed $locale): LocaleData

// Obtiene el nombre de la configuración regional predeterminada.
Locales::getDefault(): LocaleData

// Obtiene el nombre de la configuración regional de reserva.
Locales::getFallback(): LocaleData

// Obtiene información de una configuración regional disponible o, si no lo está, de la activa en la aplicación.
Locales::info(mixed $locale): LocaleData
```

### Ejemplos {/* #examples */}

```php
use LaravelLang\LocaleList\Direction;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\CountryData;
use LaravelLang\Locales\Data\CurrencyData;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// config('app.locale') // de

return Locales::getDefault(withCountry: true, withCurrency: true);

// Sin alias
LocaleData {
  +code: "de"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
  +country: CountryData {
    +code: "DE"
    +native: "Deutschland"
    +localized: "Allemagne"
  }
  +currency: CurrencyData {
    +code: "EUR"
    +numeric: 978
    +native: "Euro"
    +localized: "euro"
  }
  +direction: Direction {
    +name: "LeftToRight"
    +value: "ltr"
  }
  +locale: Locale {
    +name: "German"
    +value: "de"
  }
}

// Con alias

  +code: "de-DE"
```

Este paquete contiene las traducciones de todas las claves oficiales de los proyectos de Laravel.

[Laravel Framework](<https://laravel.com>), [Jetstream](<https://jetstream.laravel.com/>), [Fortify](<https://github.com/laravel/fortify>), [Cashier](<https://laravel.com/docs/billing>), [Breeze](<https://github.com/laravel/breeze>), [Nova (también Dusk Suite y Log Viewer)](<https://nova.laravel.com/>), [Nova](<https://nova.laravel.com/>) (también [Dusk Suite](<https://github.com/laravel/nova-dusk-suite>) y [Log Viewer](<https://github.com/laravel/nova-log-viewer>)) y [UI](<https://github.com/laravel/ui>)

:::

## Instalación {/* #installation */}

:::note

Consulta la [tabla de compatibilidad](<#compatibility> "Tabla de compatibilidad del paquete Lang").

:::

Para instalarlo, ejecuta el siguiente comando de consola.

```bash
composer require --dev laravel-lang/lang:^15.39.1
```

## Uso {/* #usage */}

Ya puedes [actualizar](<./usage-update-locales.mdx> "Actualizar configuraciones regionales en una aplicación de Laravel") las traducciones existentes con el comando de consola `lang:update`.

```bash
php artisan lang:update
```

También se recomienda agregar la llamada a la sección `post-update-cmd` del bloque `scripts` del archivo `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Así, los archivos de traducción se actualizarán automáticamente cuando se actualicen las dependencias, sin tener que ejecutar manualmente `php artisan lang:update`.

---

Para restablecer los archivos a su estado predeterminado, ejecuta el siguiente comando de consola.

```bash
php artisan lang:reset
```

Esto elimina de todos los archivos de destino las claves que no definen los paquetes de <strong>Laravel Lang</strong> ni los [complementos de terceros](<./plugins-community.mdx>) instalados.

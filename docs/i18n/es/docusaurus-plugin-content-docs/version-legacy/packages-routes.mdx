## Instalación {/* #installation */}

:::note

Consulta la [tabla de compatibilidad](<#compatibility> "Tabla de compatibilidad del paquete Routes").

:::

Para instalarlo, ejecuta el siguiente comando de consola.

```bash
composer require laravel-lang/routes:^1.11.0
```

Puedes [cambiar](<./configuration.mdx#routes>) la configuración predeterminada editando `config/localization.php`.

:::note

Compatibilidad completa con la [caché de rutas](<https://laravel.com/docs/routing#route-caching>)

```bash
php artisan route:cache
```

:::

Supongamos que una aplicación tiene instalados el francés y el alemán.

La configuración de la aplicación se vería así.

```php
// config/app.php
use LaravelLang\LocaleList\Locale;

return [
    'locale' => Locale::French->value,

    'fallback_locale' => Locale::German->value,
];
```

También se han definido valores para el francés y el alemán.

```json
{
    "Foo": "Toutes les données ont été chargées."
}
```

```json
{

}
```

### Uso directo {/* #direct */}

Puedes hacer referencia al middleware sin agregar alias.

```php
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('some/{locale}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByParameterWithRedirect::class)
    ->get('some/{locale?}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByHeader::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByCookie::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationBySession::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('some', fn () => view('welcome'));
```

### Alias {/* #aliases */}

Para usar alias de middleware, regístralos en la aplicación.

<Tabs>

<TabItem value="tab-1" label={"Laravel 11"}>

```php
// bootstrap/app.php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Middleware;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'localization.parameter' => LocalizationByParameter::class,
            'localization.redirect'  => LocalizationByParameterWithRedirect::class,
            'localization.header'    => LocalizationByHeader::class,
            'localization.cookie'    => LocalizationByCookie::class,
            'localization.session'   => LocalizationBySession::class,
            'localization.model'     => LocalizationByModel::class,
        ]);
    });
```

</TabItem>

<TabItem value="tab-2" label={"Laravel 10"}>

```php
// app/Http/Kernel.php

use Illuminate\Foundation\Http\Kernel as HttpKernel;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

class Kernel extends HttpKernel
{
    protected $middlewareAliases = [
        // ...

        'localization.parameter' => LocalizationByParameter::class,
        'localization.redirect'  => LocalizationByParameterWithRedirect::class,
        'localization.header'    => LocalizationByHeader::class,
        'localization.cookie'    => LocalizationByCookie::class,
        'localization.session'   => LocalizationBySession::class,
        'localization.model'     => LocalizationByModel::class,
    ];
}
```

</TabItem>

```php

app('router')
    ->middleware('localization.cookie')
    ->get('some', fn () => view('welcome'));

    ->middleware('localization.session')
    ->get('some', fn () => view('welcome'));

    ->middleware('localization.model')
```

### Mediante un parámetro de URL {/* #via_url_parameter */}

:::tip

Primero indica el parámetro `{locale}` en cualquier parte de la URL de tus rutas.

Puedes cambiar el nombre del parámetro en la sección `routes` de `config/localization.php`.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByParameter;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('foo/{locale}/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Si pasas una configuración regional no válida o no instalada, la página se renderiza en la configuración regional principal de la aplicación.

### Mediante un modelo {/* #via_model */}

:::tip

Establece la configuración regional según el valor de la columna <abbr title={"Puedes cambiar este nombre en la sección \"routes\" del archivo \"config/localization.php\"."}>locale</abbr>.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Este método permite establecer la configuración regional de cualquier cliente autenticado. Asegúrate de que el modelo contenga el atributo <abbr title={"Puedes cambiar este nombre en la sección \"routes\" del archivo \"config/localization.php\"."}>"locale"</abbr>.

Si la tabla de usuarios no tiene esta columna, agrégala si hace falta o crea un método dinámico en la clase del modelo.

Considera este ejemplo.

```php
use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Foundation\Auth\User as Authenticatable;
use LaravelLang\LocaleList\Locale;

class User extends Authenticatable
{
    protected function locale(): Attribute
    {
        return Attribute::make(
            get: fn () => Locale::French
        );
    }
}
```

Cuando el usuario se autentique mediante el middleware o manualmente, por ejemplo con `Auth::login($user)`, la aplicación devolverá la información en el idioma que eligió.

Si un guard específico autentica al usuario, añade dos puntos y el nombre del guard al llamar al middleware.

Considera este ejemplo.

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class . ':guard_name')
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

El middleware usa este código para obtener la instancia de usuario.

```php
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;

class LocalizationByModel extends Middleware
{
    public function __construct(
        protected ?string $guard = null,
    ) {}

    protected function user(Request $request): ?Model
    {
        return $request->user($this->guard);
    }
}
```

### Mediante un grupo de localización {/* #via_localization_group */}

:::note

Si llamas a `localizedRoute` sin <abbr title={"Los métodos disponibles son \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" y \"LocalizationRoute::group\"."}>agrupar</abbr> las rutas, la configuración regional se especifica como parámetro de consulta. Considera este ejemplo.

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Puedes cambiar el nombre del parámetro, el prefijo de nombres y la opción de redirección en la sección `routes` del archivo `config/localization.php`.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Este método permite gestionar los prefijos de grupo con rutas localizadas.

Además del middleware principal del grupo, `LocalizationByParameterPrefix`, intervienen `LocalizationByCookie`, `LocalizationByHeader` y `LocalizationBySession`.

Puedes usar cualquiera de estos tres métodos.

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

La aplicación registrará dos tipos de rutas, con el prefijo `{locale}` y sin él. Considera este ejemplo.

| URL | Patrón | Nombre |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Puedes cambiar el prefijo de nombres en la sección `routes` de `config/localization.php`.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

Esta función es compatible con [Laravel Idea](<https://laravel-idea.com/>), un complemento para [PhpStorm](<https://www.jetbrains.com/phpstorm/>).

## Eventos {/* #events */}

:::note

El evento está disponible en `laravel-lang/routes` a partir de la versión `1.1`.

:::

El evento se emite cuando se pasa una configuración regional para establecerla en la aplicación.

```php
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

LocaleHasBeenSetEvent::dispatch($locale);
```

La propiedad `$locale` del evento es de tipo `LaravelLang\Locales\Data\LocaleData`.

Si lo necesitas, puedes escuchar este evento.

```php
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\ServiceProvider;
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Event::listen(static function (LocaleHasBeenSetEvent $event) {
            Log::info('Locale set to: ' . $event->locale->code);
        });
    }
}
```

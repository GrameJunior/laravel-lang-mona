Este paquete contiene las traducciones de la interfaz del [<strong>panel de administración de MoonShine</strong>](<https://getmoonshine.app>).

Así puedes localizar también esa interfaz.

:::

## Instalación {/* #installation */}

:::note

Consulta la [tabla de compatibilidad](<#compatibility> "Tabla de compatibilidad del paquete MoonShine").

:::

Para instalarlo, ejecuta el siguiente comando de consola.

```bash
composer require --dev laravel-lang/moonshine:^1.9.2
```

## Uso {/* #usage */}

Ya puedes [actualizar](<./usage-update-locales.mdx> "Actualizar configuraciones regionales en una aplicación de Laravel") las traducciones existentes con el comando de consola `lang:update`.

```bash
php artisan lang:update
```

También se recomienda agregar la llamada a la sección `post-update-cmd` del bloque `scripts` del archivo `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Así, los archivos de traducción se actualizarán automáticamente cuando se actualicen las dependencias, sin tener que ejecutar manualmente `php artisan lang:update`.

## Instalación {/* #installation */}

:::note

Consulta la [tabla de compatibilidad](<#compatibility> "Tabla de compatibilidad del paquete Models").

:::

Para instalarlo, ejecuta el siguiente comando de consola.

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Puedes [cambiar](<./configuration.mdx#translator>) la configuración predeterminada editando `config/localization.php`.

## Uso {/* #usage */}

:::tip

Si es necesario, indica las credenciales de los proveedores en `config/localization.php`. Los servicios de pago las necesitan para funcionar correctamente.

:::

### Traducción en cadena {/* #cyclical_translation */}

Algunas API no cubren todas las configuraciones regionales necesarias. Por eso es posible que debas buscar un servicio capaz de traducir el texto en una sola llamada.

Considera esta configuración de ejemplo.

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

En la configuración se activaron Google Translate y DeepL Translate y se desactivó Yandex.Translate. El parámetro `enabled` solo se aplica a la traducción en cadena.

Supongamos que Google Translate solo puede traducir al francés y que DeepL Translate solo puede traducir al alemán. Se dan tres casos.

#### Mediante la fachada {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Mediante inyección de dependencias {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Traducción directa {/* #direct_translate */}

#### Mediante Google Translate {/* #via_google */}

:::note

Al traducir texto directamente con [Google Translate](<https://translate.google.com>), se ignora el parámetro `enabled`.

:::

Para traducir directamente, usa la fachada `LaravelLang\Translator\Facades\Translate` o inyecta la clase de servicio `LaravelLang\Translator\Services\Translate` como dependencia.

<Tabs>

<TabItem value="tab-1" label={"Mediante la fachada"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// devuelve una cadena

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// devuelve un arreglo

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// devuelve un arreglo

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// devuelve un arreglo
```

</TabItem>

<TabItem value="tab-2" label={"Inyectar Translator"}>

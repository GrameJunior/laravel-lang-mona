## Instalación {/* #installation */}

:::note

Consulta la [tabla de compatibilidad](<#compatibility> "Tabla de compatibilidad del paquete JSON Fallback").

:::

De forma predeterminada, Laravel <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">no permite</a> traducciones de reserva para claves JSON. Por ejemplo, si llamas a `__('Remember Me')`, obtienes `Remember Me` en lugar de `Se souvenir de moi` cuando el idioma de reserva es el francés.

Para instalarlo, ejecuta el siguiente comando de consola.

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Uso {/* #usage */}

:::note

En Laravel 11, el archivo de configuración `config/app.php` no incluye la sección `providers`. Puedes agregarla manualmente.

:::

Después de instalar el paquete, agrega una referencia al proveedor de servicios en la sección `providers` del archivo de configuración `config/app.php`.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // otros proveedores de servicios
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Ahora las claves JSON devolverán el valor correspondiente a la configuración regional seleccionada.

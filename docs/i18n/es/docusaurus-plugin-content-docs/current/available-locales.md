---
title: Configuraciones regionales disponibles
description: Consulta los códigos canónicos de las configuraciones regionales compatibles con Laravel-Lang Mona.
---

Usa los códigos de la tabla con [Artisan](./translations.md) y en la configuración regional de Laravel. Por ejemplo, ejecuta `php artisan lang:add pt_BR` para instalar portugués de Brasil. Se puede pasar un [alias configurado](./configure.md#locale-aliases), pero los archivos generados usan el código canónico.

Puedes obtener esta lista en el código con [`Locale::values()`](./locales.md#find-supported-and-installed-locales). La cobertura de traducción varía según el paquete y la configuración regional.

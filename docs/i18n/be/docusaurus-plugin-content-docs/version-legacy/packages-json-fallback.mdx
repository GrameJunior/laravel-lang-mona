## Усталяванне {/* #installation */}

:::note

Табліцу сумяшчальнасці можна паглядзець [тут](<#compatibility> "Табліца сумяшчальнасці пакета JSON Fallback").

:::

Па змаўчанні Laravel <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">не падтрымлівае</a> рэзервовых перакладаў для ключоў JSON. Напрыклад, пры выкліку `__('Remember Me')` для рэзервовай французскай мовы вы атрымаеце `Remember Me` замест `Se souvenir de moi`.

Каб усталяваць пакет, выканайце каманду:

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Выкарыстанне {/* #usage */}

:::note

У канфігурацыі Laravel 11 у файле `config/app.php` няма раздзела `providers`. Яго можна дадаць уручную.

:::

Пасля ўсталявання дадайце спасылку на пастаўшчыка сэрвісаў у раздзел `providers` файла налад `config/app.php`:

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // Іншыя пастаўшчыкі сэрвісаў
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Цяпер для ключоў JSON будуць вяртацца значэнні, якія адпавядаюць выбранай лакалі.

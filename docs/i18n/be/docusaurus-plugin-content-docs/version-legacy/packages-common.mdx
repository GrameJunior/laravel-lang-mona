## Усталяванне {/* #installation */}

:::note

Раім выкарыстоўваць гэты пакет, бо ён дазваляе хутка абнаўляць усе залежнасці, патрэбныя для лакалізацыі прыкладання.

Табліцу сумяшчальнасці можна паглядзець [тут](<#compatibility> "Табліца сумяшчальнасці пакета Common").

:::

Пакет можна ўсталяваць праз [Composer](<https://getcomposer.org>):

```bash
composer require laravel-lang/common:^6.9
```

:::warning

Калі вы выкарыстоўваеце Laravel 10, версію пакета `laravel-lang/lang` для ўсталявання трэба пазначыць уручную:

```bash
composer require --dev laravel-lang/lang:^15.39.1:^14.0
```

:::

## Выкарыстанне {/* #usage */}

Цяпер можна [абнавіць](<./usage-update-locales.mdx> "Абнаўленне лакаляў у прыкладанні Laravel") наяўныя лакалі з дапамогай каманды `lang:update`:

```bash
php artisan lang:update
```

Таксама раім дадаць выклік у раздзел `post-update-cmd` блока `scripts` файла `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Так файлы лакалізацыі будуць абнаўляцца аўтаматычна пасля абнаўлення залежнасцей, без ручнога запуску каманды `php artisan lang:update`.

## Схема нумарацыі версій {/* #versioning_scheme */}

Усе нашы пакеты прытрымліваюцца [семантычнага версіявання](<https://semver.org>). Асноўныя выпускі выходзяць пры даданні магчымасцей, якія парушаюць зваротную сумяшчальнасць, або спыненні падтрымкі [састарэлых версій](<https://laravel.com/docs/releases>) Laravel ці іншых яго афіцыйных пакетаў. Малыя выпускі і выпускі з выпраўленнямі ніколі не павінны ўключаць несумяшчальныя змены.

## Палітыка падтрымкі {/* #support_policy */}

Усе праекты Lang прытрымліваюцца [палітыкі падтрымкі Laravel](<https://laravel.com/docs/releases#support-policy>).

Мы не чакаем, што пакеты праекта `Lang` будуць мець код, які ўплывае на бяспеку праекта. Таму арыентуемся на [запланаваныя тэрміны заканчэння падтрымкі](<https://laravel.com/docs/releases#support-policy>) праектаў Laravel і малых версій [PHP](<https://www.php.net>).

:::note

Спіс даступных кодаў лакаляў ёсць [тут](<./available-locales-list.mdx>).

Спіс змяшчае 128 кодаў лакаляў.

:::

Каб усталяваць патрэбныя лакалі, запусціце каманду `php artisan lang:add <locale>` і перадайце адзін ці некалькі кодаў лакаляў праз прабел:

```bash
php artisan lang:add fr de de_AT de_CH vi zh_CN
php artisan lang:add fr
```

Калі мэтавыя файлы існуюць, каманда спытае, ці прапусціць іх усталяванне або замяніць файлы.

Калі гэтыя файлы змяшчаюць дададзеныя вамі ключы, раім іх прапусціць, бо каманда `php artisan lang:update` зможа абнавіць файлы без выдалення вашага кода.

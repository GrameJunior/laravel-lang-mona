## Усталяванне {/* #installation */}

:::note

Табліцу сумяшчальнасці можна паглядзець [тут](<#compatibility> "Табліца сумяшчальнасці пакета Starter Kits").

:::

Каб усталяваць пакет, выканайце каманду:

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## Выкарыстанне {/* #usage */}

:::note

Каб публікацыя ключоў перакладу [стартавых набораў Laravel](<https://laravel.com/starter-kits>) працавала правільна, пакіньце імя прыкладання, зададзенае ў ключы \`name\` файла \`composer.json\`. Калі яго перайменаваць, пераклады стартавых набораў не ўсталююцца.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

Цяпер можна [абнавіць](<./usage-update-locales.mdx> "Абнаўленне лакаляў у прыкладанні Laravel") наяўныя лакалі з дапамогай каманды `lang:update`:

```bash
php artisan lang:update
```

Таксама раім дадаць выклік у раздзел `post-update-cmd` блока `scripts` файла `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Так файлы лакалізацыі будуць абнаўляцца аўтаматычна пасля абнаўлення залежнасцей, без ручнога запуску каманды `php artisan lang:update`.

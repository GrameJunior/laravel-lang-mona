:::note

Таксама можна прагледзець спісы даступных [афіцыйных плагінаў](<./plugins-official.mdx>) і [плагінаў супольнасці](<./plugins-community.mdx>).

:::

Каб пачаць карыстацца Publisher, выканайце два крокі:

1. Усталюйце пакет у сваё прыкладанне. Напрыклад, `composer require --dev laravel-lang/lang:^15.39.1` або іншы пакет.
1. Гэта ўсё 😊

Цяпер пры запуску каманды `php artisan lang:update` Publisher праверыць пазначаныя пакеты і аўтаматычна абновіць файлы ў вашым прыкладанні.

Калі ў розных пакетах ёсць аднайменныя файлы, напрыклад `custom.php`, пры апрацоўцы будуць улічаны ўсе ключы з усіх гэтых файлаў.

:::tip

Для спрашчэння распрацоўкі выкарыстоўвайце гатовы [шаблон перакладаў](<https://github.com/Laravel-Lang/translations-template>).

:::

Прыемнай працы! 😊

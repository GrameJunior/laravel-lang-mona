---

Каб абнавіць файлы, выканайце каманду:

```bash
php artisan lang:update
```

Так, гэта ўсё, што трэба зрабіць 🙂

Каманда знаходзіць лакалі, усталяваныя ў прыкладанні, і абнаўляе файлы.

:::tip

У некаторых малых версіях Laravel ключы могуць знікнуць з яго рэпазіторыяў і, адпаведна, з прыкладання. Гэта здараецца вельмі рэдка.

Каманда абнаўлення лакаляў толькі дадае новыя або абнаўляе наяўныя фразы перакладу. Каб выдаліць нявыкарыстаныя фразы, запусціце каманду [`php artisan lang:reset`](<./usage-reset-locales.mdx> "Скід лакаляў у прыкладанні Laravel").

:::

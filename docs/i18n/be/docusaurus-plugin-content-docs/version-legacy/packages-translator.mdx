## Усталяванне {/* #installation */}

:::note

Табліцу сумяшчальнасці можна паглядзець [тут](<#compatibility> "Табліца сумяшчальнасці пакета Models").

:::

Каб усталяваць пакет, выканайце каманду:

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Каб [змяніць](<./configuration.mdx#translator>) налады па змаўчанні, адрэдагуйце файл `config/localization.php`.

## Выкарыстанне {/* #usage */}

:::tip

Пры патрэбе ўкажыце ў файле налад `config/localization.php` даныя для аўтарызацыі ў сэрвісах. Без іх платныя сэрвісы не будуць працаваць належным чынам.

:::

### Паслядоўны пераклад {/* #cyclical_translation */}

Розныя сэрвісы API падтрымліваюць розны набор лакаляў. Можна знайсці сэрвіс, які здолее перакласці тэкст адным выклікам.

Няхай у нас такія налады:

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

У наладах мы ўключылі Google Translate і DeepL Translate і выключылі Yandex.Translate. Параметр `enabled` дзейнічае толькі для паслядоўнага перакладу.

Дапусцім, Google Translate можа перакладаць толькі на французскую мову, а DeepL Translate — толькі на нямецкую. Тады ёсць тры варыянты:

#### Праз фасад {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Праз укараненне залежнасцей {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Прамы пераклад {/* #direct_translate */}

#### Праз Google Translate {/* #via_google */}

:::note

Пры прамым перакладзе тэксту праз [Google Translate](<https://translate.google.com>) параметр налад `enabled` ігнаруецца.

:::

Для прамога перакладу можна выкарыстаць фасад `LaravelLang\Translator\Facades\Translate` або ўкараніць клас сэрвісу `LaravelLang\Translator\Services\Translate` як залежнасць.

<Tabs>

<TabItem value="tab-1" label={"Праз фасад"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// Вяртае радок

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// Вяртае масіў

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// Вяртае масіў

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// Вяртае масіў
```

</TabItem>

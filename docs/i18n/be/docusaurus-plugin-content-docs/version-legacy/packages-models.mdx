## Усталяванне {/* #installation */}

:::note

Табліцу сумяшчальнасці можна паглядзець [тут](<#compatibility> "Табліца сумяшчальнасці пакета Models").

:::

Каб усталяваць пакет, выканайце каманду:

```bash
composer require laravel-lang/models:^1.8.0
```

Каб [змяніць](<./configuration.mdx#models>) налады па змаўчанні, адрэдагуйце файл `config/localization.php`.

## Кансольныя каманды {/* #console_commands */}

### Стварэнне мадэлі перакладу {/* #create_translation_model */}

Сховішча разлічанае на вялікія аб’ёмы даных, якія захоўваюцца асобна. Для кожнай мадэлі, якой патрэбныя пераклады, ствараецца ўласная мадэль перакладу.

Найпрасцей стварыць сховішча з дапамогай каманды `make:model-translation`:

```bash
php artisan make:model-translation
```

Пры запуску каманда спытае імя зыходнай мадэлі і створыць яе, калі такой яшчэ няма. Пасля яна спытае, якія слупкі стварыць. Напрыклад, "title", "description" і іншыя.

Калі вы дадалі лішнія слупкі або не дадалі ніводнага, патрэбныя змены можна ўнесці ў файл мадэлі і міграцыю, якія згенеруе каманда.

Створаная мадэль сховішча заўсёды павінна быць побач з бацькоўскай мадэллю, і менавіта там яе стварае каманда. Напрыклад:

```text
App\Models\Content\News
App\Models\Content\NewsTranslation
App\Models\Products\Category
App\Models\Products\CategoryTranslation
```

:::tip

Стандартны суфікс — `Translation`. Каб задаць свой, змяніце яго ў раздзеле `models` файла налад [config/localization.php](<./configuration.mdx#models>).

:::

Пасля гэтага запусціце міграцыю камандай:

```bash
php artisan migrate
```

### Наладжванне мадэлі {/* #model_setup */}

Пасля стварэння сховішча перакладаў падключыце трэйт `LaravelLang\Models\HasTranslations` да асноўнай мадэлі.

Напрыклад:

```php
use Illuminate\Database\Eloquent\Model;
use LaravelLang\Models\HasTranslations;

class Article extends Model
{
    use HasTranslations;
}
```

Таксама пераканайцеся, што ў базавай мадэлі няма фізічных і віртуальных палёў, якія выкарыстоўваюцца для перакладаў.

Напрыклад:

```php
use Illuminate\Database\Eloquent\Model;
use LaravelLang\Models\HasTranslations;

class Article extends Model
{
    use HasTranslations;

    protected $fillable = [
        'category_id',

        // Трэба выдаліць:
        'title',
        'description',
    ];
}
```

### Атрыманне перакладу {/* #get_translation */}

:::tip

Усе сховішчы рэпазіторыя аўтаматычна перадаюць бацькоўскай мадэлі сцяг [папярэдняй загрузкі](<https://laravel.com/docs/eloquent-relationships#eager-loading>), таму ўручную гэтага рабіць не трэба.

Па змаўчанні сувязь змяшчае толькі запісы асноўных лакаляў (бягучай і рэзервовай). Пры патрэбе можна загрузіць усе запісы, змяніўшы [налады фільтрацыі](<./configuration.mdx#models>):

```php
// config/localization.php
config(['localization.models.filter.enabled' => false]);
```

```ini
; .env
LOCALIZATION_FILTER_ENABLED=false
```

У гэтым выпадку для элементаў будуць загружаны ўсе даступныя лакалі.

:::

Каб атрымаць значэнне ўласцівасці для бягучай лакалі, звярніцеся да ўласцівасці мадэлі. Напрыклад:

```php
use App\Models\Article;

$page = Article::first();

$page->title;
```

Калі значэнне для <abbr title={"Значэнне параметра \"app.locale\" у файле \"config/app.php\"."}>асноўнай лакалі</abbr> адсутнічае, метад верне значэнне для <abbr title={"Значэнне параметра \"app.fallback_locale\" у файле \"config/app.php\"."}>рэзервовай лакалі</abbr>.

Таксама можна выкарыстоўваць метад `getTranslation`:

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title');
```

Каб атрымаць значэнне для пэўнай лакалі, перадайце яе код як другі аргумент. Напрыклад:

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title', 'fr');
// or
$page->getTranslation('title', Locale::French);
```

:::tip

Гэтыя метады вернуць значэнне нават тады, калі змены ў мадэлі яшчэ не запісаныя ў базу даных.

:::

### Заданне перакладаў {/* #set_translations */}

#### Адно значэнне {/* #single_value */}

Каб дадаць або абнавіць пераклад для бягучай лакалі прыкладання, прысвойце значэнне ўласцівасці мадэлі. Напрыклад:

```php
use App\Models\Article;

$page = Article::first();

$page->title = 'New value';
```

Таксама можна задаць новае значэнне метадам `setTranslation`:

```php
use App\Models\Article;

$page = Article::first();

$page->setTranslation('title', 'New value');
```

Гэтыя метады задаюць новае значэнне для бягучай актыўнай лакалі. Каб задаць значэнне для пэўнай лакалі, перадайце яе код як трэці параметр. Напрыклад:

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->setTranslation('title', 'New value', 'fr');
// or
$page->setTranslation('title', 'New value', Locale::French);
```

Таксама можна запаўняць палі масава:

```php
use App\Models\Article;

$page = Article::first();

$page->fill([
    'title' => 'New value',
]);
```

:::note

Пасля выкліку гэтых метадаў новыя значэнні захоўваюцца ў аб’ектах мадэлі. Каб запісаць змены ў базу даных, выклічце метад `save` для бацькоўскай мадэлі. Напрыклад:

```php
$page->save();
```

:::

Запаўняць палі можна таксама пры стварэнні мадэлі. Напрыклад:

```php
use App\Models\Article;

$page = Article::first();

Article::create([
    'title' => 'New value',
]);
```

#### Некалькі значэнняў {/* #plural_value */}

Калі трэба хутка запоўніць уласцівасць перакладамі для некалькіх лакаляў, выкарыстоўвайце любы з наступных спосабаў:

```php
use App\Models\Article;
use Illuminate\Database\Eloquent\Model;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Models\HasTranslations;

/** @var Model|HasTranslations $post */
$post = Article::first();

$titles = [
    'fr' => 'Mettre à jour & continuer à éditer',
    'en' => 'Update & Continue Editing',
    'de' => 'Aktualisieren & Weiterbearbeiten',
];

$descriptions = collect([
    Locale::French->value => 'Met à jour les informations et continue d\'éditer le message',
    Locale::German->value => 'Aktualisiert die Informationen und bearbeitet den Beitrag weiter',
]);

// Варыянт 1
foreach ($titles as $locale => $value) {
    $post->setTranslation('title', $value, $locale);
}

foreach ($descriptions as $locale => $value) {
    $post->setTranslation('description', $value, $locale);
}

// Варыянт 2
$post->setTranslations('title', $titles);
$post->setTranslations('description', $descriptions);
```

Пры масавым запаўненні таксама можна прысвойваць аб’екты `iterable`. Напрыклад:

```php
$post->fill([
    'title'       => $titles,
    'description' => $descriptions,
]);

Article::create([
    'title'       => $titles,
    'description' => $descriptions,
]);
```

Для розных палёў можна задаваць розныя наборы лакаляў. Напрыклад, код вышэй запоўніць поле `title` для французскай, англійскай і нямецкай лакаляў, а поле `description` — толькі для французскай і нямецкай.

### Выдаленне перакладу {/* #forget_translation */}

:::warning

Пры [даданні і абнаўленні](<#set_translations>) змены захоўваюцца ў мадэлі. Метады `forgetTranslation` і `forgetAllTranslations` адразу змяняюць базу даных, выклікаючы `delete` для мадэлі перакладу.

Мадэль перакладу па змаўчанні не мае трэйта [SoftDeletes](<https://laravel.com/docs/eloquent#soft-deleting>), таму даныя выдаляюцца адразу. Пры патрэбе можна самастойна ўнесці адпаведныя змены ў клас мадэлі і файл міграцыі.

:::

```php
use App\Models\Article;

$page = Article::first();

$page->forgetTranslation('fr');
// or
$page->forgetTranslation(Locale::French);
```

Таксама можна выдаліць усе лакалі адначасова метадам `forgetAllTranslations`.

```php
use App\Models\Article;

$page = Article::first();

$page->forgetAllTranslations();
```

### Праверка наяўнасці перакладу {/* #has_translated */}

Наяўнасць перакладу слупка можна праверыць некалькімі спосабамі. Першы — выклікаць метад `hasTranslated` з імем слупка ў якасці параметра.

```php
use App\Models\Article;

$page = Article::first();

$page->hasTranslated('title');
```

Гэты метад правярае і <abbr title={"Значэнне параметра \"app.locale\" у файле \"config/app.php\"."}>асноўную</abbr>, і <abbr title={"Значэнне параметра \"app.fallback_locale\" у файле \"config/app.php\"."}>рэзервовую</abbr> лакалі. Ён вяртае `true`, калі адно са значэнняў запоўненае, і `false`, калі абодва пустыя.

:::note

Захаваныя лагічныя (`true / false`) і лікавыя (`0, 0.0`) значэнні лічацца запоўненымі, таму метад верне `true`.

:::

Каб праверыць наяўнасць значэння для пэўнай лакалі, перадайце яе код як другі аргумент. Напрыклад:

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->hasTranslated('title', 'fr');
// or
$page->hasTranslated('title', Locale::French);
```

### Праверка магчымасці перакладу {/* #is_translatable */}

Метад `isTranslatable` правярае, ці ёсць поле ва ўласцівасці `$fillable` мадэлі Translate.

Напрыклад:

```php
use Illuminate\Database\Eloquent\Model;
use LaravelLang\Models\Eloquent\Translation;
use LaravelLang\Models\HasTranslations;

class Article extends Model
{
    use HasTranslations;
}

class ArticleTranslation extends Translation
{
    protected $fillable = [
        'title',
    ];
}

$page = Article::first();

$page->isTranslatable('title'); // true
$page->isTranslatable('description'); // false
```

### Выдаленне базавай мадэлі {/* #delete_base_model */}

Мадэль перакладу па змаўчанні мае знешні ключ да бацькоўскай мадэлі. Пры мяккім выдаленні бацькоўскай мадэлі праз трэйт [SoftDeletes](<https://laravel.com/docs/eloquent#soft-deleting>) усе пераклады застануцца. Пры выкліку `forceDelete` яны аўтаматычна выдаляцца з базы даных.

```php
use App\Models\Article;

$page = Article::first();

$page->delete();
// or
$page->forceDelete();
```

## Падзеі {/* #events */}

Наступныя падзеі спрацоўваюць пры адпаведных дзеяннях:

```php
use LaravelLang\Models\Events\AllTranslationsHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenSetEvent;

AllTranslationsHasBeenForgetEvent::dispatch($model);
TranslationHasBeenForgetEvent::dispatch($model, $locale);
TranslationHasBeenSetEvent::dispatch($model, $column, $locale, $oldValue, $newValue);
```

Пры патрэбе можна падпісацца на падзею. Напрыклад:

```php
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\ServiceProvider;
use LaravelLang\Models\Events\AllTranslationsHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenSetEvent;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Event::listen(static function (AllTranslationsHasBeenForgetEvent $event) {
            Log::info('Forget all locales', [
                'model' => $event->model->getKey(),
            ]);
        });

        Event::listen(static function (TranslationHasBeenForgetEvent $event) {
            Log::info('Forget locale', [
                'model'  => $event->model->getKey(),
                'locale' => $event->locale?->value,
            ]);
        });

        Event::listen(static function (TranslationHasBeenSetEvent $event) {
            Log::info('Set new translation', [
                'model'  => $event->model->getKey(),
                'locale' => $event->locale?->value,
                'column' => $event->column,

                'old' => $event->oldValue,
                'new' => $event->newValue,
            ]);
        });
    }
}
```

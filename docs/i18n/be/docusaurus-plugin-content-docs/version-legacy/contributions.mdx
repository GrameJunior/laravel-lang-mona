Мы <strong>вітаем</strong> ваш уклад і абавязкова <strong>пазначаем аўтарства</strong>.

Мы прымаем змены праз запыты на зліццё ва [ўсіх праектах](<https://github.com/orgs/Laravel-Lang/repositories>) нашай арганізацыі.

## Прызначэнне файлаў {/* #what_do_the_files_mean */}

- <strong>php.json</strong> — пераклады значэнняў для файлаў лакалізацыі PHP.
- <strong>php-inline.json</strong> — убудаваныя пераклады значэнняў для файлаў лакалізацыі PHP.
- <strong>json.json</strong> — пераклады значэнняў для файлаў лакалізацыі JSON.
- <strong>json-inline.json</strong> — убудаваныя пераклады значэнняў для файлаў лакалізацыі JSON.
- <strong>\_excludes.json</strong> — значэнні, пераклады якіх супадаюць з англійскімі. У гэтым файле пералічваюцца значэнні, а ключоў у ім няма.

## Рэдагаванне файлаў {/* #how_to_edit_files */}

Усе файлы, даступныя для перакладу, маюць пашырэнне json і знаходзяцца ў каталогу `locales`. Адкрыйце патрэбны файл і зрабіце змены.

:::tip

Нават калі вы заўважылі памылку ў ключы, пакіньце яго як ёсць, інакш Laravel не зможа яго прачытаць.

Каб выправіць напісанне, можна даслаць [запыт на зліццё](<https://github.com/orgs/laravel/repositories>) у адпаведны праект каманды Laravel.

Пасля гэтага нашы прадукты аўтаматычна абновяць ключы. Гэта адбываецца раз на дзень.

:::

1. Адкрыйце файл лакалізацыі.
1. Змяніце значэнні ключоў.
1. Стварыце каміт і адпраўце яго.
1. Стварыце запыт на зліццё і ўкажыце код лакалі, для якой робіце змены. Напрыклад:

   :::tip

   \[fr\]: Added new localization

   :::

:::tip

Звярніце ўвагу на файлы з суфіксам `inline`: у іх не павінна быць спасылак на бягучы атрыбут (`:attribute`).

Убудаваныя пераклады адрозніваюцца формай звароту:

```text
// Звычайны пераклад
The :attribute must contain at least one letter.

// Убудаваны пераклад
This field must contain at least one letter.
```

:::

## Даданне новай лакалі {/* #how_to_add_a_new_locale */}

### Для праектаў Laravel Lang {/* #for_laravel_lang_projects */}

Як правіла, усе нашы праекты ўжо змяшчаюць даступныя лакалі. Калі хочаце прапанаваць новую, [напішыце нам](<https://github.com/orgs/Laravel-Lang/discussions/new?category=ideas&title=I%20want%20to%20add%20a%20new%20localization>).

### Для старонніх праектаў {/* #for_third_party_projects */}

:::tip

Каб дадаць лакаль, якой няма ў `laravel-lang/locale-list`, [напішыце нам](<https://github.com/orgs/Laravel-Lang/discussions/new?category=ideas&title=I%20want%20to%20add%20a%20new%20localization>).

:::

Пераканайцеся, што пакет `laravel-lang/status-generator` усталяваны, і выканайце каманду:

```bash
vendor/bin/lang create <locale>
# vendor/bin/lang create fr
```

Каб усталяваць усе адсутныя лакалі, запусціце каманду без кода лакалі:

```bash
vendor/bin/lang create
```

## Стыль кода {/* #code_style */}

Каманда Laravel-Lang прытрымліваецца стандарту афармлення кода [PER](<https://www.php-fig.org/per/coding-style/>) і стандарту аўтазагрузкі [PSR-4](<https://www.php-fig.org/psr/psr-4/>).

Каб прымяніць фарматаванне паводле стандарту, выканайце каманду:

```bash
composer style
```

## Загаловак запыту на зліццё {/* #pr_title */}

Загаловак запыту на зліццё павінен адпавядаць наступнаму фармату:

```bash
[locale]: Description
```

Напрыклад:

```bash
[fr]: Added new localization
```

Адпаведнасць загалоўка зададзенаму фармату правяраецца рэгулярным выразам:

```bash
/^(Draft:\s)?\[[a-zA-Z,_\s]+\]:\s.+$/
```

## Правілы паводзін {/* #code_of_conduct */}

Правілы паводзін Laravel заснаваныя на [Contributor Covenant](<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>). Пра парушэнні правілаў можна паведаміць [Андрэю Хелдару і Фрэду Дэльрыё](<mailto:helldar@dragon-code.pro;caouecs@caouecs.net>):

- Удзельнікі павінны талерантна ставіцца да супрацьлеглых поглядаў.
- Удзельнікі павінны пазбягаць асабістых нападак і зняважлівых заўваг у выказваннях і дзеяннях.
- Тлумачачы словы і дзеянні іншых, удзельнікі заўсёды павінны зыходзіць з таго, што ў іх добрыя намеры.
- Паводзіны, якія можна абгрунтавана лічыць дамаганнем, недапушчальныя.

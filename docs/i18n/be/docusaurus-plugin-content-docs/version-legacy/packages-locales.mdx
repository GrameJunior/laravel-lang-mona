## Усталяванне {/* #installation */}

:::note

Табліцу сумяшчальнасці можна паглядзець [тут](<#compatibility> "Табліца сумяшчальнасці пакета Locales").

:::

Каб усталяваць пакет, выканайце каманду:

```bash
composer require laravel-lang/locales:^2.11.0
```

## Выкарыстанне {/* #usage */}

Для працы з лакалямі можна выкарыстоўваць фасад `LaravelLang\Locales\Facades\Locales`. Ён вяртае звесткі ў двух фарматах: як спіс кодаў лакаляў або як масіў аб’ектаў DTO.

### Аб’екты даных {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// Спіс даступных лакаляў.
Locales::available(): array // array<LocaleData>

// Спіс усталяваных лакаляў.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// Спіс неўсталяваных лакаляў.
Locales::notInstalled(): array // array<LocaleData>

// Атрыманне спіса абароненых лакаляў.
Locales::protects(): array // array<LocaleData>

// Праверка наяўнасці моўных пакетаў для запытанай лакалі.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// Праверка, ці ўсталяваны моўны пакет.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// Праверка, ці абароненая лакаль.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// Праверка лакалі і вяртанне сапраўднага значэння.
// Калі запытаная лакаль не ўсталяваная, вяртаецца бягучая лакаль прыкладання.
Locales::get(mixed $locale): LocaleData

// Атрыманне назвы лакалі па змаўчанні.
Locales::getDefault(): LocaleData

// Атрыманне назвы рэзервовай лакалі.
Locales::getFallback(): LocaleData

// Вяртае звесткі пра любую даступную лакаль, інакш — пра бягучую лакаль прыкладання.
Locales::info(mixed $locale): LocaleData
```

### Прыклады {/* #examples */}

```php
use LaravelLang\LocaleList\Direction;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\CountryData;
use LaravelLang\Locales\Data\CurrencyData;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// config('app.locale') // de

return Locales::getDefault(withCountry: true, withCurrency: true);

// Без аліяса
LocaleData {
  +code: "de"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
  +country: CountryData {
    +code: "DE"
    +native: "Deutschland"
    +localized: "Allemagne"
  }
  +currency: CurrencyData {
    +code: "EUR"

    +localized: "euro"

    +name: "LeftToRight"
    +value: "ltr"
  }

    +name: "German"
    +value: "de"
```

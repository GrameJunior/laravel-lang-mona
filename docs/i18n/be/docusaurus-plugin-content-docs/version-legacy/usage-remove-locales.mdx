:::warning

Каманда выдаляе ўвесь каталог лакалі разам з файламі, за выключэннем лакалі па змаўчанні і рэзервовай лакалі.

:::

Для выдалення лакаляў запусціце каманду `php artisan lang:rm <locale>` і перадайце іх літарныя коды:

```bash
php artisan lang:rm fr de de_AT de_CH vi zh_CN
```

Калі не перадаць аргументы, у кансолі з’явіцца інтэрактыўнае пытанне з выбарам лакаляў з даступнага спіса.

```bash
php artisan lang:rm
```

Па змаўчанні каманда паведамляе пра памылку пры спробе выдаліць абароненую лакаль.

Абароненыя лакалі — гэта коды з параметраў `locale` і `fallback_locale` файла `config/app.php`.

Для прымусовага выдалення абароненай лакалі выкарыстоўвайце опцыю `force`:

```bash
php artisan lang:rm en --force
```

---

Каб вярнуць файлы ў стан па змаўчанні, выканайце каманду:

```bash
php artisan lang:reset
```

У выніку з усіх мэтавых файлаў будуць выдалены ключы, якія не вызначаюцца пакетамі <strong>Laravel Lang</strong> або ўсталяванымі [староннімі плагінамі](<./plugins-community.mdx>).

olgan har qanday shaxsga Dasturdan cheklovsiz foydalanish uchun
bepul ruxsat beriladi. Bu, jumladan, Dasturdan foydalanish,
uni nusxalash, o‘zgartirish, birlashtirish, e’lon qilish, tarqatish,
quyi litsenziya berish va/yoki nusxalarini sotish, shuningdek Dastur
berilgan shaxslarga ham shu huquqlarni quyidagi shartlar asosida berishni o‘z ichiga oladi:

Yuqoridagi mualliflik huquqi bayonnomasi va ushbu ruxsat bayonnomasi
Dasturning barcha nusxalari yoki muhim qismlariga kiritilishi shart.

## O‘rnatish {/* #installation */}

:::note

Ushbu maxsus paketdan foydalanish tavsiya etiladi, chunki u ilovani mahalliylashtirish uchun kerakli barcha bog‘liqliklarni tez yangilash imkonini beradi.

Moslik jadvalini [shu yerda](<#compatibility> "Common paketi uchun moslik jadvali") ko‘rishingiz mumkin.

:::

Paketni [Composer](<https://getcomposer.org>) orqali o‘rnatishingiz mumkin:

```bash
composer require laravel-lang/common:^6.9
```

:::warning

Laravel 10 dan foydalansangiz, o‘rnatiladigan `laravel-lang/lang` paketi versiyasini qo‘lda ko‘rsatishingiz kerak:

```bash
composer require --dev laravel-lang/lang:^15.39.1:^14.0
```

:::

## Foydalanish {/* #usage */}

Endi `lang:update` konsol buyrug‘i orqali mavjud lokallarni [yangilashingiz](<./usage-update-locales.mdx> "Laravel ilovasida lokallarni yangilash") mumkin:

```bash
php artisan lang:update
```

Buyruq chaqiruvini `composer.json` faylidagi `scripts` blokining `post-update-cmd` bo‘limiga qo‘shishni ham tavsiya qilamiz:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Bu bog‘liqliklar yangilangach, `php artisan lang:update` konsol buyrug‘ini qo‘lda bajarishga hojat qoldirmay, lokal fayllarini avtomatik yangilash imkonini beradi.

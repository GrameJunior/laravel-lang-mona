Xavfsizlik tuzatishlari chiqariladigan versiyalar haqida [<strong>qo‘llab-quvvatlash siyosatimizga</strong>](<./release-notes.mdx#support_policy>) qarang.

## Zaiflik haqida xabar berish {/* #reporting_a_vulnerability */}

:::warning

Ushbu sahifaga kelgan veb-saytingiz Cloudflare bilan himoyalangan. Zararli botlar ololmasligi uchun o‘sha sahifadagi elektron pochta manzillari yashirilgan.

Quyidagi matndagi havolani bosganda xabar ko‘rsatilsa, brauzerda sahifani qayta yuklang.

:::

## O‘rnatish {/* #installation */}

:::note

Moslik jadvalini [shu yerda](<#compatibility> "Native Country Names paketi uchun moslik jadvali") ko‘rishingiz mumkin.

:::

O‘rnatish uchun quyidagi konsol buyrug‘ini bajaring:

```bash
composer require laravel-lang/native-country-names:^1.8.0
```

## Foydalanish {/* #usage */}

use LaravelLang\NativeCountryNames\CountryNames;

### Asl tildagi nomlar {/* #native_names */}

```php
use LaravelLang\NativeCountryNames\CountryNames;

return CountryNames::get();
// yoki
return CountryNames::get('');
// yoki
return CountryNames::get(null);
// yoki
return CountryNames::get('foo');
```

### Tartiblash {/* #sorting */}

Natijani kalit yoki qiymat bo‘yicha tartiblangan holda olish uchun parametrga `SortBy` enum variantini uzating.

Standart holatda qiymatlar bo‘yicha tartiblanadi.

#### Kalitlar bo‘yicha tartiblash {/* #sort_by_keys */}

```php
use LaravelLang\NativeCountryNames\CountryNames;
use LaravelLang\NativeCountryNames\Enums\SortBy;

return CountryNames::get('en', SortBy::Key);
```

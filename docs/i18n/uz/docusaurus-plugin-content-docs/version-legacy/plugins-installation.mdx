:::note

Mavjud [rasmiy](<./plugins-official.mdx>) va [hamjamiyat yaratgan](<./plugins-community.mdx>) plaginlar ro‘yxatini ham ko‘rishingiz mumkin.

:::

Nashr boshqaruvchisidan foydalanish uchun ikkita qadam kifoya:

1. Paketni ilovangizga o‘rnating. Masalan, `composer require --dev laravel-lang/lang:^15.39.1` ni bajaring yoki boshqa paketni o‘rnating.
1. Shu bilan tamom 😊

Endi `php artisan lang:update` buyrug‘i bajarilganda, boshqaruvchi ko‘rsatilgan paketlarni tekshiradi va ilovangizdagi fayllarni avtomatik yangilaydi.

Turli paketlarda bir xil nomli fayllar, masalan, `custom.php` bo‘lsa, ishlov berishda barcha fayllardagi kalitlarning barchasi hisobga olinadi.

:::tip

Ishlab chiqishni osonlashtirish uchun tayyor [tarjima andozasidan](<https://github.com/Laravel-Lang/translations-template>) foydalaning.

:::

Ishlaringizga omad! 😊

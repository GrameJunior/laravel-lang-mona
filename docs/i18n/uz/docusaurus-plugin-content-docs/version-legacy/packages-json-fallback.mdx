## O‘rnatish {/* #installation */}

:::note

Moslik jadvalini [shu yerda](<#compatibility> "JSON Fallback paketi uchun moslik jadvali") ko‘rishingiz mumkin.

:::

Laravel standart holatda JSON kalitlari uchun zaxira tarjimalarga <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">ruxsat bermaydi</a>. Masalan, `__('Remember Me')` ni chaqirsangiz, fransuzcha zaxira til uchun `Se souvenir de moi` o‘rniga `Remember Me` ni olasiz.

O‘rnatish uchun quyidagi konsol buyrug‘ini bajaring:

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Foydalanish {/* #usage */}

:::note

Laravel 11 da `config/app.php` faylida `providers` bo‘limi yo‘q. Uni qo‘lda qo‘shishingiz mumkin.

:::

O‘rnatgach, `config/app.php` sozlama faylining `providers` bo‘limiga xizmat provayderini qo‘shing:

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // boshqa xizmat provayderlari
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Endi JSON kalitlari tanlangan lokalga qarab to‘g‘ri qiymatni chiqaradi.

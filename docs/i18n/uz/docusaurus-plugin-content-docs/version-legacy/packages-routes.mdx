## O‘rnatish {/* #installation */}

:::note

Moslik jadvalini [shu yerda](<#compatibility> "Routes paketi uchun moslik jadvali") ko‘rishingiz mumkin.

:::

O‘rnatish uchun quyidagi konsol buyrug‘ini bajaring:

```bash
composer require laravel-lang/routes:^1.11.0
```

Standart sozlamalarni `config/localization.php` faylini tahrirlab [o‘zgartirishingiz](<./configuration.mdx#routes>) ham mumkin.

:::note

[Marshrut keshi](<https://laravel.com/docs/routing#route-caching>) to‘liq qo‘llab-quvvatlanadi.

```bash
php artisan route:cache
```

:::

## Foydalanish {/* #usage */}

Bu yerda bitta ilovada [Routes](<./packages-routes.mdx#usage> "Routes paketidan foydalanish") va [Models](<./packages-models.mdx#usage> "Models paketidan foydalanish") loyihalarini o‘rnatish va ishlatish haqida qisqa videoni ko‘rishingiz mumkin ([YouTube’da ko‘rish](<https://youtu.be/mH76pGbpVu0>)):

<iframe className="legacy-video" src="https://www.youtube-nocookie.com/embed/mH76pGbpVu0" title={"Routes va Models"} loading="lazy" allowFullScreen />

Ilovada ikki lokal, fransuz va nemis tillari o‘rnatilgan deb olaylik.

Ilova sozlamalari quyidagicha bo‘ladi:

```php
// config/app.php
use LaravelLang\LocaleList\Locale;

return [
    'locale' => Locale::French->value,

    'fallback_locale' => Locale::German->value,
];
```

Fransuz va nemis tillari uchun quyidagi qiymatlarni ham belgiladik:

```json
{
    "Foo": "Toutes les données ont été chargées."
}
```

```json
{
    "Foo": "Alle Ressourcen geladen."
}
```

### Bevosita ulash {/* #direct */}

Muqobil nom qo‘shmasdan, vositachi dasturga bevosita murojaat qilishingiz mumkin:

```php
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('some/{locale}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByParameterWithRedirect::class)
    ->get('some/{locale?}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByHeader::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByCookie::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationBySession::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('some', fn () => view('welcome'));
```

```php

    ->middleware(LocalizationByParameter::class)
```

### Model orqali {/* #via_model */}

:::tip

Lokalni <abbr title={"Bu nomni \"config/localization.php\" faylining \"routes\" bo‘limida o‘zgartirish mumkin."}>locale</abbr> nomli ustunga qarab belgilaydi.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Bu metod autentifikatsiyadan o‘tgan har qanday mijoz uchun lokalni belgilash imkonini beradi. Buning uchun modelda <abbr title={"Bu nomni \"config/localization.php\" faylining \"routes\" bo‘limida o‘zgartirish mumkin."}>"locale"</abbr> atributi borligini tekshiring.

Foydalanuvchilar jadvalida bu ustun bo‘lmasa, kerak bo‘lganda uni qo‘shing yoki model sinfida dinamik metod yarating.

Masalan:

```php
use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Foundation\Auth\User as Authenticatable;
use LaravelLang\LocaleList\Locale;

class User extends Authenticatable
{
    protected function locale(): Attribute
    {
        return Attribute::make(
            get: fn () => Locale::French
        );
    }
}
```

Endi foydalanuvchi vositachi dastur orqali yoki qo‘lda, masalan, `Auth::login($user)` metodi bilan autentifikatsiyadan o‘tganda, ilova ma’lumotni foydalanuvchi tanlagan tilda qaytaradi.

Bundan tashqari, foydalanuvchi muayyan autentifikatsiya mexanizmi bilan kirgan bo‘lsa, vositachi dasturni chaqirganda uni ikki nuqta bilan ajratib ko‘rsatishingiz mumkin.

Masalan:

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class . ':guard_name')
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Vositachi dastur foydalanuvchi obyektini olish uchun quyidagi koddan foydalanadi:

```php
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;

class LocalizationByModel extends Middleware
{
    public function __construct(
        protected ?string $guard = null,
    ) {}

    protected function user(Request $request): ?Model
    {
        return $request->user($this->guard);
    }
}
```

### Mahalliylashtirilgan guruh orqali {/* #via_localization_group */}

:::note

`localizedRoute` yordamchi funksiyasi marshrutlarni <abbr title={"Mavjud metodlar: \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" va \"LocalizationRoute::group\"."}>guruhlamasdan</abbr> chaqirilsa, lokal so‘rov parametri sifatida ko‘rsatiladi. Masalan:

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Parametr nomi, nom prefiksi va yo‘naltirish parametrini `config/localization.php` faylining `routes` bo‘limida o‘zgartirish mumkin.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Bu metod mahalliylashtirilgan marshrutlar yordamida guruh prefikslarini boshqarishni osonlashtiradi.

Ushbu guruhning asosiy `LocalizationByParameterPrefix` vositachi dasturidan tashqari, `LocalizationByCookie`, `LocalizationByHeader` va `LocalizationBySession` ham qatnashadi.

Uchta usuldan birini ishlatishingiz mumkin:

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

Natijadagi ilova ikki turdagi marshrutni ro‘yxatdan o‘tkazadi: `{locale}` prefiksli va prefikssiz. Masalan:

| URL | Andoza | Nom |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Nom prefiksini `config/localization.php` faylining `routes` bo‘limida o‘zgartirish mumkin.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

## Hodisalar {/* #events */}

:::note

Hodisa `laravel-lang/routes` paketining `1.1` va undan keyingi versiyalarida mavjud.

:::

Ilovada lokalni belgilash uchun parametr uzatilganda, hodisa chaqiriladi:

```php
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

LocaleHasBeenSetEvent::dispatch($locale);
```

Hodisaning `$locale` xususiyati `LaravelLang\Locales\Data\LocaleData` tipiga ega.

Kerak bo‘lsa, ushbu hodisani tinglashingiz mumkin. Masalan:

```php
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\ServiceProvider;
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Event::listen(static function (LocaleHasBeenSetEvent $event) {
            Log::info('Locale set to: ' . $event->locale->code);
        });
    }
}
```

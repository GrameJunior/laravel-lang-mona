## Nashr qilish {/* #publish */}

Istasangiz, sozlama faylini quyidagicha nashr qilishingiz mumkin:

```bash
php artisan vendor:publish --tag="localization"
```

Nashr qilingan `config/localization.php` faylining mazmuni:

<details>
<summary>Sozlamalarni ko‘rsatish</summary>

```php

    /*
     * Til fayllari yangilanganda qaysi turdagi fayllar ishlatilishini belgilaydi.
     *
     * @see https://laravel-lang.com/configuration.html#inline
     *
     * Standart qiymat: `false`.
     */

    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),

     *
     * Loyihangizdagi lokallarning moslik xaritasini shu yerda belgilang.

     * @see https://laravel-lang.com/configuration.html#aliases

    /*

            'double_quote_opener' => '“',

            'yandex' => [
                'translator' => '\LaravelLang\Translator\Integrations\Yandex',

                    'key'    => (string) env('TRANSLATION_YANDEX_KEY'),

            ],
        ],

        'options' => [
            /*

             *   Standart qiymat: `true`

             * @example (e.g. "Hello :name" will extract "name")
             */

            'preserve_parameters' => true,
        ],
    ],
];
```

## Inline tarjimalar {/* #inline */}

`inline` parametri til fayllarini yangilashda qaysi turdagi fayllar ishlatilishini belgilaydi.

- `true` bo‘lsa, inline fayllar ishlatiladi.
- `false` bo‘lsa, standart fayllar ishlatiladi.

Masalan, ular orasidagi farqni bu yerda ko‘rish mumkin:

```text
The :attribute must be accepted. // default
This field must be accepted. // inline
```

Bu parametr `config/localization.php` faylida mavjud:

```php
return [
    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),
];
```

## Tekislash {/* #alignment */}

`align` parametri lokal fayllariga ishlov berishda qiymatlar qanday tekislanishini belgilaydi.

Fayllar yangilanganda yakuniy fayllardan barcha izohlar avtomatik olib tashlanadi. [var\_export](<https://www.php.net/manual/en/function.var-export.php>) izohlarni saqlay olmaydi.

Faylingizdan misol:

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Autentifikatsiya til satrlari
    |--------------------------------------------------------------------------
    |
    | The following language lines are used during authentication for various
    | messages that we need to display to the user. You are free to modify
    | these language lines according to your application's requirements.
    |
    */
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

Yangilangan fayl quyidagicha bo‘ladi:

```php
declare(strict_types=1);

return [
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

`validation.php` faylidan misol:

<details>
<summary>Mazmunni ko‘rsatish</summary>

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Tekshiruv til satrlari
    |--------------------------------------------------------------------------
    |
    | The following language lines contain the default error messages used by
    | the validator class. Some of these rules have multiple versions such
    | as the size rules. Feel free to tweak each of these messages here.
    |
    */
    'accepted'   => 'The :attribute must be accepted.',
    'active_url' => 'The :attribute is not a valid URL.',

    // boshqa qoidalar

    'uuid' => 'The :attribute must be a valid UUID.',
    /*
    |--------------------------------------------------------------------------
    | Custom Validation Language Lines
    |--------------------------------------------------------------------------
    |
    | Here you may specify custom validation messages for attributes using the
    | convention "attribute.rule" to name the lines. This makes it quick to
    | specify a specific custom language line for a given attribute rule.
    |
    */
    'custom' => [
        'name' => [
            'required' => 'Custom message 1',
            'string'   => 'Custom message 2',
        ],
    ],
    /*
    |--------------------------------------------------------------------------
    | Custom Validation Attributes
    |--------------------------------------------------------------------------
    |
    | The following language lines are used to swap our attribute placeholder
    | with something more reader friendly such as "E-Mail Address" instead
    | of "email". This simply helps us make our message more expressive.
    |
    */
    'attributes' => [
        'name' => 'Foo',
        'bar'  => 'Bar',
        'baz'  => 'Baz',
    ],
];
```

</details>

Fayl yangilangach, quyidagicha ko‘rinadi:

```php
declare(strict_types=1);

return [
    'accepted'   => 'The :attribute must be accepted.',
    'active_url' => 'The :attribute is not a valid URL.',
    'uuid'       => 'The :attribute must be a valid UUID.',
    'custom'     => [
        'name' => [
            'required' => 'Custom message 1',
            'string'   => 'Custom message 2',
        ],
    ],
    'attributes' => [
        'name' => 'Foo',
        'bar'  => 'Bar',
        'baz'  => 'Baz',
    ],
];
```

Bu parametr `config/localization.php` faylida mavjud:

```php
return [
    'align' => (bool) env('LOCALIZATION_ALIGN', env('LANG_PUBLISHER_ALIGN', true)),
];
```

## Muqobil nomlar {/* #aliases */}

Kodlarni boshqacha nomlashni istasangiz, masalan, `de` o‘rniga `de-DE` yoki `de_CH` o‘rniga `de-CH`, [sozlama faylida](<./configuration.mdx#aliases>) `aliases` ni belgilashingiz mumkin.

Shundan so‘ng qo‘shish, yangilash va o‘chirish amallarining barchasi `config/localization.php` sozlama faylida ko‘rsatilgan muqobil nomlardan avtomatik foydalanadi:

```php
declare(strict_types=1);

use LaravelLang\LocaleList\Locale;

return [
    'aliases' => [
        Locale::German->value            => 'de-DE',
        Locale::GermanAustria->value     => 'de-AT',
        Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

`config/localization.php` fayli allaqachon mavjud bo‘lsa, unga muqobil nomlar kalitini qo‘shishingiz va kerakli `aliases` qiymatlarini massiv orqali belgilashingiz mumkin.

Shundan so‘ng, masalan, ham asosiy kodni, ham uning muqobil nomini ko‘rsatib yangi lokallarni qo‘shishingiz mumkin:

```bash
php artisan lang:add de de_CH
```

O‘rnatilgan lokallar berilgan muqobil nomlarni PHP tarjimalari uchun katalog, JSON tarjimalari uchun fayl nomi sifatida ishlatadi:

```text
lang
de-CH
de-DE
```

Bu parametr `config/localization.php` faylida mavjud:

```php
return [
    'aliases' => [
        // \LaravelLang\LocaleList\Locale::German->value => 'de-DE',
        // \LaravelLang\LocaleList\Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

## Aqlli punktuatsiya {/* #smart_punctuation */}

Masalan:

```json
{
    "Some": "\"It's super-configurable... you can even use additional extensions to expand its capabilities -- just like this one!\""
}
```

Natijadagi fayllar:

```json
{
    "Some": "“It’s super-configurable… you can even use additional extensions to expand its capabilities – just like this one!”"
}
```

Bu parametr `config/localization.php` faylida mavjud:

                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,

## Modellar {/* #models */}

[Models](<./packages-models.mdx> "Modellarni oson va tez mahalliylashtirish") paketidan foydalanganda parametrlarning standart qiymatlarini belgilashingiz mumkin.

Bu sozlama `config/localization.php` faylida mavjud:

```php
return [
    'models' => [
        'suffix' => 'Translation',
        'filter' => [
            'enabled' => (bool) env('LOCALIZATION_FILTER_ENABLED', true),
        ],
        'helpers' => env('VENDOR_PATH', base_path('vendor/_laravel_lang')),
    ],
];
```

`suffix` parametri tarjima repozitoriysi tegishli bo‘lgan modellar nomining suffiksini belgilaydi.

Masalan:

```text
App\Models\Post::class
App\Models\PostTranslation::class
```

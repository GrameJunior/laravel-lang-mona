## O‘rnatish {/* #installation */}

:::note

Moslik jadvalini [shu yerda](<#compatibility> "Models paketi uchun moslik jadvali") ko‘rishingiz mumkin.

:::

O‘rnatish uchun quyidagi konsol buyrug‘ini bajaring:

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Standart sozlamalarni `config/localization.php` faylini tahrirlab [o‘zgartirishingiz](<./configuration.mdx#translator>) ham mumkin.

## Foydalanish {/* #usage */}

:::tip

Zarur bo‘lsa, provayderlarning autentifikatsiya ma’lumotlarini `config/localization.php` sozlama faylida belgilang. Bu ma’lumotlarsiz pulli xizmatlar to‘g‘ri ishlamaydi.

:::

### Navbatma-navbat tarjima {/* #cyclical_translation */}

Barcha API xizmatlari tarjima uchun kerakli lokallarni qamrab olmaydi. Shu sabab matnni bitta chaqiruvda tarjima qila oladigan xizmatni izlash mumkin.

Masalan, quyidagi sozlamalarimiz bor:

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

Sozlamalarda Google Translate va DeepL Translate’ni faol tarjimonlar sifatida belgiladik, Yandex.Translate’ni esa o‘chirdik. `enabled` parametri faqat navbatma-navbat tarjimaga tatbiq etiladi.

Google Translate faqat fransuz tiliga, DeepL Translate esa faqat nemis tiliga tarjima qila oladi deb olaylik. Shunda uchta tarjima holati yuzaga keladi:

#### Fasad orqali {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Bog‘liqlikni uzatish orqali {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

#### Google Translate orqali {/* #via_google */}

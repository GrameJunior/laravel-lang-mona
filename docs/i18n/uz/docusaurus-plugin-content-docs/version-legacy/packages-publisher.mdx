## O‘rnatish {/* #installation */}

:::note

Moslik jadvalini [shu yerda](<#compatibility> "Publisher paketi uchun moslik jadvali") ko‘rishingiz mumkin.

:::

O‘rnatish uchun quyidagi konsol buyrug‘ini bajaring:

```bash
composer require --dev laravel-lang/publisher:^16.9.0
```

## Foydalanish {/* #usage */}

Endi `lang:update` konsol buyrug‘i orqali mavjud lokallarni [yangilashingiz](<./usage-update-locales.mdx> "Laravel ilovasida lokallarni yangilash") mumkin:

```bash
php artisan lang:update
```

Buyruq chaqiruvini `composer.json` faylidagi `scripts` blokining `post-update-cmd` bo‘limiga qo‘shishni ham tavsiya qilamiz:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Bu bog‘liqliklar yangilangach, `php artisan lang:update` konsol buyrug‘ini qo‘lda bajarishga hojat qoldirmay, lokal fayllarini avtomatik yangilash imkonini beradi.

## O‘rnatish {/* #installation */}

:::note

Moslik jadvalini [shu yerda](<#compatibility> "Locales paketi uchun moslik jadvali") ko‘rishingiz mumkin.

:::

O‘rnatish uchun quyidagi konsol buyrug‘ini bajaring:

```bash
composer require laravel-lang/locales:^2.11.0
```

## Foydalanish {/* #usage */}

Lokallar bilan ishlash uchun `LaravelLang\Locales\Facades\Locales` fasadidan foydalanishingiz mumkin. U ma’lumotni ikki shaklda olish imkonini beradi: lokal kodlari ro‘yxati yoki DTO obyektlari massivi.

### Ma’lumot obyektlari {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// Mavjud lokallar ro‘yxati.
Locales::available(): array // array<LocaleData>

// O‘rnatilgan lokallar ro‘yxati.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// O‘rnatilmagan lokallar ro‘yxati.
Locales::notInstalled(): array // array<LocaleData>

// Himoyalangan lokallar ro‘yxatini olish.
Locales::protects(): array // array<LocaleData>

// So‘ralgan lokal uchun til paketlari mavjudligini tekshirish.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// Til paketi o‘rnatilganini tekshirish.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// Tekshirilayotgan lokal himoyalanganini aniqlash.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// Tekshiradi va to‘g‘ri lokalni qaytaradi.
// O‘rnatilmagan lokal so‘ralsa, ilovadagi hozirgi faol lokalni qaytaradi.
Locales::get(mixed $locale): LocaleData

// Standart lokal nomini olish.
Locales::getDefault(): LocaleData

// Zaxira lokal nomini olish.
Locales::getFallback(): LocaleData

// Mavjud lokal haqida ma’lumot oladi. U topilmasa, ilovadagi hozirgi faol lokalni qaytaradi.
Locales::info(mixed $locale): LocaleData
```

use LaravelLang\Locales\Data\CurrencyData;

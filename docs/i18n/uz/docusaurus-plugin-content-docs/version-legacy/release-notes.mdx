## Versiyalash tartibi {/* #versioning_scheme */}

Barcha paketlarimiz [semantik versiyalashga](<https://semver.org>) amal qiladi. Orqaga moslikni buzuvchi imkoniyat qo‘shilganda yoki Laravel va uning boshqa rasmiy paketlarining [eskirgan versiyalarini](<https://laravel.com/docs/releases>) qo‘llab-quvvatlash to‘xtatilganda asosiy versiya chiqariladi. Kichik versiyalar va tuzatish relizlarida bunday o‘zgarishlar bo‘lmasligi kerak.

## Qo‘llab-quvvatlash siyosati {/* #support_policy */}

Barcha Lang loyihalarida [Laravel qo‘llab-quvvatlash siyosatiga](<https://laravel.com/docs/releases#support-policy>) amal qilamiz.

`Lang` loyihasi paketlarida loyiha xavfsizligiga ta’sir qiluvchi kod bo‘lishi kutilmagani sababli, Laravel loyihalari va [PHP](<https://www.php.net>) ning kichik versiyalari uchun [rejalashtirilgan xizmat ko‘rsatish yakuni sanalariga](<https://laravel.com/docs/releases#support-policy>) tayanamiz.

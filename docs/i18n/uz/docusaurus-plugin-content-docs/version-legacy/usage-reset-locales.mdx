Fayllarni standart holatga qaytarish uchun konsolda quyidagi buyruqni bajaring:

```bash
php artisan lang:reset
```

Natijada barcha maqsad fayllaridan <strong>Laravel Lang</strong> paketlari yoki o‘rnatilgan [uchinchi tomon plaginlari](<./plugins-community.mdx>) belgilamagan kalitlar olib tashlanadi.

ファイルを更新するには、次のコンソールコマンドを実行します。

```bash
php artisan lang:update
```

これで完了です 🙂

このコンソールコマンドは、アプリケーションにインストールされているロケールを検出し、ファイルを更新します。

:::tip

Laravel の一部のマイナーバージョンでは、リポジトリからキーが削除され、アプリケーションで使われなくなることがあります。まれですが、起こり得ます。

ロケールの更新コマンドは、新しい翻訳文言を追加するか、既存の翻訳文言を更新するだけです。未使用の文言を削除するには、[`php artisan lang:reset`](<./usage-reset-locales.mdx> "Laravel アプリケーションのロケールをリセットする") コマンドを使用します。

:::

## インストール {/* #installation */}

:::note

[Translator パッケージの互換性表](<#compatibility> "Translator パッケージの互換性表")を参照してください。

:::

インストールするには、次のコンソールコマンドを実行します。

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

`config/localization.php` ファイルを編集して、既定の設定を[変更](<./configuration.mdx#translator>)できます。

## 使用方法 {/* #usage */}

:::tip

必要に応じて、`config/localization.php` 設定ファイルにプロバイダーの認証情報を指定してください。指定しなければ有料サービスは正常に動作しません。

:::

### 翻訳サービスを順に試す {/* #cyclical_translation */}

各翻訳 API が対応するロケールは異なります。対応していないサービスを飛ばすことで、目的の言語に翻訳できるサービスを探します。

次の設定を例にします。

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

この設定では Google Translate と DeepL Translate を有効にし、Yandex.Translate を無効にしています。`enabled` パラメーターは、翻訳サービスを順に試す場合にのみ適用されます。

Google Translate はフランス語だけ、DeepL Translate はドイツ語だけに対応するとします。このとき、翻訳結果は次の 3 通りです。

<TabItem value="tab-1" label={"フランス語への翻訳"}>

<span id={"procedure-tif"} />

1. Google Translate が目的の言語に対応するか確認します。フランス語には対応しています。

Google Translate の翻訳結果を返します。

</TabItem>

<TabItem value="tab-2" label={"ドイツ語への翻訳"}>

<span id={"procedure-tig"} />

1. Google Translate はドイツ語に対応していないため、次の翻訳サービスを試します。

DeepL Translate の翻訳結果を返します。

</TabItem>

<TabItem value="tab-3" label={"非対応言語への翻訳"}>

<span id={"procedure-tiu"} />

1. Google Translate は目的の言語に対応していないため、次の翻訳サービスを試します。
1. DeepL Translate も対応していないため、次の翻訳サービスを試します。

翻訳せず原文を返します。

</TabItem>

#### ファサードを使う {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### 依存性注入を使う {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### 翻訳サービスを直接指定する {/* #direct_translate */}

#### Google Translate を使う {/* #via_google */}

:::note

[Google Translate](<https://translate.google.com>) でテキストを直接翻訳する場合、`enabled` 設定は無視されます。

:::

翻訳サービスを直接呼び出すには、`LaravelLang\Translator\Facades\Translate` ファサードを使用するか、`LaravelLang\Translator\Services\Translate` サービスクラスを依存性注入で受け取ります。

<Tabs>

<TabItem value="tab-1" label={"ファサードを使う"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// 文字列を返す

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// 配列を返す

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// 配列を返す

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// 配列を返す
```

</TabItem>

<TabItem value="tab-2" label={"Translator の依存性注入を使う"}>

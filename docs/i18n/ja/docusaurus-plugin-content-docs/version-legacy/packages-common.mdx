## インストール {/* #installation */}

:::note

アプリケーションのローカライズに必要な依存関係をまとめてすばやく更新できるため、このパッケージの使用を推奨します。

[Common パッケージの互換性表](<#compatibility> "Common パッケージの互換性表")を参照してください。

:::

パッケージは [Composer](<https://getcomposer.org>) でインストールできます。

```bash
composer require laravel-lang/common:^6.9
```

:::warning

Laravel 10 では、インストールする `laravel-lang/lang` パッケージのバージョンを手動で指定してください。

```bash
composer require --dev laravel-lang/lang:^15.39.1:^14.0
```

:::

## 使用方法 {/* #usage */}

既存のロケールは、コンソールコマンド `lang:update` で[更新](<./usage-update-locales.mdx> "Laravel アプリケーションのロケールを更新する")できます。

```bash
php artisan lang:update
```

`composer.json` の `scripts` ブロックにある `post-update-cmd` セクションに、コマンドの呼び出しを追加することも推奨します。

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

これにより、依存関係を更新するとローカライズファイルも自動で更新されます。`php artisan lang:update` を手動で実行する手間が省けます。

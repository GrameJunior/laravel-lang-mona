このパッケージはスターターキットのインターフェースの翻訳を含みます。

このパッケージを使うと、対応する文言を簡単にローカライズできます。

## インストール {/* #installation */}

:::note

[Starter Kits パッケージの互換性表](<#compatibility> "Starter Kits パッケージの互換性表")を参照してください。

:::

インストールするには、次のコンソールコマンドを実行します。

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## 使用方法 {/* #usage */}

:::note

[Laravel スターターキット](<https://laravel.com/starter-kits>)の翻訳キーを正しく公開するには、`composer.json` の `name` キーに指定されているアプリケーション名を変更しないでください。変更すると、スターターキットの翻訳はインストールされません。

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

既存のロケールは、コンソールコマンド `lang:update` で[更新](<./usage-update-locales.mdx> "Laravel アプリケーションのロケールを更新する")できます。

```bash
php artisan lang:update
```

`composer.json` の `scripts` ブロックにある `post-update-cmd` セクションに、コマンドの呼び出しを追加することも推奨します。

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

これにより、依存関係を更新するとローカライズファイルも自動で更新されます。`php artisan lang:update` を手動で実行する手間が省けます。

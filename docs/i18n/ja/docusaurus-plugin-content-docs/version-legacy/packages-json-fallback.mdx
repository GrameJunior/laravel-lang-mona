## インストール {/* #installation */}

:::note

[JSON Fallback パッケージの互換性表](<#compatibility> "JSON Fallback パッケージの互換性表")を参照してください。

:::

Laravel の標準機能では、JSON キーのフォールバック翻訳は<a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">使用できません</a>。たとえば、フランス語をフォールバック言語にして `__('Remember Me')` を呼び出しても、`Se souvenir de moi` ではなく `Remember Me` が返ります。

インストールするには、次のコンソールコマンドを実行します。

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## 使用方法 {/* #usage */}

:::note

Laravel 11 の `config/app.php` 設定ファイルには `providers` セクションがありません。手動で追加できます。

:::

インストール後、`config/app.php` 設定ファイルの `providers` セクションにサービスプロバイダーへの参照を追加します。

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // その他のサービスプロバイダー
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

これで JSON キーは選択したロケールに応じた値を返すようになります。

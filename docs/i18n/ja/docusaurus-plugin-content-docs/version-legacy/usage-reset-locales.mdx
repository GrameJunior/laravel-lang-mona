---
title: "ロケールをリセットする"
slug: /usage-reset-locales.html
description: "Laravel アプリケーションのロケールをリセットします。"
---

ファイルを既定の状態にリセットするには、次のコンソールコマンドを使用します。

```bash
php artisan lang:reset
```

<strong>Laravel Lang</strong> パッケージまたはインストール済みの[サードパーティープラグイン](<./plugins-community.mdx>)で定義していないキーは、すべての対象ファイルから削除されます。

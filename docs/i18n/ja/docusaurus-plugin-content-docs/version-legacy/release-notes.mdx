## バージョン管理方式 {/* #versioning_scheme */}

すべてのパッケージは[セマンティック バージョニング](<https://semver.org>)に従います。下位互換性を破る機能を追加する場合や、Laravel またはそのほかの公式パッケージの[非推奨バージョン](<https://laravel.com/docs/releases>)への対応を終了する場合は、メジャーリリースを行います。マイナーリリースとパッチリリースには互換性を破る変更を含めません。

## サポートポリシー {/* #support_policy */}

すべての Lang プロジェクトは [Laravel のサポートポリシー](<https://laravel.com/docs/releases#support-policy>)に従います。

`Lang` プロジェクトのパッケージにはプロジェクトのセキュリティに影響するコードが含まれないと想定しています。そのため、Laravel プロジェクトの[メンテナンス終了予定日](<https://laravel.com/docs/releases#support-policy>)と [PHP](<https://www.php.net>) のマイナーバージョンを基準にしています。

---
title: 利用可能なロケール
description: Laravel-Lang Mona が対応する正規ロケールコードを確認できます。
---

以下のコードは [Artisan](./translations.md) や Laravel のロケール設定で使用します。たとえば、ブラジルポルトガル語をインストールするには `php artisan lang:add pt_BR` を実行します。[設定済みのエイリアス](./configure.md#locale-aliases)を入力に使用できますが、生成されるファイルには正規コードが使われます。

コードから一覧を取得するには [`Locale::values()`](./locales.md#find-supported-and-installed-locales) を使用します。翻訳の収録範囲はパックやロケールによって異なります。

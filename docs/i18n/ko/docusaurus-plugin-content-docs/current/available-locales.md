---
title: 지원 로캘
description: Laravel-Lang Mona가 지원하는 표준 로캘 코드를 확인합니다.
---

아래 코드는 [Artisan](./translations.md) 명령과 Laravel의 로캘 설정에 사용합니다. 예를 들어 브라질 포르투갈어를 설치하려면 `php artisan lang:add pt_BR`을 실행합니다. 입력으로는 [설정한 별칭](./configure.md#locale-aliases)도 사용할 수 있으며, 생성되는 파일에는 표준 코드가 사용됩니다.

코드에서는 [`Locale::values()`](./locales.md#find-supported-and-installed-locales)로 목록을 가져올 수 있습니다. 번역 범위는 팩과 로캘에 따라 다릅니다.

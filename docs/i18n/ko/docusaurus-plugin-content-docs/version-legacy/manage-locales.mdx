:::warning

기본 Laravel에서는 JSON 키에 대체 번역을 <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">사용할 수 없습니다</a>. 예를 들어 대체 언어가 프랑스어일 때 `__('Remember Me')`를 호출하면 `Se souvenir de moi` 대신 `Remember Me`를 반환합니다.

:::

거의 모든 콘솔 명령은 매개변수로 로캘 목록을 받습니다.

다음은 예제입니다.

```bash
php artisan lang:<command> fr de de_AT de_CH vi zh_CN
php artisan lang:<command> fr
php artisan lang:<command>
```

각 인수의 의미는 다음과 같습니다.

- `fr de de_AT de_CH vi zh_CN`은 공백으로 구분한 로캘 목록입니다.
- `fr`처럼 로캘 하나만 지정할 수도 있습니다.
- 호출할 때 매개변수를 생략하면 스크립트가 두 가지 질문을 합니다.
- `Do you want to %s all localizations?`에서 `%s`는 `install`, `remove`, `reset` 중 하나입니다.
- `no`라고 답하면 다음 질문은 `Select localizations to add (specify the necessary localizations separated by commas)`입니다.

:::note

파일 작업(`install`, `uninstall`, `reset`, `update`)을 할 때는 PHP 파일과 JSON 파일을 함께 자동으로 처리합니다. 대상에는 [Laravel Framework](<https://laravel.com>), [Jetstream](<https://jetstream.laravel.com/>), [Fortify](<https://github.com/laravel/fortify>), [Cashier](<https://laravel.com/docs/billing>), [Breeze](<https://github.com/laravel/breeze>), [Nova(Dusk Suite 및 Log Viewer 포함)](<https://nova.laravel.com/>), [Nova](<https://nova.laravel.com/>)의 [Dusk Suite](<https://github.com/laravel/nova-dusk-suite>)와 [Log Viewer](<https://github.com/laravel/nova-log-viewer>), [UI](<https://github.com/laravel/ui>) 번역이 포함됩니다.

:::

## 설치 {/* #installation */}

:::note

애플리케이션 현지화에 필요한 모든 의존성을 빠르게 업데이트할 수 있으므로 Common 패키지 사용을 권장합니다.

[Common 패키지의 호환성 표](<#compatibility> "Common 패키지 호환성 표")를 참조하세요.

:::

[Composer](<https://getcomposer.org>)로 패키지를 설치할 수 있습니다.

```bash
composer require laravel-lang/common:^6.9
```

:::warning

Laravel 10을 사용한다면 설치할 `laravel-lang/lang` 패키지의 버전을 수동으로 지정해야 합니다.

```bash
composer require --dev laravel-lang/lang:^15.39.1:^14.0
```

:::

## 사용법 {/* #usage */}

이제 `lang:update` 콘솔 명령으로 기존 로캘을 [업데이트](<./usage-update-locales.mdx> "Laravel 애플리케이션의 로캘 업데이트")할 수 있습니다.

```bash
php artisan lang:update
```

`composer.json`의 `scripts` 블록에서 `post-update-cmd` 항목에 호출을 추가하는 것도 좋습니다.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

이렇게 하면 의존성을 업데이트한 뒤 `php artisan lang:update` 콘솔 명령을 수동으로 실행할 필요 없이 로캘 파일을 자동으로 갱신합니다.

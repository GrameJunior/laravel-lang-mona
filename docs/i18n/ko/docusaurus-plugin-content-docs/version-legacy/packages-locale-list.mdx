:::tip

이 패키지에는 <strong>Laravel-Lang 팀</strong>의 모든 패키지가 지원하는 로캘 목록이 포함됩니다.

패키지는 열거형 클래스 하나로 구성되어 있으며 애플리케이션에서도 이 클래스를 사용할 수 있습니다.

:::

## 설치 {/* #installation */}

:::note

[Locale List 패키지의 호환성 표](<#compatibility> "Locale List 패키지 호환성 표")를 참조하세요.

:::

설치하려면 다음 콘솔 명령을 실행하세요.

```bash
composer require laravel-lang/locale-list:^1.7.0
```

## 사용법 {/* #usage */}

### 열거형 사용 {/* #as_enum */}

```php
use LaravelLang\LocaleList\Locale;

return Locale::Bengali;
```

<details>
<summary>결과 보기</summary>

```php
 LaravelLang\LocaleList\Locale {
  +name: "Bengali"
  +value: "bn"
}
```

</details>

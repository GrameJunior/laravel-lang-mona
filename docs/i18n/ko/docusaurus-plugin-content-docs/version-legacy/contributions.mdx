<strong>기여를 환영합니다</strong>. 모든 기여의 <strong>작성자를 명시</strong>합니다.

조직의 [모든 프로젝트](<https://github.com/orgs/Laravel-Lang/repositories>)에서 풀 리퀘스트로 기여를 받습니다.

## 파일의 용도 {/* #what_do_the_files_mean */}

- <strong>php.json</strong>에는 PHP 로캘 파일에 들어갈 값의 번역이 있습니다.
- <strong>php-inline.json</strong>에는 PHP 로캘 파일에 들어갈 값의 인라인 번역이 있습니다.
- <strong>json.json</strong>에는 JSON 로캘 파일에 들어갈 값의 번역이 있습니다.
- <strong>json-inline.json</strong>에는 JSON 로캘 파일에 들어갈 값의 인라인 번역이 있습니다.
- <strong>\_excludes.json</strong>에는 영어 원문과 번역이 같은 값이 있습니다. 이 파일에 들어가는 항목은 값입니다. 키를 넣으면 안 됩니다.

## 파일을 수정하는 방법 {/* #how_to_edit_files */}

번역할 수 있는 파일은 모두 확장자가 json이고 `locales` 디렉터리에 있습니다. 원하는 파일을 열고 수정하세요.

:::tip

키에 오류가 있어도 그대로 두세요. 키를 바꾸면 Laravel이 읽지 못합니다.

오타를 고치려면 [Laravel 팀의 해당 프로젝트](<https://github.com/orgs/laravel/repositories>)에 풀 리퀘스트를 보내세요.

수정 후에는 우리의 패키지가 하루에 한 번 자동으로 키를 갱신합니다.

:::

1. 로캘 파일을 엽니다.
1. 키의 값을 바꿉니다.
1. 커밋을 만들고 푸시합니다.
1. 변경한 로캘 코드를 명시해 풀 리퀘스트를 만듭니다. 아래는 예제입니다.

   :::tip

   \[fr\]: Added new localization

   :::

:::tip

`inline` 접미사가 있는 파일의 문구는 현재 속성(`:attribute`)을 참조하면 안 됩니다.

인라인 번역은 다음 예시처럼 지칭 방식이 다릅니다.

```text
// 일반 번역
The :attribute must contain at least one letter.

// 인라인 번역
This field must contain at least one letter.
```

:::

## 새 로캘을 추가하는 방법 {/* #how_to_add_a_new_locale */}

### Laravel Lang 프로젝트 {/* #for_laravel_lang_projects */}

보통 각 프로젝트에 지원 로캘이 포함되어 있습니다. 로캘 추가를 제안하려면 [토론에 남겨주세요](<https://github.com/orgs/Laravel-Lang/discussions/new?category=ideas&title=I%20want%20to%20add%20a%20new%20localization>).

### 서드 파티 프로젝트 {/* #for_third_party_projects */}

:::tip

`laravel-lang/locale-list`에 없는 로캘을 추가하려면 [토론에 남겨주세요](<https://github.com/orgs/Laravel-Lang/discussions/new?category=ideas&title=I%20want%20to%20add%20a%20new%20localization>).

:::

`laravel-lang/status-generator` 패키지가 설치되어 있는지 확인하고 다음 콘솔 명령을 실행하세요.

```bash
vendor/bin/lang create <locale>
# vendor/bin/lang create fr
```

누락된 로캘을 모두 설치하려면 로캘 코드를 생략하고 실행하세요.

```bash
vendor/bin/lang create
```

## 코드 스타일 {/* #code_style */}

Laravel-Lang 팀은 [PER](<https://www.php-fig.org/per/coding-style/>) 코딩 표준과 [PSR-4](<https://www.php-fig.org/psr/psr-4/>) 오토로딩 표준을 따릅니다.

코드 스타일에 맞춰 서식을 정리하려면 다음 콘솔 명령을 실행하세요.

```bash
composer style
```

## 풀 리퀘스트 제목 {/* #pr_title */}

풀 리퀘스트 제목은 다음 형식을 따라야 합니다.

```bash
[locale]: Description
```

다음은 예제입니다.

```bash
[fr]: Added new localization
```

제목이 정해진 형식과 일치하는지는 정규식으로 검사합니다.

```bash
/^(Draft:\s)?\[[a-zA-Z,_\s]+\]:\s.+$/
```

## 행동 강령 {/* #code_of_conduct */}

Laravel의 행동 강령은 [기여자 규약](<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>)에서 파생되었습니다. 행동 강령 위반은 [Andrey Helldar 또는 Fred Delrieu](<mailto:helldar@dragon-code.pro;caouecs@caouecs.net>)에게 신고할 수 있습니다.

- 참여자는 다른 의견을 존중합니다.
- 참여자는 말과 행동에서 인신공격과 타인을 비하하는 발언을 삼가야 합니다.
- 참여자는 다른 사람의 말과 행동을 해석할 때 항상 선의를 전제로 해야 합니다.
- 합리적으로 괴롭힘이라고 판단할 수 있는 행동은 용납하지 않습니다.

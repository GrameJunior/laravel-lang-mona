:::tip

이 패키지에는 스타터 키트 인터페이스의 번역이 포함됩니다.

따라서 인터페이스도 쉽게 현지화할 수 있습니다.

:::

## 설치 {/* #installation */}

:::note

[Starter Kits 패키지의 호환성 표](<#compatibility> "Starter Kits 패키지 호환성 표")를 참조하세요.

:::

설치하려면 다음 콘솔 명령을 실행하세요.

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## 사용법 {/* #usage */}

:::note

[Laravel 스타터 키트](<https://laravel.com/starter-kits>)의 번역 키를 정상적으로 게시하려면 `composer.json` 파일의 `name` 키에 있는 애플리케이션 이름을 바꾸지 마세요. 이름을 바꾸면 스타터 키트 번역이 설치되지 않습니다.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

이제 `lang:update` 콘솔 명령으로 기존 로캘을 [업데이트](<./usage-update-locales.mdx> "Laravel 애플리케이션의 로캘 업데이트")할 수 있습니다.

```bash
php artisan lang:update
```

`composer.json`의 `scripts` 블록에서 `post-update-cmd` 항목에 호출을 추가하는 것도 좋습니다.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

이렇게 하면 의존성을 업데이트한 뒤 `php artisan lang:update` 콘솔 명령을 수동으로 실행할 필요 없이 로캘 파일을 자동으로 갱신합니다.

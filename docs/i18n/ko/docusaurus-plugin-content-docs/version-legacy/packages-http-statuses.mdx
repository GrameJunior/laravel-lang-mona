:::tip

이 패키지는 일반적인 HTTP 상태의 번역을 포함하며, 각 문구를 해당 숫자 코드와 연결합니다.

따라서 상태 문구도 쉽게 현지화할 수 있습니다.

:::

## 설치 {/* #installation */}

:::note

[HTTP Statuses 패키지의 호환성 표](<#compatibility> "HTTP Statuses 패키지 호환성 표")를 참조하세요.

:::

설치하려면 다음 콘솔 명령을 실행하세요.

```bash
composer require --dev laravel-lang/http-statuses:^3.13.2
```

## 사용법 {/* #usage */}

이제 `lang:update` 콘솔 명령으로 기존 로캘을 [업데이트](<./usage-update-locales.mdx> "Laravel 애플리케이션의 로캘 업데이트")할 수 있습니다.

```bash
php artisan lang:update
```

`composer.json`의 `scripts` 블록에서 `post-update-cmd` 항목에 호출을 추가하는 것도 좋습니다.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

이렇게 하면 의존성을 업데이트한 뒤 `php artisan lang:update` 콘솔 명령을 수동으로 실행할 필요 없이 로캘 파일을 자동으로 갱신합니다.

## 의존성 업데이트 {/* #updating_dependencies */}

:::note

`laravel-lang/common` 패키지를 사용한다면 이 단계를 건너뛰세요.

:::

애플리케이션의 `composer.json`에서 다음 의존성을 업데이트하세요.

- `laravel-lang/publisher`를 `^16.0`으로 변경

이어서 다음 콘솔 명령으로 의존성을 업데이트하세요.

```bash
composer update
```

## 로캘 네임스페이스 변경하기 {/* #change_namespace */}

아래 로캘 네임스페이스를 바꾸세요.

```php
LaravelLang\Locales\Enums\Locale
```

대체할 값은 다음과 같습니다.

```php
LaravelLang\LocaleList\Locale
```

다음은 예제입니다.

```php
// 변경 전
LaravelLang\Locales\Enums\Locale::Afrikaans; // af

// 변경 후
LaravelLang\LocaleList\Locale::Afrikaans; // af
```

## 버전 관리 방식 {/* #versioning_scheme */}

모든 패키지는 [시맨틱 버전 관리](<https://semver.org>)를 따릅니다. 하위 호환성을 깨는 기능을 추가하거나 Laravel 또는 다른 공식 패키지의 [사용 중단된 버전](<https://laravel.com/docs/releases>)에 대한 지원을 종료할 때 메이저 버전을 릴리스합니다. 마이너 및 패치 릴리스에는 호환성이 깨지는 변경 사항을 포함하면 안 됩니다.

## 지원 정책 {/* #support_policy */}

모든 Lang 프로젝트는 [Laravel 지원 정책](<https://laravel.com/docs/releases#support-policy>)을 따릅니다.

`Lang` 프로젝트 패키지에는 프로젝트 보안에 영향을 주는 코드가 없을 것으로 예상합니다. 따라서 Laravel 프로젝트의 [예정된 유지보수 종료일](<https://laravel.com/docs/releases#support-policy>)과 [PHP](<https://www.php.net>) 마이너 버전을 기준으로 합니다.

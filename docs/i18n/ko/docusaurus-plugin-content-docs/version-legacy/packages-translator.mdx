:::warning

`Translator` 프로젝트는 현재 <strong>알파</strong> 테스트 단계입니다.

안정 버전이 릴리스되기 전에는 운영 환경에서 사용하지 않는 것이 좋습니다.

:::

## 설치 {/* #installation */}

:::note

[Models 패키지의 호환성 표](<#compatibility> "Models 패키지 호환성 표")를 참조하세요.

:::

설치하려면 다음 콘솔 명령을 실행하세요.

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

`config/localization.php` 파일을 편집하여 기본 설정을 [변경](<./configuration.mdx#translator>)할 수도 있습니다.

## 사용법 {/* #usage */}

:::tip

필요한 경우 `config/localization.php` 설정 파일에 제공업체의 인증 정보를 지정하세요. 인증 정보가 없으면 유료 서비스가 정상적으로 작동하지 않습니다.

:::

### 순차 번역 {/* #cyclical_translation */}

모든 API 서비스가 필요한 언어를 지원하는 것은 아닙니다. 여러 서비스를 순서대로 시도해 한 번의 호출로 텍스트를 번역할 수 있는 서비스를 찾습니다.

다음은 설정 예제입니다.

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

설정에서 Google 번역과 DeepL 번역을 활성화하고 Yandex.Translate는 비활성화했습니다. `enabled` 매개변수는 순차 번역에만 적용됩니다.

Google 번역은 프랑스어로만, DeepL 번역은 독일어로만 번역할 수 있다고 가정하면 세 가지 경우가 있습니다.

#### 파사드 사용 {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### 의존성 주입 사용 {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### 직접 번역 {/* #direct_translate */}

#### Google 번역 사용 {/* #via_google */}

:::note

[Google 번역](<https://translate.google.com>)으로 텍스트를 직접 번역하면 `enabled` 설정을 무시합니다.

:::

직접 번역하려면 `LaravelLang\Translator\Facades\Translate` 파사드를 사용하거나 `LaravelLang\Translator\Services\Translate` 서비스 클래스를 의존성 주입으로 연결합니다.

<Tabs>

<TabItem value="tab-1" label={"파사드 사용"}>

```php

use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// 문자열을 반환합니다.

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// 배열을 반환합니다.

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// 배열을 반환합니다.

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// 배열을 반환합니다.
```

</TabItem>

## 설치 {/* #installation */}

:::note

[JSON Fallback 패키지의 호환성 표](<#compatibility> "JSON Fallback 패키지 호환성 표")를 참조하세요.

:::

기본 Laravel에서는 JSON 키에 대체 번역을 <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">사용할 수 없습니다</a>. 예를 들어 대체 언어가 프랑스어일 때 `__('Remember Me')`를 호출하면 `Se souvenir de moi` 대신 `Remember Me`를 반환합니다.

설치하려면 다음 콘솔 명령을 실행하세요.

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## 사용법 {/* #usage */}

:::note

Laravel 11에서는 `config/app.php` 설정 파일에 `providers` 항목이 없습니다. 수동으로 추가할 수 있습니다.

:::

설치한 뒤 `config/app.php` 설정 파일의 `providers` 항목에서 서비스 프로바이더를 등록하세요.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // 다른 서비스 프로바이더
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

이제 JSON 키는 선택한 로캘의 값을 반환합니다.

파일을 업데이트하려면 다음 콘솔 명령을 실행하세요.

```bash
php artisan lang:update
```

이 명령만 실행하면 됩니다. 🙂

이 콘솔 명령은 애플리케이션에 설치된 로캘을 찾아 해당 파일을 갱신합니다.

:::tip

드물지만 일부 Laravel 마이너 버전에서 저장소의 키를 제거하여 애플리케이션에서도 해당 키가 사라질 수 있습니다.

업데이트 명령은 새 번역 문구를 추가하거나 기존 번역을 갱신합니다. 더 이상 쓰지 않는 문구를 제거하려면 [`php artisan lang:reset`](<./usage-reset-locales.mdx> "Laravel 애플리케이션의 로캘 초기화") 명령을 사용하세요.

:::

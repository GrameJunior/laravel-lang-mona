## 설치 {/* #installation */}

:::note

[Native Currency Names 패키지의 호환성 표](<#compatibility> "Native Currency Names 패키지 호환성 표")를 참조하세요.

:::

설치하려면 다음 콘솔 명령을 실행하세요.

```bash
composer require laravel-lang/native-currency-names:^1.11.0
```

## 사용법 {/* #usage */}

### 현지화된 이름 {/* #localized_names */}

```php
use LaravelLang\NativeCurrencyNames\CurrencyNames;
use LaravelLang\LocaleList\Locale;

return CurrencyNames::get('bn');
// 또는
return CurrencyNames::get(Locale::Bengali);
```

### 고유 이름 {/* #native_names */}

인수를 전달하지 않고 `get` 메서드를 호출하여 현지화된 이름 목록을 얻을 수도 있습니다. 잘못된 값이나 빈 값을 전달할 때도 같은 동작을 합니다.

```php
use LaravelLang\NativeCurrencyNames\CurrencyNames;

return CurrencyNames::get();
// 또는
return CurrencyNames::get('');
// 또는
return CurrencyNames::get(null);
// 또는
return CurrencyNames::get('foo');
```

### 정렬 {/* #sorting */}

결과를 키나 값으로 정렬하려면 열거형 매개변수에 `SortBy`를 전달하세요.

기본적으로 값으로 정렬합니다.

#### 키로 정렬 {/* #sort_by_keys */}

```php
use LaravelLang\NativeCurrencyNames\CurrencyNames;
use LaravelLang\NativeCurrencyNames\Enums\SortByy;

return CurrencyNames::get('en', SortBy::Key);
```

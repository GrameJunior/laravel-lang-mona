## 설치 {/* #installation */}

:::note

[Models 패키지의 호환성 표](<#compatibility> "Models 패키지 호환성 표")를 참조하세요.

:::

설치하려면 다음 콘솔 명령을 실행하세요.

```bash
composer require laravel-lang/models:^1.8.0
```

`config/localization.php` 파일을 편집하여 기본 설정을 [변경](<./configuration.mdx#models>)할 수도 있습니다.

## 콘솔 명령 {/* #console_commands */}

### 번역 모델 만들기 {/* #create_translation_model */}

저장소는 대량의 데이터를 서로 섞이지 않게 저장하도록 설계되었습니다. 따라서 번역이 필요한 모델마다 별도의 번역 모델을 만듭니다.

저장소를 만드는 가장 쉬운 방법은 `make:model-translation` 콘솔 명령을 사용하는 것입니다.

```bash
php artisan make:model-translation
```

실행하면 원본 모델을 묻고, 모델이 없으면 생성합니다. 이어서 생성할 열을 묻습니다. 예를 들어 "title", "description" 등을 입력할 수 있습니다.

열을 너무 많이 추가했거나 하나도 추가하지 않았어도 괜찮습니다. 콘솔 명령이 생성한 모델 파일과 마이그레이션에서 필요한 변경을 할 수 있습니다.

생성한 저장소 모델은 항상 상위 모델과 같은 디렉터리에 있어야 합니다. 다음은 예제입니다.

```text
App\Models\Content\News
App\Models\Content\NewsTranslation
App\Models\Products\Category
App\Models\Products\CategoryTranslation
```

:::tip

기본 접미사는 `Translation`입니다. [config/localization.php](<./configuration.mdx#models>) 설정 파일의 `models` 항목에서 원하는 접미사로 바꿀 수 있습니다.

:::

이후에는 콘솔 명령으로 마이그레이션만 실행하면 됩니다.

```bash
php artisan migrate
```

### 모델 설정 {/* #model_setup */}

번역 저장소를 만든 뒤 기본 모델에 `LaravelLang\Models\HasTranslations` 트레이트를 적용하세요.

다음은 예제입니다.

```php
use Illuminate\Database\Eloquent\Model;
use LaravelLang\Models\HasTranslations;

class Article extends Model
{
    use HasTranslations;
}
```

기본 모델에 번역에 사용하는 물리적 필드나 가상 필드가 없는지도 확인하세요.

다음은 예제입니다.

```php
use Illuminate\Database\Eloquent\Model;
use LaravelLang\Models\HasTranslations;

class Article extends Model
{
    use HasTranslations;

    protected $fillable = [
        'category_id',

        // 제거 대상
        'title',
        'description',
    ];
}
```

### IDE 헬퍼 {/* #ide_helpers */}

:::tip

`php artisan make:model-translation` 콘솔 명령은 저장소를 만들 때 헬퍼 파일도 자동으로 생성하므로 별도 명령이 필요하지 않습니다.

번역 저장소 모델을 변경했다면 이 명령을 다시 실행하는 것이 좋습니다.

:::

IDE가 번역 가능한 필드를 처리할 수 있도록 다음 콘솔 명령 실행을 권장합니다.

```bash
php artisan lang:models-helper
```

### 번역 가져오기 {/* #get_translation */}

:::tip

모든 저장소는 [즉시 로딩](<https://laravel.com/docs/eloquent-relationships#eager-loading>) 플래그를 상위 모델에 자동으로 전달하므로 수동으로 설정할 필요가 없습니다.

이 관계에는 기본적으로 현재 로캘과 대체 로캘의 레코드만 포함됩니다. 필요한 경우 [필터 설정](<./configuration.mdx#models>)을 변경해 모두 불러올 수 있습니다.

```php
// config/localization.php
config(['localization.models.filter.enabled' => false]);
```

```ini
; .env
LOCALIZATION_FILTER_ENABLED=false
```

이 경우 항목에서 사용할 수 있는 로캘을 모두 불러옵니다.

:::

현재 로캘의 속성값을 가져오려면 모델의 속성을 읽으세요. 다음은 예제입니다.

```php
use App\Models\Article;

$page = Article::first();

$page->title;
```

<abbr title={"config/app.php 파일의 app.locale에 설정된 값입니다."}>기본 로캘</abbr>의 값이 없으면 이 메서드는 <abbr title={"config/app.php 파일의 app.fallback_locale에 설정된 값입니다."}>대체 로캘</abbr>의 값을 반환합니다.

`getTranslation` 메서드를 사용할 수도 있습니다.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title');
```

특정 로캘의 값은 두 번째 인수로 로캘 코드를 전달해 가져옵니다. 다음은 예제입니다.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title', 'fr');
// 또는
$page->getTranslation('title', Locale::French);
```

:::tip

모델의 변경 사항을 데이터베이스에 저장하지 않았어도 이 메서드는 변경한 값을 반환합니다.

:::

### 번역 설정하기 {/* #set_translations */}

#### 단일 값 {/* #single_value */}

애플리케이션의 현재 로캘에 번역을 추가하거나 갱신하려면 모델 속성에 값을 할당하세요. 다음은 예제입니다.

```php
use App\Models\Article;

$page = Article::first();

$page->title = 'New value';
```

`setTranslation`으로 새 값을 설정할 수도 있습니다.

```php
use App\Models\Article;

$page = Article::first();

$page->setTranslation('title', 'New value');
```

이 메서드는 현재 로캘에 새 값을 설정합니다. 특정 로캘의 값은 세 번째 매개변수에 해당 코드를 전달해 설정하세요. 다음은 예제입니다.

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->setTranslation('title', 'New value', 'fr');
// 또는
$page->setTranslation('title', 'New value', Locale::French);
```

대량 할당도 사용할 수 있습니다.

```php
use App\Models\Article;

$page = Article::first();

$page->fill([
    'title' => 'New value',
]);
```

:::note

이 메서드를 호출하면 새 값은 모델 객체에만 저장됩니다. 데이터베이스에 반영하려면 상위 모델에서 `save`를 호출하세요. 다음은 예제입니다.

```php
$page->save();
```

:::

모델을 생성할 때 값을 채울 수도 있습니다. 다음은 예제입니다.

```php
use App\Models\Article;

$page = Article::first();

Article::create([
    'title' => 'New value',
]);
```

#### 여러 값 {/* #plural_value */}

여러 로캘의 번역으로 속성을 빠르게 채우려면 다음 방법 중 하나를 사용하세요.

```php
use App\Models\Article;
use Illuminate\Database\Eloquent\Model;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Models\HasTranslations;

/** @var Model|HasTranslations $post */
$post = Article::first();

$titles = [
    'fr' => 'Mettre à jour & continuer à éditer',
    'en' => 'Update & Continue Editing',
    'de' => 'Aktualisieren & Weiterbearbeiten',
];

$descriptions = collect([
    Locale::French->value => 'Met à jour les informations et continue d\'éditer le message',
    Locale::German->value => 'Aktualisiert die Informationen und bearbeitet den Beitrag weiter',
]);

// 방법 1
foreach ($titles as $locale => $value) {
    $post->setTranslation('title', $value, $locale);
}

foreach ($descriptions as $locale => $value) {
    $post->setTranslation('description', $value, $locale);
}

// 방법 2
$post->setTranslations('title', $titles);
$post->setTranslations('description', $descriptions);
```

대량 할당에 `iterable` 객체를 사용할 수도 있습니다. 다음은 예제입니다.

```php
$post->fill([
    'title'       => $titles,
    'description' => $descriptions,
]);

Article::create([
    'title'       => $titles,
    'description' => $descriptions,
]);
```

필드마다 같은 로캘을 지정할 필요는 없습니다. 위 예에서는 `title`에 프랑스어, 영어, 독일어 값을 설정하고, `description`에는 프랑스어와 독일어 값만 설정합니다.

### 번역 삭제하기 {/* #forget_translation */}

:::warning

[추가 및 갱신](<#set_translations>) 메서드와 달리 `forgetTranslation`과 `forgetAllTranslations`는 번역 모델의 `delete`를 호출해 데이터베이스에 즉시 반영합니다.

번역 모델에는 [SoftDeletes](<https://laravel.com/docs/eloquent#soft-deleting>) 트레이트가 기본적으로 없으므로 데이터는 즉시 삭제됩니다. 필요하면 모델 클래스와 마이그레이션 파일에 직접 추가할 수 있습니다.

:::

```php
use App\Models\Article;

$page = Article::first();

$page->forgetTranslation('fr');
// 또는
$page->forgetTranslation(Locale::French);
```

`forgetAllTranslations`를 호출해 모든 로캘의 번역을 한꺼번에 삭제할 수도 있습니다.

```php
use App\Models\Article;

$page = Article::first();

$page->forgetAllTranslations();
```

### 번역 여부 확인하기 {/* #has_translated */}

열에 번역이 있는지 확인하는 방법은 여러 가지입니다. 첫 번째 방법은 `hasTranslated`에 열 이름을 전달하는 것입니다.

```php
use App\Models\Article;

$page = Article::first();

$page->hasTranslated('title');
```

이 메서드는 <abbr title={"config/app.php 파일의 app.locale에 설정된 값입니다."}>기본</abbr> 및 <abbr title={"config/app.php 파일의 app.fallback_locale에 설정된 값입니다."}>대체</abbr> 로캘을 모두 확인합니다. 하나라도 값이 채워져 있으면 `true`, 둘 다 비어 있으면 `false`를 반환합니다.

:::note

저장된 불리언 값(`true / false`)과 숫자 값(`0, 0.0`)도 채워진 것으로 간주하여 `true`를 반환합니다.

:::

특정 로캘에서 값이 있는지 확인하려면 두 번째 인수로 로캘 코드를 전달하세요. 다음은 예제입니다.

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->hasTranslated('title', 'fr');
// 또는
$page->hasTranslated('title', Locale::French);
```

### 번역 가능 여부 확인하기 {/* #is_translatable */}

`isTranslatable` 메서드는 번역 모델의 `$fillable` 속성에 필드가 포함되어 있는지 확인합니다.

다음은 예제입니다.

```php
use Illuminate\Database\Eloquent\Model;
use LaravelLang\Models\Eloquent\Translation;
use LaravelLang\Models\HasTranslations;

class Article extends Model
{
    use HasTranslations;
}

class ArticleTranslation extends Translation
{
    protected $fillable = [
        'title',
    ];
}

$page = Article::first();

$page->isTranslatable('title'); // true
$page->isTranslatable('description'); // false
```

### 기본 모델 삭제하기 {/* #delete_base_model */}

기본적으로 번역 모델은 상위 모델을 참조하는 외래 키를 포함합니다. 따라서 [SoftDeletes](<https://laravel.com/docs/eloquent#soft-deleting>) 트레이트로 상위 모델을 소프트 삭제하면 번역이 모두 남지만, `forceDelete`를 호출하면 데이터베이스에서 번역도 자동으로 삭제됩니다.

```php
use App\Models\Article;

$page = Article::first();

$page->delete();
// 또는
$page->forceDelete();
```

## 이벤트 {/* #events */}

특정 작업을 수행하면 아래 이벤트가 발생합니다.

```php
use LaravelLang\Models\Events\AllTranslationsHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenSetEvent;

AllTranslationsHasBeenForgetEvent::dispatch($model);
TranslationHasBeenForgetEvent::dispatch($model, $locale);
TranslationHasBeenSetEvent::dispatch($model, $column, $locale, $oldValue, $newValue);
```

필요하면 이 이벤트를 수신할 수 있습니다. 다음은 예제입니다.

```php
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\ServiceProvider;
use LaravelLang\Models\Events\AllTranslationsHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenForgetEvent;
use LaravelLang\Models\Events\TranslationHasBeenSetEvent;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Event::listen(static function (AllTranslationsHasBeenForgetEvent $event) {
            Log::info('Forget all locales', [
                'model' => $event->model->getKey(),
            ]);
        });

        Event::listen(static function (TranslationHasBeenForgetEvent $event) {
            Log::info('Forget locale', [
                'model'  => $event->model->getKey(),
                'locale' => $event->locale?->value,
            ]);
        });

        Event::listen(static function (TranslationHasBeenSetEvent $event) {
            Log::info('Set new translation', [
                'model'  => $event->model->getKey(),
                'locale' => $event->locale?->value,
                'column' => $event->column,

                'old' => $event->oldValue,
                'new' => $event->newValue,
            ]);
        });
    }
}
```

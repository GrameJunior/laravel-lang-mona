---
title: Доступные локали
description: Канонические коды локалей, поддерживаемые Laravel-Lang Mona.
---

Используйте коды ниже в [Artisan](./translations.md) и в настройках локали Laravel. Например, выполните `php artisan lang:add pt_BR`, чтобы установить переводы для бразильского португальского. При вводе можно использовать [настроенный алиас](./configure.md#locale-aliases), а сгенерированные файлы используют канонический код.

Список доступен в коде через [`Locale::values()`](./locales.md#find-supported-and-installed-locales). Полнота перевода зависит от пакета и локали.

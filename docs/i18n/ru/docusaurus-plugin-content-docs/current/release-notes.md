## Версионирование и совместимость {#versioning-and-compatibility}

Laravel-Lang следует правилам семантического версионирования. Несовместимые изменения и прекращение поддержки платформ приурочены к мажорным выпускам. Официальные пакеты выпускаются под общей версией. [Семантическое версионирование](https://semver.org/)

Текущий выпуск требует PHP `^8.3` и поддерживает Laravel 12 и 13. Для вашей версии Laravel может требоваться более новая версия PHP. Для зависимостей Common также нужны расширения `intl` и `json`.

Теги выпусков и описания исправлений доступны в разделе [Выпуски Mona](https://github.com/Laravel-Lang/mona/releases). Сроки поддержки Laravel приведены в [политике поддержки Laravel](https://laravel.com/docs/releases#support-policy).

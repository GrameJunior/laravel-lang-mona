## Установка {/* #installation */}

:::note

См. [таблицу совместимости](<#compatibility> "Таблица совместимости пакета Attributes").

:::

Для установки выполните команду:

```bash
composer require --dev laravel-lang/attributes:^2.16.5
```

## Использование {/* #usage */}

Теперь можно [обновить](<./usage-update-locales.mdx> "Обновление локалей в приложении Laravel") существующие локали командой `lang:update`:

```bash
php artisan lang:update
```

Добавьте вызов в раздел `post-update-cmd` в блоке `scripts` файла `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Так файлы локализаций будут обновляться автоматически после обновления зависимостей, и запускать `php artisan lang:update` вручную не придётся.

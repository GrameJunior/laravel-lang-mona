## Установка {/* #installation */}

:::note

См. [таблицу совместимости](<#compatibility> "Таблица совместимости пакета Models").

:::

Для установки выполните команду:

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Также можно [переопределить](<./configuration.mdx#translator>) настройки по умолчанию в файле `config/localization.php`.

## Использование {/* #usage */}

:::tip

При необходимости укажите данные авторизации поставщиков в файле `config/localization.php`. Без них платные сервисы могут не работать.

:::

### Последовательный перебор переводчиков {/* #cyclical_translation */}

Сервисы перевода поддерживают разные наборы локалей. Перебор позволяет выбрать сервис, который может перевести текст одним вызовом.

Пример настроек:

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

В настройках включены Google Translate и DeepL Translate, а Yandex.Translate выключен. Параметр `enabled` применяется только при последовательном переборе.

Допустим, Google Translate поддерживает только французский, а DeepL Translate — только немецкий. Тогда возможны три сценария:

<TabItem value="tab-1" label={"На французский"}>

<span id={"procedure-tif"} />

1. Проверяем, может ли Google Translate перевести на этот язык. Может.

Возвращаем перевод из Google Translate.

</TabItem>

<TabItem value="tab-2" label={"На немецкий"}>

<span id={"procedure-tig"} />

1. Проверяем, может ли Google Translate перевести на этот язык. Не может, переходим к следующему сервису.

Возвращаем перевод из DeepL Translate.

</TabItem>

<TabItem value="tab-3" label={"На неподдерживаемый язык"}>

<span id={"procedure-tiu"} />

1. Проверяем, может ли Google Translate перевести на этот язык. Не может, переходим к следующему сервису.
1. Проверяем, может ли DeepL Translate перевести на этот язык. Не может, переходим к следующему сервису.

Возвращаем исходный текст без перевода.

</TabItem>

#### Через фасад {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Через внедрение зависимостей {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Прямой перевод {/* #direct_translate */}

#### Через Google Translate {/* #via_google */}

:::note

При прямом переводе через [Google Translate](<https://translate.google.com>) параметр `enabled` игнорируется.

:::

Для прямого перевода используйте фасад `LaravelLang\Translator\Facades\Translate` или внедрите сервис `LaravelLang\Translator\Services\Translate` через DI.

<Tabs>

<TabItem value="tab-1" label={"Через фасад"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// Возвращает строку

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// Возвращает массив

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// Возвращает массив

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// Возвращает массив
```

</TabItem>

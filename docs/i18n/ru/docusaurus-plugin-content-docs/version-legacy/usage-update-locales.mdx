Чтобы обновить файлы, выполните команду:

```bash
php artisan lang:update
```

На этом всё 🙂

Команда определяет установленные в приложении локали и обновляет файлы.

:::tip

В некоторых минорных версиях Laravel из репозиториев могут удаляться ключи. В результате они исчезают из приложения. Такое случается редко.

Команда обновления локалей только добавляет новые или обновляет существующие переводы. Чтобы удалить неиспользуемые фразы, выполните команду [`php artisan lang:reset`](<./usage-reset-locales.mdx> "Сброс локалей приложения Laravel").

:::

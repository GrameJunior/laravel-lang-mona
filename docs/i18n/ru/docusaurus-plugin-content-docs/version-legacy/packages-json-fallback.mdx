## Установка {/* #installation */}

:::note

См. [таблицу совместимости](<#compatibility> "Таблица совместимости пакета JSON Fallback").

:::

По умолчанию Laravel <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">не поддерживает</a> резервный поиск переводов для JSON-ключей. Например, при вызове `__('Remember Me')` вы получите `Remember Me` вместо `Se souvenir de moi` для резервной французской локали.

Для установки выполните команду:

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Использование {/* #usage */}

:::note

В Laravel 11 файл `config/app.php` не содержит секции `providers`. Её можно добавить вручную.

:::

После установки добавьте ссылку на сервис-провайдера в секцию `providers` файла `config/app.php`:

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // Другие сервис-провайдеры
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Теперь JSON-ключи будут возвращать значения для выбранной локали.

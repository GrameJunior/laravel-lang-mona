## Правила версионирования {/* #versioning_scheme */}

Все наши пакеты следуют правилам [семантического версионирования](<https://semver.org>). Мажорная версия проекта выпускается, когда новая функциональность нарушает обратную совместимость или прекращается поддержка [устаревших версий](<https://laravel.com/docs/releases>) Laravel или других его официальных пакетов. Минорные релизы и исправления никогда не должны содержать несовместимых изменений.

## Политика поддержки {/* #support_policy */}

Для всех проектов Lang мы следуем [политике поддержки Laravel](<https://laravel.com/docs/releases#support-policy>).

Поскольку пакеты проекта `Lang` не должны содержать код, влияющий на безопасность проекта, мы ориентируемся на [запланированные даты окончания сопровождения](<https://laravel.com/docs/releases#support-policy>) проектов Laravel и минорных версий [PHP](<https://www.php.net>).

## Установка {/* #installation */}

:::note

См. [таблицу совместимости](<#compatibility> "Таблица совместимости пакета Starter Kits").

:::

Для установки выполните команду:

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## Использование {/* #usage */}

:::note

Для публикации переводов [стартовых наборов Laravel](<https://laravel.com/starter-kits>) сохраните имя приложения, указанное в ключе `name` файла `composer.json`. При изменённом имени эти переводы не будут установлены.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

Теперь можно [обновить](<./usage-update-locales.mdx> "Обновление локалей в приложении Laravel") существующие локали командой `lang:update`:

```bash
php artisan lang:update
```

Добавьте вызов в раздел `post-update-cmd` в блоке `scripts` файла `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Так файлы локализаций будут обновляться автоматически после обновления зависимостей, и запускать `php artisan lang:update` вручную не придётся.

## Установка {/* #installation */}

:::note

См. [таблицу совместимости](<#compatibility> "Таблица совместимости пакета Routes").

:::

Для установки выполните команду:

```bash
composer require laravel-lang/routes:^1.11.0
```

Также можно [переопределить](<./configuration.mdx#routes>) настройки по умолчанию в файле `config/localization.php`.

:::note

Полная поддержка [кеширования маршрутов](<https://laravel.com/docs/routing#route-caching>).

```bash
php artisan route:cache
```

:::

## Использование {/* #usage */}

В коротком видео показано, как установить и использовать [Routes](<./packages-routes.mdx#usage> "Использование пакета Routes") и [Models](<./packages-models.mdx#usage> "Использование пакета Models") в одном приложении ([смотреть на YouTube](<https://youtu.be/mH76pGbpVu0>)):

<iframe className="legacy-video" src="https://www.youtube-nocookie.com/embed/mH76pGbpVu0" title={"Маршруты и модели"} loading="lazy" allowFullScreen />

Допустим, в приложении установлены две локали: французская и немецкая.

Настройки приложения будут выглядеть так:

```php
// config/app.php
use LaravelLang\LocaleList\Locale;

return [
    'locale' => Locale::French->value,

    'fallback_locale' => Locale::German->value,
];
```

Также мы задали переводы для французской и немецкой локалей:

```json
{
    "Foo": "Toutes les données ont été chargées."
}
```

```json
{
    "Foo": "Alle Ressourcen geladen."
}
```

### Прямое подключение {/* #direct */}

Можно сослаться на класс промежуточного ПО без добавления псевдонима:

```php
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('some/{locale}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByParameterWithRedirect::class)
    ->get('some/{locale?}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByHeader::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByCookie::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationBySession::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('some', fn () => view('welcome'));
```

### Псевдонимы {/* #aliases */}

Чтобы использовать псевдонимы промежуточного ПО, зарегистрируйте их в приложении:

<Tabs>

<TabItem value="tab-1" label={"Laravel 11"}>

```php
// bootstrap/app.php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Middleware;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'localization.parameter' => LocalizationByParameter::class,
            'localization.redirect'  => LocalizationByParameterWithRedirect::class,
            'localization.header'    => LocalizationByHeader::class,
            'localization.cookie'    => LocalizationByCookie::class,
            'localization.session'   => LocalizationBySession::class,
            'localization.model'     => LocalizationByModel::class,
        ]);
    });
```

</TabItem>

<TabItem value="tab-2" label={"Laravel 10"}>

```php
// app/Http/Kernel.php

use Illuminate\Foundation\Http\Kernel as HttpKernel;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

class Kernel extends HttpKernel
{
    protected $middlewareAliases = [
        // ...

        'localization.parameter' => LocalizationByParameter::class,
        'localization.redirect'  => LocalizationByParameterWithRedirect::class,
        'localization.header'    => LocalizationByHeader::class,
        'localization.cookie'    => LocalizationByCookie::class,
        'localization.session'   => LocalizationBySession::class,
        'localization.model'     => LocalizationByModel::class,
    ];
}
```

</TabItem>

</Tabs>

Затем можно указать псевдонимы в методе маршрута `middleware`:

```php
app('router')
    ->middleware('localization.parameter')
    ->get('some/{locale}', fn () => view('welcome'));

app('router')
    ->middleware('localization.redirect')
    ->get('some/{locale?}', fn () => view('welcome'));

app('router')
    ->middleware('localization.header')
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware('localization.cookie')
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware('localization.session')
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware('localization.model')
    ->get('some', fn () => view('welcome'));
```

### Через параметр URL {/* #via_url_parameter */}

:::tip

Для начала укажите параметр `{locale}` в любом месте URL маршрутов.

Имя параметра можно изменить в разделе `routes` файла `config/localization.php`.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByParameter;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('foo/{locale}/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Если передали неверную или неустановленную локаль, страница отобразится на основной локали приложения.

### Через модель {/* #via_model */}

:::tip

Выбирает локаль по столбцу <abbr title={"Имя можно изменить в разделе \"routes\" файла \"config/localization.php\"."}>locale</abbr>.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Так можно выбрать локаль для любого аутентифицированного пользователя. Убедитесь, что его модель содержит атрибут <abbr title={"Имя можно изменить в разделе \"routes\" файла \"config/localization.php\"."}>"locale"</abbr>.

Если этого столбца нет в таблице пользователей, добавьте его при необходимости или создайте динамический метод в классе модели.

Пример:

```php
use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Foundation\Auth\User as Authenticatable;
use LaravelLang\LocaleList\Locale;

class User extends Authenticatable
{
    protected function locale(): Attribute
    {
        return Attribute::make(
            get: fn () => Locale::French
        );
    }
}
```

Теперь после аутентификации через промежуточное ПО или вручную, например через `Auth::login($user)`, приложение будет использовать язык, выбранный пользователем.

Если пользователь аутентифицируется через конкретный guard, его имя можно указать после двоеточия при подключении промежуточного ПО.

Пример:

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class . ':guard_name')
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Для получения экземпляра пользователя промежуточное ПО использует следующий код:

```php
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;

class LocalizationByModel extends Middleware
{
    public function __construct(
        protected ?string $guard = null,
    ) {}

    protected function user(Request $request): ?Model
    {
        return $request->user($this->guard);
    }
}
```

### Через группу локализованных маршрутов {/* #via_localization_group */}

:::note

При вызове вспомогательной функции `localizedRoute` без <abbr title={"Доступные методы: \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" и \"LocalizationRoute::group\"."}>группировки маршрутов</abbr> локаль передаётся как параметр строки запроса. Например:

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Имя параметра, префикс имени и настройку перенаправления можно изменить в разделе `routes` файла `config/localization.php`.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Этот метод упрощает настройку префиксов групп локализованных маршрутов.

Помимо основного промежуточного ПО этой группы, `LocalizationByParameterPrefix`, используются `LocalizationByCookie`, `LocalizationByHeader` и `LocalizationBySession`.

Можно использовать любой из трёх способов:

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

Приложение зарегистрирует два вида маршрутов: с префиксом `{locale}` и без него. Пример:

| URL | Шаблон | Имя |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Префикс имени можно изменить в разделе `routes` файла `config/localization.php`.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

Эту возможность поддерживает [Laravel Idea](<https://laravel-idea.com/>), плагин для [PhpStorm](<https://www.jetbrains.com/phpstorm/>):

<img src={require("@site/static/images/packages-route-idea-friendly.png").default} alt={"Локализованные маршруты в Laravel Idea"} />

:::

## События {/* #events */}

:::note

Событие доступно в пакете `laravel-lang/routes` начиная с версии `1.1`.

:::

Когда приложению передаётся параметр для установки локали, срабатывает событие:

```php
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

LocaleHasBeenSetEvent::dispatch($locale);
```

Свойство `$locale` события имеет тип `LaravelLang\Locales\Data\LocaleData`.

При необходимости можно подписаться на событие. Пример:

```php
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\ServiceProvider;
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Event::listen(static function (LocaleHasBeenSetEvent $event) {
            Log::info('Locale set to: ' . $event->locale->code);
        });
    }
}
```

:::note

Посмотрите списки доступных [официальных плагинов](<./plugins-official.mdx>) и [плагинов сообщества](<./plugins-community.mdx>).

:::

Для подключения плагина выполните два шага:

1. Установите пакет в приложение. Например, выполните `composer require --dev laravel-lang/lang:^15.39.1` или установите другой пакет.
1. Готово 😊

При выполнении команды `php artisan lang:update` Publisher проверит указанные пакеты и автоматически обновит файлы приложения.

Если в разных пакетах есть одноимённые файлы, например `custom.php`, при обработке будут учтены ключи из всех этих файлов.

:::tip

Для разработки воспользуйтесь готовым [шаблоном переводов](<https://github.com/Laravel-Lang/translations-template>).

:::

Пользуйтесь 😊

## Установка {/* #installation */}

Установите пакет командой:

```bash
composer require laravel-lang/common:^6.9
```

## Управление локалями {/* #managing_locales */}

### Добавление локалей {/* #add_locales */}

:::note

См. [<strong>список доступных локалей</strong>](<./available-locales-list.mdx>).

:::

Теперь можно [добавлять](<./usage-add-locales.mdx> "Добавление локалей в приложение Laravel") новые локали командой `lang:add`:

```bash
php artisan lang:add <locale>
```

### Обновление локалей {/* #update_locales */}

Теперь можно [обновить](<./usage-update-locales.mdx> "Обновление локалей в приложении Laravel") существующие локали командой `lang:update`:

```bash
php artisan lang:update
```

Добавьте вызов в раздел `post-update-cmd` в блоке `scripts` файла `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Так файлы локализаций будут обновляться автоматически после обновления зависимостей, и запускать `php artisan lang:update` вручную не придётся.

## Маршруты {/* #routes */}

### Через группу локализованных маршрутов {/* #via_localization_group */}

:::note

При вызове вспомогательной функции `localizedRoute` без <abbr title={"Доступные методы: \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" и \"LocalizationRoute::group\"."}>группировки маршрутов</abbr> локаль передаётся как параметр строки запроса. Например:

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Имя параметра, префикс имени и настройку перенаправления можно изменить в разделе `routes` файла `config/localization.php`.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Этот метод упрощает настройку префиксов групп локализованных маршрутов.

Помимо основного промежуточного ПО этой группы, `LocalizationByParameterPrefix`, используются `LocalizationByCookie`, `LocalizationByHeader` и `LocalizationBySession`.

Можно использовать любой из трёх способов:

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

Приложение зарегистрирует два вида маршрутов: с префиксом `{locale}` и без него. Пример:

| URL | Шаблон | Имя |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Префикс имени можно изменить в разделе `routes` файла `config/localization.php`.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

Эту возможность поддерживает [Laravel Idea](<https://laravel-idea.com/>), плагин для [PhpStorm](<https://www.jetbrains.com/phpstorm/>):

<img src={require("@site/static/images/packages-route-idea-friendly.png").default} alt={"Локализованные маршруты в Laravel Idea"} />

:::

## Модели {/* #models */}

### Чтение перевода {/* #get_translation */}

:::tip

Все хранилища переводов автоматически применяют [жадную загрузку](<https://laravel.com/docs/eloquent-relationships#eager-loading>) к родительской модели.

По умолчанию связь содержит записи только для текущей и резервной локалей. Чтобы загрузить все записи, измените [настройки фильтрации](<./configuration.mdx#models>):

```php
// config/localization.php
config(['localization.models.filter.enabled' => false]);
```

```ini
; .env
LOCALIZATION_FILTER_ENABLED=false
```

Тогда для записей загрузятся переводы всех доступных локалей.

:::

Чтобы получить значение поля для текущей локали, обратитесь к свойству модели. Пример:

```php
use App\Models\Article;

$page = Article::first();

$page->title;
```

Если значение для <abbr title={"Значение параметра \"app.locale\" в файле \"config/app.php\"."}>текущей локали</abbr> отсутствует, метод вернёт значение для <abbr title={"Значение параметра \"app.fallback_locale\" в файле \"config/app.php\"."}>резервной локали</abbr>.

Также можно вызвать метод `getTranslation`:

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title');
```

Чтобы прочитать значение для конкретной локали, передайте её код вторым аргументом. Пример:

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title', 'fr');
// или
$page->getTranslation('title', Locale::French);
```

:::tip

Методы возвращают новое значение и для изменений модели, которые ещё не сохранены в базе данных.

:::

### Запись переводов {/* #set_translations */}

#### Одно значение {/* #single_value */}

Чтобы добавить или обновить перевод для текущей локали приложения, присвойте значение свойству модели. Пример:

```php
use App\Models\Article;

$page = Article::first();

$page->title = 'New value';
```

Также можно задать новое значение через метод `setTranslation`:

```php
use App\Models\Article;

$page = Article::first();

$page->setTranslation('title', 'New value');
```

Эти методы записывают новое значение в текущую локаль. Чтобы задать значение для другой локали, передайте её код третьим аргументом метода. Пример:

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->setTranslation('title', 'New value', 'fr');
// или
$page->setTranslation('title', 'New value', Locale::French);
```

Также можно использовать массовое заполнение:

```php
use App\Models\Article;

$page = Article::first();

$page->fill([
    'title' => 'New value',
]);
```

:::note

Эти методы меняют значения в объектах моделей. Чтобы записать изменения в базу данных, вызовите `save` у родительской модели. Пример:

```php
$page->save();
```

:::

Заполнять поля можно и при создании модели. Пример:

```php
use App\Models\Article;

$page = Article::first();

Article::create([
    'title' => 'New value',
]);
```

#### Несколько значений {/* #plural_value */}

Чтобы быстро заполнить поле переводами для нескольких локалей, используйте один из способов:

```php
use App\Models\Article;
use Illuminate\Database\Eloquent\Model;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Models\HasTranslations;

/** @var Model|HasTranslations $post */
$post = Article::first();

$titles = [
    'fr' => 'Mettre à jour & continuer à éditer',
    'en' => 'Update & Continue Editing',
    'de' => 'Aktualisieren & Weiterbearbeiten',
];

$descriptions = collect([
    Locale::French->value => 'Met à jour les informations et continue d\'éditer le message',
    Locale::German->value => 'Aktualisiert die Informationen und bearbeitet den Beitrag weiter',
]);

// Вариант 1
foreach ($titles as $locale => $value) {
    $post->setTranslation('title', $value, $locale);
}

foreach ($descriptions as $locale => $value) {
    $post->setTranslation('description', $value, $locale);
}

// Вариант 2
$post->setTranslations('title', $titles);
$post->setTranslations('description', $descriptions);
```

При массовом заполнении также можно присваивать итерируемые объекты `iterable`. Пример:

```php
$post->fill([
    'title'       => $titles,
    'description' => $descriptions,
]);

Article::create([
    'title'       => $titles,
    'description' => $descriptions,
]);
```

Набор локалей для каждого поля может различаться. В примере поле `title` заполняется для французской, английской и немецкой локалей, а `description` — только для французской и немецкой.

## Резервный поиск в JSON {/* #json_fallback */}

:::note

В Laravel 11 файл `config/app.php` не содержит секции `providers`. Её можно добавить вручную.

:::

После установки добавьте ссылку на поставщика служб в секцию `providers` файла `config/app.php`:

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // Другие поставщики служб
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Теперь JSON-ключи будут возвращать значения для выбранной локали.

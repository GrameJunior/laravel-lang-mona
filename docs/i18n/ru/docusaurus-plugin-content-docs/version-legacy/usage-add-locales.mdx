:::note

Посмотрите [список доступных кодов локалей](<./available-locales-list.mdx>).

Список содержит 128 кодов локалей.

:::

Чтобы установить нужные локали, выполните команду `php artisan lang:add <locale>` и передайте один или несколько кодов через пробел:

```bash
php artisan lang:add fr de de_AT de_CH vi zh_CN
php artisan lang:add fr
```

Если целевые файлы существуют, команда предложит пропустить установку или заменить файлы.

Если в этих файлах есть добавленные вами ключи, пропустите их. Команда `php artisan lang:update` сможет обновить файлы, сохранив ваши изменения.

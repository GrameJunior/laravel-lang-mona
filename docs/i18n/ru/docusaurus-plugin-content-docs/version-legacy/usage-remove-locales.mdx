:::warning

Команда удаляет весь каталог локали со всеми файлами. Локаль по умолчанию и резервная локаль защищены.

:::

Чтобы удалить локали, выполните команду `php artisan lang:rm <locale>` и передайте коды:

```bash
php artisan lang:rm fr de de_AT de_CH vi zh_CN
```

Если не передать аргументы, консоль интерактивно предложит выбрать локали из списка доступных.

```bash
php artisan lang:rm
```

По умолчанию попытка удалить защищённую локаль приводит к сообщению об ошибке.

Защищённые локали — коды, указанные в параметрах `locale` и `fallback_locale` файла `config/app.php`.

Чтобы принудительно удалить защищённую локаль, используйте параметр `force`:

```bash
php artisan lang:rm en --force
```

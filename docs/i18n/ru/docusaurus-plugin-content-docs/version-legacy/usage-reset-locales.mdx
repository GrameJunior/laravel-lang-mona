---
title: "Сброс локалей"
slug: /usage-reset-locales.html
description: "Возврат локалей приложения Laravel к исходному состоянию"
---

Чтобы сбросить файлы до состояния по умолчанию, выполните команду:

```bash
php artisan lang:reset
```

Из всех целевых файлов будут удалены ключи, которые не определены пакетами <strong>Laravel Lang</strong> или установленными [сторонними плагинами](<./plugins-community.mdx>).

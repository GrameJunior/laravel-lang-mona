## Инсталација {/* #installation */}

:::note

Погледајте [табелу компатибилности](<#compatibility> "Табела компатибилности за пакет JSON Fallback").

:::

Laravel подразумевано <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">не дозвољава</a> резервне преводе за JSON кључеве. На пример, позив `__('Remember Me')` враћа `Remember Me` уместо `Se souvenir de moi` када је француски резервни језик.

За инсталацију покрените следећу команду.

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Употреба {/* #usage */}

:::note

У Laravel-у 11 у датотеци подешавања `config/app.php` нема одељка `providers`. Можете га додати ручно.

:::

После инсталације додајте упућивање на сервисног провајдера у одељак `providers` датотеке подешавања `config/app.php`.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // other service providers
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

JSON кључеви ће сада враћати исправне вредности на основу изабраног локала.

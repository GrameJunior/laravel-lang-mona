## Објављивање {/* #publish */}

По избору, датотеку подешавања можете да објавите следећом командом.

```bash
php artisan vendor:publish --tag="localization"
```

Ово је садржај објављене датотеке `config/localization.php`.

     */

         *

                'priority' => (int) env('TRANSLATION_GOOGLE_PRIORITY', 1),

            'deepl' => [
                'translator' => '\LaravelLang\Translator\Integrations\Deepl',

                'enabled'  => (bool) env('TRANSLATION_DEEPL_ENABLED', false),
                'priority' => (int) env('TRANSLATION_DEEPL_PRIORITY', 2),

                'credentials' => [
                    'key' => (string) env('TRANSLATION_DEEPL_KEY'),
                ],
            ],

            'yandex' => [
                'translator' => '\LaravelLang\Translator\Integrations\Yandex',

                'enabled'  => (bool) env('TRANSLATION_YANDEX_ENABLED', false),

                ],
            ],
        ],

        'options' => [
            /*

## Поруке без назива поља {/* #inline */}

Опција `inline` одређује која врста датотека се користи при ажурирању језичких датотека.

- Са `true` користе се датотеке без назива поља.
- Са `false` користе се подразумеване датотеке.

Разлика се види у следећем примеру.

```text
The :attribute must be accepted. // default
This field must be accepted. // inline
```

Ова опција доступна је у датотеци `config/localization.php`.

```php
return [
    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),
];
```

## Поравнавање {/* #alignment */}

Опција `align` одређује како се вредности поравнавају једна у односу на другу при обради датотека локализације.

При ажурирању се сви коментари аутоматски уклањају из коначних датотека. Функција [var\_export](<https://www.php.net/manual/en/function.var-export.php>) не уме да обради коментаре.

Погледајте пример улазне датотеке.

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Поруке за аутентификацију
    |--------------------------------------------------------------------------
    |
    | Следећи преводи користе се током аутентификације за различите
    | поруке које треба приказати кориснику. Можете их изменити
    | у складу са захтевима своје апликације.
    |
    */
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

Ажурирана датотека изгледа овако.

```php
declare(strict_types=1);

return [
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

Погледајте и пример датотеке `validation.php`.

## Псеудоними {/* #aliases */}

Ако желите другачије називе кодова, на пример `de-DE` уместо `de` или `de-CH` уместо `de_CH`, дефинишите `aliases` у [датотеци подешавања](<./configuration.mdx#aliases>).

После тога све радње додавања, ажурирања и брисања аутоматски користе псеудониме из датотеке `config/localization.php`.

```php
declare(strict_types=1);

use LaravelLang\LocaleList\Locale;

return [
    'aliases' => [
        Locale::German->value            => 'de-DE',
        Locale::GermanAustria->value     => 'de-AT',
        Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

Ако `config/localization.php` већ постоји, можете у њу додати кључ `aliases` и навести жељене псеудониме у низу података.

Затим можете, на пример, додати нове локале навођењем и главног кода и његовог псеудонима.

```bash
php artisan lang:add de de_CH
```

Инсталирани локали користиће наведене псеудониме као називе директоријума за PHP преводе и називе датотека за JSON преводе.

```text
lang
de-CH
de-DE
```

Ова опција доступна је у датотеци `config/localization.php`.

```php
return [
    'aliases' => [
        // \LaravelLang\LocaleList\Locale::German->value => 'de-DE',
        // \LaravelLang\LocaleList\Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

## Паметна интерпункција {/* #smart_punctuation */}

Погледајте пример.

```json
{
    "Some": "\"It's super-configurable... you can even use additional extensions to expand its capabilities -- just like this one!\""
}
```

Добићете следеће датотеке.

```json
{
    "Some": "“It’s super-configurable… you can even use additional extensions to expand its capabilities – just like this one!”"
}
```

Ова опција доступна је у датотеци `config/localization.php`.

## Руте {/* #routes */}

Када користите пакет за рад са [рутирањем](<./packages-routes.mdx> "Лак и брз начин локализације рута"), можете да замените подразумеване називе кључева.

Ова опција укључује се у датотеци `config/localization.php`.

```php
use LaravelLang\Config\Constants\RouteName;

return [
    'routes' => [
        'names' => [
            'parameter' => RouteName::Parameter,
            'header'    => RouteName::Header,
            'cookie'    => RouteName::Cookie,
            'session'   => RouteName::Session,
            'column'    => RouteName::Column,
        ],

        'name_prefix' => env('LOCALIZATION_NAME_PREFIX', 'localized.'),
        'redirect_default' => (bool) env('LOCALIZATION_REDIRECT_DEFAULT', false),
        'hide_default' => (bool) env('LOCALIZATION_HIDE_DEFAULT', false),

        'group' => [
            'middlewares' => [
                'default' => [
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
                'prefix' => [
                    LaravelLang\Routes\Middlewares\LocalizationByParameterPrefix::class,
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
            ],
        ],
    ],
];
```

## Модели {/* #models */}

Када користите пакет [Models](<./packages-models.mdx> "Лак и брз начин локализације модела"), можете дефинисати подразумеване вредности параметара.

Ово подешавање доступно је у датотеци `config/localization.php`.

```php
return [
    'models' => [
        'suffix' => 'Translation',
        'filter' => [
            'enabled' => (bool) env('LOCALIZATION_FILTER_ENABLED', true),
        ],
        'helpers' => env('VENDOR_PATH', base_path('vendor/_laravel_lang')),
    ],
];
```

Параметар `suffix` одређује суфикс модела којима припада складиште превода.

Погледајте пример.

```text
App\Models\Post::class
App\Models\PostTranslation::class
```

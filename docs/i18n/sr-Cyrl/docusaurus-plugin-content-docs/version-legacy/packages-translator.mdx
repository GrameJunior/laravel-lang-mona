## Инсталација {/* #installation */}

:::note

Погледајте [табелу компатибилности](<#compatibility> "Табела компатибилности за пакет Translator").

:::

За инсталацију покрените следећу команду.

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Подразумевана подешавања можете и [изменити](<./configuration.mdx#translator>) у датотеци `config/localization.php`.

## Употреба {/* #usage */}

:::tip

Ако је потребно, у датотеци подешавања `config/localization.php` наведите податке за ауторизацију код добављача услуга. Без њих плаћене услуге неће радити исправно.

:::

### Циклично превођење {/* #cyclical_translation */}

Појединачне API услуге не покривају увек све потребне локале. Циклично превођење омогућава да се пронађе услуга која може да преведе текст једним позивом.

Узмимо следећа подешавања.

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

У подешавањима су Google Translate и DeepL Translate активни, а Yandex.Translate је искључен. Параметар `enabled` важи само за циклично превођење.

Претпоставимо да Google Translate може да преведе само на француски, а DeepL Translate само на немачки. Тада постоје три случаја.

Враћамо превод из DeepL Translate-а.

</TabItem>

<TabItem value="tab-3" label={"На неподржани језик"}>

1. Проверавамо да ли DeepL Translate подржава овај језик. Не подржава га, па прелазимо на следећег преводиоца.

Враћамо изворни текст без превода.

#### Преко фасаде {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Преко убризгавања зависности {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Директно превођење {/* #direct_translate */}

#### Преко Google Translate-а {/* #via_google */}

:::note

При директном превођењу помоћу [Google Translate-а](<https://translate.google.com>), параметар `enabled` из подешавања се занемарује.

:::

За директан превод можете користити фасаду `LaravelLang\Translator\Facades\Translate` или класу услуге `LaravelLang\Translator\Services\Translate` преко убризгавања зависности.

<Tabs>

<TabItem value="tab-1" label={"Преко фасаде"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// returns string

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// returns array

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// returns array

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// returns array
```

</TabItem>

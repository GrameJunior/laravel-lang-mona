:::note

Погледајте [списак доступних кодова локала](<./available-locales-list.mdx>).

Списак садржи 128 кодова локала.

:::

Потребне локале можете да инсталирате командом `php artisan lang:add <locale>`. Проследите јој један или више кодова локала, раздвојених размацима.

```bash
php artisan lang:add fr de de_AT de_CH vi zh_CN
php artisan lang:add fr
```

Ако одредишне датотеке већ постоје, команда ће вас питати да ли да прескочи инсталацију или замени датотеке.

Ако ове датотеке садрже кључеве које сте додали, препоручљиво је да их прескочите. Команда `php artisan lang:update` може да ажурира датотеке без брисања вашег кода.

:::warning

Ова команда брише цео директоријум локала са свим датотекама, осим за подразумевани и резервни локал.

:::

За брисање локала употребите команду `php artisan lang:rm <locale>` и проследите словне кодове.

```bash
php artisan lang:rm fr de de_AT de_CH vi zh_CN
```

Ако не наведете аргументе, у конзоли ће се појавити интерактивно питање у ком можете да изаберете неки од доступних локала.

```bash
php artisan lang:rm
```

Команда подразумевано враћа поруку о грешци при покушају уклањања заштићеног локала.

Заштићени локали су кодови постављени у параметрима `locale` и `fallback_locale` у датотеци `config/app.php`.

За принудно брисање заштићеног локала користите опцију `force`.

```bash
php artisan lang:rm en --force
```

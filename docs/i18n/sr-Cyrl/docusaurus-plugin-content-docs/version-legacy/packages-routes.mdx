## Инсталација {/* #installation */}

:::note

Погледајте [табелу компатибилности](<#compatibility> "Табела компатибилности за пакет Routes").

:::

За инсталацију покрените следећу команду.

```bash
composer require laravel-lang/routes:^1.11.0
```

Подразумевана подешавања можете и [изменити](<./configuration.mdx#routes>) у датотеци `config/localization.php`.

:::note

Потпуна подршка за [кеширање рута](<https://laravel.com/docs/routing#route-caching>)

```bash
php artisan route:cache
```

:::

## Употреба {/* #usage */}

Инсталацију и употребу пакета [Routes](<./packages-routes.mdx#usage> "Употреба пакета Routes") и [Models](<./packages-models.mdx#usage> "Употреба пакета Models") у истој апликацији приказује кратак видео ([погледајте на YouTube-у](<https://youtu.be/mH76pGbpVu0>)).

<iframe className="legacy-video" src="https://www.youtube-nocookie.com/embed/mH76pGbpVu0" title={"Руте и модели"} loading="lazy" allowFullScreen />

Претпоставимо да апликација има два инсталирана локала, француски и немачки.

Подешавања апликације изгледају овако.

```php
// config/app.php
use LaravelLang\LocaleList\Locale;

return [
    'locale' => Locale::French->value,

    'fallback_locale' => Locale::German->value,
];
```

Поставили смо и вредности за француски и немачки.

```json
{
    "Foo": "Toutes les données ont été chargées."
}
```

```json
{
    "Foo": "Alle Ressourcen geladen."
}
```

### Непосредна употреба {/* #direct */}

На посреднички софтвер можете упутити и без додавања псеудонима.

```php
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('some/{locale}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByParameterWithRedirect::class)
    ->get('some/{locale?}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByHeader::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByCookie::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationBySession::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('some', fn () => view('welcome'));
```

### Псеудоними {/* #aliases */}

За употребу псеудонима посредничког софтвера региструјте их у апликацији.

<Tabs>

<TabItem value="tab-1" label={"Laravel 11"}>

```php
// bootstrap/app.php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Middleware;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'localization.parameter' => LocalizationByParameter::class,
            'localization.redirect'  => LocalizationByParameterWithRedirect::class,
            'localization.header'    => LocalizationByHeader::class,
            'localization.cookie'    => LocalizationByCookie::class,
            'localization.session'   => LocalizationBySession::class,
            'localization.model'     => LocalizationByModel::class,
        ]);
    });
```

</TabItem>

<TabItem value="tab-2" label={"Laravel 10"}>

```php
// app/Http/Kernel.php

use Illuminate\Foundation\Http\Kernel as HttpKernel;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

class Kernel extends HttpKernel
{
    protected $middlewareAliases = [
        // ...

        'localization.parameter' => LocalizationByParameter::class,
        'localization.redirect'  => LocalizationByParameterWithRedirect::class,
        'localization.header'    => LocalizationByHeader::class,
        'localization.cookie'    => LocalizationByCookie::class,
        'localization.session'   => LocalizationBySession::class,
        'localization.model'     => LocalizationByModel::class,
    ];
}
```

</TabItem>

</Tabs>

Затим можете навести псеудониме у методу руте `middleware`.

```php
app('router')
    ->middleware('localization.parameter')
    ->get('some/{locale}', fn () => view('welcome'));

app('router')
    ->middleware('localization.redirect')
    ->get('some/{locale?}', fn () => view('welcome'));

app('router')
    ->middleware('localization.header')
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware('localization.cookie')
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware('localization.session')
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware('localization.model')
    ->get('some', fn () => view('welcome'));
```

### Преко URL параметра {/* #via_url_parameter */}

:::tip

Најпре наведите параметар `{locale}` било где у URL-у рута.

Назив параметра можете променити у одељку `routes` датотеке `config/localization.php`.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByParameter;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('foo/{locale}/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Ако је прослеђен неисправан локал или локал није подешен, страница се приказује на главном локалу инсталираном у апликацији.

### Преко модела {/* #via_model */}

:::tip

Поставља локал према колони <abbr title={"Овај назив можете променити у одељку \"routes\" датотеке \"config/localization.php\"."}>locale</abbr>.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Овај метод омогућава постављање локала за сваког пријављеног клијента. Уверите се да модел садржи атрибут <abbr title={"Овај назив можете променити у одељку \"routes\" датотеке \"config/localization.php\"."}>"locale"</abbr>.

Ако корисничка табела нема ту колону, додајте је по потреби или направите динамички метод у класи модела.

Погледајте пример.

```php
use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Foundation\Auth\User as Authenticatable;
use LaravelLang\LocaleList\Locale;

class User extends Authenticatable
{
    protected function locale(): Attribute
    {
        return Attribute::make(
            get: fn () => Locale::French
        );
    }
}
```

Када је корисник пријављен преко посредничког софтвера или ручно, на пример методом `Auth::login($user)`, апликација враћа податке на језику који је корисник изабрао.

Ако је корисник пријављен преко одређеног механизма за аутентификацију, наведите га после двотачке при позиву посредничког софтвера.

Погледајте пример.

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class . ':guard_name')
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Да добије инстанцу корисника, посреднички софтвер користи следећи код.

```php
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;

class LocalizationByModel extends Middleware
{
    public function __construct(
        protected ?string $guard = null,
    ) {}

    protected function user(Request $request): ?Model
    {
        return $request->user($this->guard);
    }
}
```

### Преко групе за локализацију {/* #via_localization_group */}

:::note

Када позовете помоћну функцију `localizedRoute` без <abbr title={"Доступни методи су \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" и \"LocalizationRoute::group\"."}>груписања</abbr> рута, локал се наводи као параметар упита. Погледајте пример.

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Назив параметра, префикс назива и опцију преусмеравања можете изменити у одељку `routes` датотеке `config/localization.php`.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Овај метод омогућава једноставно управљање префиксима групе помоћу локализованих рута.

Поред главне компоненте посредничког софтвера за ову групу, `LocalizationByParameterPrefix`, учествују и `LocalizationByCookie`, `LocalizationByHeader` и `LocalizationBySession`.

Можете користити један од следећа три начина.

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

Апликација ће регистровати две врсте рута, са и без префикса `{locale}`. Погледајте пример.

| URL | Образац | Назив |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Префикс назива можете изменити у одељку `routes` датотеке `config/localization.php`.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

Ову могућност подржава [Laravel Idea](<https://laravel-idea.com/>), додатак за [PhpStorm](<https://www.jetbrains.com/phpstorm/>).

## Догађаји {/* #events */}

:::note

Догађај је доступан од верзије `1.1` пакета `laravel-lang/routes`.

:::

Догађај се окида када се проследи параметар локала да би се тај локал поставио у апликацији.

```php
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

LocaleHasBeenSetEvent::dispatch($locale);
```

Својство `$locale` догађаја је типа `LaravelLang\Locales\Data\LocaleData`.

Ако је потребно, можете слушати овај догађај. Погледајте пример.

```php
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\ServiceProvider;
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Event::listen(static function (LocaleHasBeenSetEvent $event) {
            Log::info('Locale set to: ' . $event->locale->code);
        });
    }
}
```

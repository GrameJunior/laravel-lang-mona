## Инсталација {/* #installation */}

:::note

Погледајте [табелу компатибилности](<#compatibility> "Табела компатибилности за пакет Locales").

:::

За инсталацију покрените следећу команду.

```bash
composer require laravel-lang/locales:^2.11.0
```

## Употреба {/* #usage */}

За рад са локалима користите фасаду `LaravelLang\Locales\Facades\Locales`. Она омогућава добијање података у два облика, као списак кодова локала или као низ DTO објеката.

### Објекти података {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// Списак доступних локала.
Locales::available(): array // array<LocaleData>

// Списак инсталираних локала.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// Списак локала који нису инсталирани.
Locales::notInstalled(): array // array<LocaleData>

// Списак заштићених локала.
Locales::protects(): array // array<LocaleData>

// Проверава да ли су језички пакети доступни за тражени локал.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// Проверава да ли је језички пакет инсталиран.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// Проверава да ли је локал заштићен.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// Проверава и враћа одговарајући локал.
// Ако тражени локал није инсталиран, враћа текући локал апликације.
Locales::get(mixed $locale): LocaleData

// Враћа назив подразумеваног локала.
Locales::getDefault(): LocaleData

// Враћа назив резервног локала.
Locales::getFallback(): LocaleData

// Враћа податке о доступном локалу. У супротном враћа текући локал апликације.
Locales::info(mixed $locale): LocaleData
```

### Примери {/* #examples */}

```php
use LaravelLang\LocaleList\Direction;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\CountryData;
use LaravelLang\Locales\Data\CurrencyData;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// config('app.locale') // de

return Locales::getDefault(withCountry: true, withCurrency: true);

// Без алијаса
LocaleData {
  +code: "de"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
  +country: CountryData {
    +code: "DE"
    +native: "Deutschland"
    +localized: "Allemagne"
  }
  +currency: CurrencyData {
    +code: "EUR"
    +numeric: 978
    +native: "Euro"
    +localized: "euro"
  }
  +direction: Direction {
    +name: "LeftToRight"
    +value: "ltr"
  }
  +locale: Locale {
    +name: "German"
    +value: "de"
  }
}
```

Овај пакет обухвата локализацију интерфејса почетних комплета.

Тако можете лако да прилагодите и ове преводе.

## Инсталација {/* #installation */}

:::note

Погледајте [табелу компатибилности](<#compatibility> "Табела компатибилности за пакет Starter Kits").

:::

За инсталацију покрените следећу команду.

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## Употреба {/* #usage */}

:::note

Да би објављивање кључева превода за [Laravel почетне комплете](<https://laravel.com/starter-kits>) исправно радило, задржите назив апликације наведен у кључу \`name\` датотеке \`composer.json\`. У супротном, преводи почетних комплета неће бити инсталирани.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

Сада можете [ажурирати](<./usage-update-locales.mdx> "Ажурирање локала Laravel апликације") постојеће локале командом `lang:update`.

```bash
php artisan lang:update
```

Препоручујемо и да позив додате у одељак `post-update-cmd` блока `scripts` у датотеци `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Тако се датотеке локализације аутоматски ажурирају после ажурирања зависности, без ручног покретања команде `php artisan lang:update`.

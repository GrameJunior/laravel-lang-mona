Доприноси су <strong>добродошли</strong> и сваки ће бити <strong>приписан аутору</strong>.

Доприносе прихватамо путем захтева за повлачење у [свим пројектима](<https://github.com/orgs/Laravel-Lang/repositories>) наше организације.

## Шта садрже датотеке? {/* #what_do_the_files_mean */}

- <strong>php.json</strong> садржи преводе вредности за PHP датотеке локализације.
- <strong>php-inline.json</strong> садржи преводе вредности без назива поља за PHP датотеке локализације.
- <strong>json.json</strong> садржи преводе вредности за JSON датотеке локализације.
- <strong>json-inline.json</strong> садржи преводе вредности без назива поља за JSON датотеке локализације.
- <strong>\_excludes.json</strong> садржи вредности чији је превод исти као на енглеском. У овој датотеци наводе се вредности, док су кључеви изостављени.

## Како се мењају датотеке? {/* #how_to_edit_files */}

Све датотеке доступне за превођење имају наставак json и налазе се у директоријуму `locales`. Отворите жељену датотеку и измените је.

:::tip

Чак и ако уочите грешку у кључу, оставите га непромењеног, јер у супротном Laravel неће моћи да га прочита.

За исправку правописа можете само послати [захтев за повлачење](<https://github.com/orgs/laravel/repositories>) одговарајућем пројекту Laravel тима.

Наши пројекти затим аутоматски освежавају кључеве једном дневно.

:::

1. Отворите датотеку локализације.
1. Промените вредности кључева.
1. Направите commit и пошаљите га.
1. Отворите захтев за повлачење и наведите код локала за који правите измене. Погледајте пример испод.

   :::tip

   \[fr\]: Added new localization

   :::

:::tip

Обратите пажњу на датотеке са суфиксом `inline`. Оне не смеју да упућују на текући атрибут (`:attribute`).

Преводи без назива поља разликују се по начину обраћања.

```text
// Стандардна порука
The :attribute must contain at least one letter.

// Порука без назива поља
This field must contain at least one letter.
```

:::

## Како додати нови локал? {/* #how_to_add_a_new_locale */}

### За Laravel Lang пројекте {/* #for_laravel_lang_projects */}

Наши пројекти обично већ садрже доступне локале. Ако желите да предложите нови, [пишите нам](<https://github.com/orgs/Laravel-Lang/discussions/new?category=ideas&title=I%20want%20to%20add%20a%20new%20localization>).

### За пројекте трећих страна {/* #for_third_party_projects */}

:::tip

Да додате локал којег нема у `laravel-lang/locale-list`, [пишите нам](<https://github.com/orgs/Laravel-Lang/discussions/new?category=ideas&title=I%20want%20to%20add%20a%20new%20localization>).

:::

Уверите се да је пакет `laravel-lang/status-generator` инсталиран и покрените следећу команду.

```bash
vendor/bin/lang create <locale>
# vendor/bin/lang create fr
```

Да инсталирате све локале који недостају, покрените команду без кода локала.

```bash
vendor/bin/lang create
```

## Стил кода {/* #code_style */}

Laravel-Lang Team прати [PER](<https://www.php-fig.org/per/coding-style/>) стандард стила кода и [PSR-4](<https://www.php-fig.org/psr/psr-4/>) стандард аутоматског учитавања.

За форматирање кода покрените следећу команду.

```bash
composer style
```

## Наслов захтева за повлачење {/* #pr_title */}

Наслов захтева за повлачење мора пратити следећи формат.

```bash
[locale]: Description
```

Погледајте пример.

```bash
[fr]: Added new localization
```

Усклађеност наслова са утврђеним форматом проверава следећи регуларни израз.

```bash
/^(Draft:\s)?\[[a-zA-Z,_\s]+\]:\s.+$/
```

## Правила понашања {/* #code_of_conduct */}

Laravel правила понашања изведена су из [Повеље учесника](<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>). Свако кршење правила понашања можете пријавити на адресе [Andrey Helldar, Fred Delrieu](<mailto:helldar@dragon-code.pro;caouecs@caouecs.net>).

- Учесници ће бити толерантни према супротним гледиштима.
- Учесници морају да се постарају да њихов говор и поступци не садрже личне нападе и омаловажавајуће примедбе на нечији рачун.
- При тумачењу туђих речи и поступака учесници увек треба да претпоставе добре намере.
- Понашање које се разумно може сматрати узнемиравањем неће се толерисати.

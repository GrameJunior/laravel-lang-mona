## Инсталација {/* #installation */}

Инсталирајте пакет следећом командом.

```bash
composer require laravel-lang/common:^6.9
```

## Управљање локалима {/* #managing_locales */}

### Додавање локала {/* #add_locales */}

:::note

Погледајте [<strong>списак доступних локала</strong>](<./available-locales-list.mdx>).

:::

Сада можете [додати](<./usage-add-locales.mdx> "Додавање локала Laravel апликацији") нове локале командом `lang:add`.

```bash
php artisan lang:add <locale>
```

### Ажурирање локала {/* #update_locales */}

Сада можете [ажурирати](<./usage-update-locales.mdx> "Ажурирање локала Laravel апликације") постојеће локале командом `lang:update`.

```bash
php artisan lang:update
```

Препоручујемо и да позив додате у одељак `post-update-cmd` блока `scripts` у датотеци `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Тако се датотеке локализације аутоматски ажурирају после ажурирања зависности, без ручног покретања команде `php artisan lang:update`.

## Руте {/* #routes */}

### Преко групе за локализацију {/* #via_localization_group */}

:::note

Када позовете помоћну функцију `localizedRoute` без <abbr title={"Доступни методи су \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" и \"LocalizationRoute::group\"."}>груписања</abbr> рута, локал се наводи као параметар упита. Погледајте пример.

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Назив параметра, префикс назива и опцију преусмеравања можете изменити у одељку `routes` датотеке `config/localization.php`.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Овај метод омогућава једноставно управљање префиксима групе помоћу локализованих рута.

Поред главне компоненте посредничког софтвера за ову групу, `LocalizationByParameterPrefix`, учествују и `LocalizationByCookie`, `LocalizationByHeader` и `LocalizationBySession`.

Можете користити један од следећа три начина.

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

Апликација ће регистровати две врсте рута, са и без префикса `{locale}`. Погледајте пример.

| URL | Образац | Назив |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Префикс назива можете изменити у одељку `routes` датотеке `config/localization.php`.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

Ову могућност подржава [Laravel Idea](<https://laravel-idea.com/>), додатак за [PhpStorm](<https://www.jetbrains.com/phpstorm/>).

<img src={require("@site/static/images/packages-route-idea-friendly.png").default} alt={"Подршка за руте у Laravel Idea"} />

:::

## Модели {/* #models */}

### Читање превода {/* #get_translation */}

:::tip

Сва складишта аутоматски преносе заставицу [унапред учитаних веза](<https://laravel.com/docs/eloquent-relationships#eager-loading>) на надређени модел, па то не морате да радите ручно.

Веза подразумевано садржи само записе основних локала, текућег и резервног. У неким случајевима можете учитати све локале изменом [подешавања филтера](<./configuration.mdx#models>).

```php
// config/localization.php
config(['localization.models.filter.enabled' => false]);
```

```ini
; .env
LOCALIZATION_FILTER_ENABLED=false
```

У овом случају учитаће се сви доступни локали за ставке.

:::

Вредност својства за текући локал можете прочитати непосредним приступом својству модела. Погледајте пример.

```php
use App\Models\Article;

$page = Article::first();

$page->title;
```

Ако недостаје вредност за <abbr title={"Вредност параметра \"app.locale\" у датотеци \"config/app.php\"."}>главни локал</abbr>, метод враћа вредност за <abbr title={"Вредност параметра \"app.fallback_locale\" у датотеци \"config/app.php\"."}>резервни локал</abbr>.

Можете користити и метод `getTranslation`.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title');
```

Да добијете вредност за одређени локал, проследите његов код као други аргумент. Погледајте пример.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title', 'fr');
// or
$page->getTranslation('title', Locale::French);
```

:::tip

Ови методи враћају вредност чак и ако модел садржи измене које нису уписане у базу.

:::

### Постављање превода {/* #set_translations */}

#### Једна вредност {/* #single_value */}

Да додате или ажурирате превод за текући локал апликације, доделите вредност својству модела. Погледајте пример.

```php
use App\Models\Article;

$page = Article::first();

$page->title = 'New value';
```

Нову вредност можете поставити и методом `setTranslation`.

```php
use App\Models\Article;

$page = Article::first();

$page->setTranslation('title', 'New value');
```

Ови методи постављају нову вредност за текући активни локал. За одређени локал проследите његов код као трећи параметар. Погледајте пример.

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->setTranslation('title', 'New value', 'fr');
// or
$page->setTranslation('title', 'New value', Locale::French);
```

Можете и групно попунити поља.

```php
use App\Models\Article;

$page = Article::first();

$page->fill([
    'title' => 'New value',
]);
```

:::note

Нове вредности после позива ових метода остају у објектима модела. Да упишете измене у базу, позовите метод `save` на надређеном моделу. Погледајте пример.

```php
$page->save();
```

:::

Поља можете попунити и при прављењу модела. Погледајте пример.

```php
use App\Models\Article;

$page = Article::first();

Article::create([
    'title' => 'New value',
]);
```

#### Више вредности {/* #plural_value */}

Да брзо попуните својство преводима за више локала, употребите неки од следећих начина.

```php
use App\Models\Article;
use Illuminate\Database\Eloquent\Model;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Models\HasTranslations;

/** @var Model|HasTranslations $post */
$post = Article::first();

$titles = [
    'fr' => 'Mettre à jour & continuer à éditer',
    'en' => 'Update & Continue Editing',
    'de' => 'Aktualisieren & Weiterbearbeiten',
];

$descriptions = collect([
    Locale::French->value => 'Met à jour les informations et continue d\'éditer le message',
    Locale::German->value => 'Aktualisiert die Informationen und bearbeitet den Beitrag weiter',
]);

// Опција 1
foreach ($titles as $locale => $value) {
    $post->setTranslation('title', $value, $locale);
}

foreach ($descriptions as $locale => $value) {
    $post->setTranslation('description', $value, $locale);
}

// Опција 2
$post->setTranslations('title', $titles);
$post->setTranslations('description', $descriptions);
```

При групном попуњавању можете доделити и `iterable` објекте. Погледајте пример.

```php
$post->fill([
    'title'       => $titles,
    'description' => $descriptions,
]);

Article::create([
    'title'       => $titles,
    'description' => $descriptions,
]);
```

За свако поље можете навести различите локале. На пример, у примеру изнад поље `title` попуниће се за француски, енглески и немачки, док ће `description` добити вредности само за француски и немачки.

## Резервни JSON преводи {/* #json_fallback */}

:::note

У Laravel-у 11 у датотеци подешавања `config/app.php` нема одељка `providers`. Можете га додати ручно.

:::

После инсталације додајте упућивање на добављача услуга у одељак `providers` датотеке подешавања `config/app.php`.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // other service providers
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

JSON кључеви ће сада враћати исправне вредности на основу изабраног локала.

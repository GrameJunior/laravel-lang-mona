:::note

Погледајте и спискове доступних [званичних додатака](<./plugins-official.mdx>) и [додатака заједнице](<./plugins-community.mdx>).

:::

Да бисте користили управљач додацима, урадите следеће.

1. Инсталирајте пакет у апликацију. На пример, покрените `composer require --dev laravel-lang/lang:^15.39.1` или инсталирајте неки други пакет.
1. То је све 😊

Када покренете `php artisan lang:update`, управљач ће проверити наведене пакете и аутоматски ажурирати датотеке у апликацији.

Ако различити пакети садрже истоимене датотеке, на пример `custom.php`, при обради се узимају сви кључеви из свих тих датотека.

:::tip

За лакши развој користите готов [шаблон за преводе](<https://github.com/Laravel-Lang/translations-template>).

:::

Уживајте! 😊

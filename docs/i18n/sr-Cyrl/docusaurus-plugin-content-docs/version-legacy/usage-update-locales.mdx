За ажурирање датотека покрените следећу команду.

```bash
php artisan lang:update
```

То је све што треба да урадите 🙂

Ова команда препознаје локале инсталиране у апликацији и ажурира датотеке.

:::tip

Нека споредна издања Laravel-а могу да уклоне кључеве из својих репозиторијума, због чега ти кључеви нестају из апликације. То се дешава веома ретко.

Команда за ажурирање локала само додаје нове или ажурира постојеће преводе. Да уклоните неискоришћене изразе, користите команду [`php artisan lang:reset`](<./usage-reset-locales.mdx> "Враћање локала Laravel апликације на подразумевано стање").

:::

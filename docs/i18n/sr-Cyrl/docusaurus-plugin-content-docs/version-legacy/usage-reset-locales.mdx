---

Да вратите датотеке на подразумевано стање, покрените следећу команду.

```bash
php artisan lang:reset
```

Из свих одредишних датотека биће уклоњени кључеви које не дефинишу пакети <strong>Laravel Lang</strong> или инсталирани [додаци трећих страна](<./plugins-community.mdx>).

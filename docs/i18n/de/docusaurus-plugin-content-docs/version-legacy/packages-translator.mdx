## Installation {/* #installation */}

:::note

Die Kompatibilitätstabelle findest du [hier](<#compatibility> "Kompatibilitätstabelle für das Paket Models").

:::

Führe zur Installation den folgenden Konsolenbefehl aus.

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Du kannst die Standardeinstellungen auch in der Datei `config/localization.php` [ändern](<./configuration.mdx#translator>).

## Verwendung {/* #usage */}

:::tip

Trage bei Bedarf die Zugangsdaten der Anbieter in die Konfigurationsdatei `config/localization.php` ein. Kostenpflichtige Dienste funktionieren ohne diese Daten nicht ordnungsgemäß.

:::

### Übersetzungsdienste nacheinander aufrufen {/* #cyclical_translation */}

Die APIs unterstützen unterschiedliche Locales. Daher kannst du nach einem Dienst suchen, der den Text mit einem einzigen Aufruf übersetzen kann.

Nehmen wir die folgenden Einstellungen als Beispiel.

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

In der Konfiguration haben wir Google Translate und DeepL Translate aktiviert und Yandex.Translate deaktiviert. Der Parameter `enabled` gilt nur für Übersetzungen mit nacheinander geprüften Diensten.

Angenommen, Google Translate kann nur ins Französische und DeepL Translate nur ins Deutsche übersetzen. Daraus ergeben sich drei Fälle.

<Tabs>

<TabItem value="tab-1" label={"Ins Französische"}>

<span id={"procedure-tif"} />

1. Wir prüfen, ob Google Translate in die gewünschte Sprache übersetzen kann. Die Sprache wird unterstützt.

Wir geben die Übersetzung von Google Translate zurück.

</TabItem>

<TabItem value="tab-2" label={"Ins Deutsche"}>

<span id={"procedure-tig"} />

1. Wir prüfen, ob Google Translate in diese Sprache übersetzen kann. Da die Sprache nicht unterstützt wird, prüfen wir den nächsten Übersetzungsdienst.
1. Wir prüfen, ob DeepL Translate in die gewünschte Sprache übersetzen kann. Die Sprache wird unterstützt.

Wir geben die Übersetzung von DeepL Translate zurück.

</TabItem>

<TabItem value="tab-3" label={"In eine nicht unterstützte Sprache"}>

<span id={"procedure-tiu"} />

1. Wir prüfen, ob Google Translate in diese Sprache übersetzen kann. Da die Sprache nicht unterstützt wird, prüfen wir den nächsten Übersetzungsdienst.
1. Wir prüfen, ob DeepL Translate in die gewünschte Sprache übersetzen kann. Die Sprache wird nicht unterstützt, daher prüfen wir den nächsten Übersetzungsdienst.

Wir geben den Originaltext ohne Übersetzung zurück.

</TabItem>

</Tabs>

#### Über die Fassade {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Über Dependency Injection {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Direkt übersetzen {/* #direct_translate */}

#### Mit Google Translate {/* #via_google */}

:::note

Bei einer direkten Übersetzung mit [Google Translate](<https://translate.google.com>) wird die Einstellung `enabled` ignoriert.

:::

Für direkte Übersetzungen kannst du die Fassade `LaravelLang\Translator\Facades\Translate` verwenden oder die Serviceklasse `LaravelLang\Translator\Services\Translate` per Dependency Injection einbinden.

<Tabs>

<TabItem value="tab-1" label={"Über die Fassade"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// gibt eine Zeichenkette zurück

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// gibt ein Array zurück

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// gibt ein Array zurück

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// gibt ein Array zurück
```

</TabItem>

<TabItem value="tab-2" label={"Translator per Dependency Injection"}>

```php

    }

    public function fromCollection(): array
    {
        return $this->translator->viaGoogle(new Collection([
            'foo1' => 'some text 1',

        ]), Locale::French);
    }
}
```

## Installation {/* #installation */}

:::note

Die Kompatibilitätstabelle findest du [hier](<#compatibility> "Kompatibilitätstabelle für das Paket JSON Fallback").

:::

Laravel <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">unterstützt standardmäßig keine</a> Fallback-Übersetzungen für JSON-Schlüssel. Wenn du zum Beispiel `__('Remember Me')` aufrufst, erhältst du für Französisch als Fallback-Locale `Remember Me` anstelle von `Se souvenir de moi`.

Führe zur Installation den folgenden Konsolenbefehl aus.

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Verwendung {/* #usage */}

:::note

In Laravel 11 fehlt der Abschnitt `providers` in der Konfigurationsdatei `config/app.php`. Du kannst ihn manuell hinzufügen.

:::

Ergänze nach der Installation den Verweis auf den Service Provider im Abschnitt `providers` der Konfigurationsdatei `config/app.php`.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // weitere Service Provider
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

JSON-Schlüssel liefern jetzt den Wert für die ausgewählte Locale.

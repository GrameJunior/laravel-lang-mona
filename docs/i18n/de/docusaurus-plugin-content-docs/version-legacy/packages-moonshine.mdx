## Installation {/* #installation */}

:::note

Die Kompatibilitätstabelle findest du [hier](<#compatibility> "Kompatibilitätstabelle für das Paket MoonShine").

:::

Führe zur Installation den folgenden Konsolenbefehl aus.

```bash
composer require --dev laravel-lang/moonshine:^1.9.2
```

## Verwendung {/* #usage */}

Mit dem Konsolenbefehl `lang:update` kannst du vorhandene Locales [aktualisieren](<./usage-update-locales.mdx> "Locales einer Laravel-Anwendung aktualisieren").

```bash
php artisan lang:update
```

Wir empfehlen außerdem, den Aufruf in der Datei `composer.json` im Abschnitt `post-update-cmd` des Blocks `scripts` einzutragen.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

So werden die Sprachdateien nach jeder Aktualisierung der Abhängigkeiten automatisch aktualisiert. Du musst den Konsolenbefehl `php artisan lang:update` nicht manuell ausführen.

## Eine Sicherheitslücke melden {/* #reporting_a_vulnerability */}

:::warning

Die Website, von der du auf diese Seite gelangt bist, ist durch Cloudflare geschützt. Die E-Mail-Adressen auf der Seite sind verborgen, um sie vor schädlichen Bots zu schützen.

Wenn beim Klick auf einen Link unter diesem Hinweis eine Meldung erscheint, lade die Seite im Browser neu.

:::

Wenn du in Produkten von <strong>Laravel Lang</strong> eine Sicherheitslücke entdeckst, sende eine E-Mail an [Andrey Helldar oder Fred Delrieu](<mailto:helldar@dragon-code.pro;caouecs@caouecs.net>). Wir kümmern uns umgehend um gemeldete Sicherheitslücken.

Kontaktiere uns bitte per E-Mail.

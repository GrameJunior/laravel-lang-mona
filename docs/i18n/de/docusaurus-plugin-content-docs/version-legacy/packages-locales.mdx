## Installation {/* #installation */}

:::note

Die Kompatibilitätstabelle findest du [hier](<#compatibility> "Kompatibilitätstabelle für das Paket Locales").

:::

Führe zur Installation den folgenden Konsolenbefehl aus.

```bash
composer require laravel-lang/locales:^2.11.0
```

## Verwendung {/* #usage */}

Verwende die Fassade `LaravelLang\Locales\Facades\Locales`, um mit Locales zu arbeiten. Sie liefert entweder eine Liste von Locale-Codes oder ein Array von DTOs.

### Datenobjekte {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// Liste verfügbarer Locales.
Locales::available(): array // array<LocaleData>

// Liste installierter Locales.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// Liste nicht installierter Locales.
Locales::notInstalled(): array // array<LocaleData>

// Liste geschützter Locales abrufen.
Locales::protects(): array // array<LocaleData>

// Prüfen, ob Sprachpakete für die angegebene Locale verfügbar sind.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// Prüfen, ob ein Sprachpaket installiert ist.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// Prüfen, ob die Locale geschützt ist.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// Locale prüfen und den gültigen Wert zurückgeben.
// Bei einer nicht installierten Locale wird die aktuell in der Anwendung aktive Locale zurückgegeben.
Locales::get(mixed $locale): LocaleData

// Code der Standard-Locale abrufen.
Locales::getDefault(): LocaleData

// Code der Fallback-Locale abrufen.
Locales::getFallback(): LocaleData

// Ruft Informationen zu einer verfügbaren Locale ab. Andernfalls werden die Informationen zur aktuell in der Anwendung aktiven Locale zurückgegeben.
Locales::info(mixed $locale): LocaleData
```

### Beispiele {/* #examples */}

```php
use LaravelLang\LocaleList\Direction;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\CountryData;
use LaravelLang\Locales\Data\CurrencyData;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// config('app.locale') // de

return Locales::getDefault(withCountry: true, withCurrency: true);

// Ohne Alias
LocaleData {
  +code: "de"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
  +country: CountryData {
    +code: "DE"
    +native: "Deutschland"
    +localized: "Allemagne"
  }
  +currency: CurrencyData {
    +code: "EUR"
    +numeric: 978
    +native: "Euro"
    +localized: "euro"
  }
  +direction: Direction {
    +name: "LeftToRight"
    +value: "ltr"
  }
  +locale: Locale {
    +name: "German"
    +value: "de"
  }
}

// Mit Alias
LocaleData {
  +code: "de-DE"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
```

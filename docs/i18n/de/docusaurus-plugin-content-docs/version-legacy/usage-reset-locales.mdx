---
title: "Locales zurücksetzen"
slug: /usage-reset-locales.html
description: "Locales in einer Laravel-Anwendung zurücksetzen"
---

Verwende den folgenden Konsolenbefehl, um die Dateien auf ihren Standardzustand zurückzusetzen.

```bash
php artisan lang:reset
```

Der Befehl entfernt aus allen Zieldateien die Schlüssel, die weder von Paketen von <strong>Laravel Lang</strong> noch von installierten [Drittanbieter-Plugins](<./plugins-community.mdx>) definiert sind.

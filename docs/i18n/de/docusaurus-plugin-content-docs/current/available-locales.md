---
title: "Verfügbare Locales"
description: "Hier findest du die kanonischen Locale-Codes, die Laravel-Lang Mona unterstützt."
---

Verwende die folgenden Codes mit [Artisan](./translations.md) und in den Locale-Einstellungen von Laravel. Führe zum Beispiel `php artisan lang:add pt_BR` aus, um brasilianisches Portugiesisch zu installieren. Die Eingabe kann auch ein [konfigurierter Alias](./configure.md#locale-aliases) sein. In den generierten Dateien kommt der kanonische Code zum Einsatz.

Die Liste lässt sich im Code mit [`Locale::values()`](./locales.md#find-supported-and-installed-locales) abrufen. Der Übersetzungsumfang hängt vom Paket und von der Locale ab.

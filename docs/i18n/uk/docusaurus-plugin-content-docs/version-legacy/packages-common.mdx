## Установлення {/* #installation */}

:::note

Рекомендуємо цей пакет, оскільки він дає змогу швидко оновити всі залежності, які забезпечують локалізацію застосунку.

Перегляньте [таблицю сумісності](<#compatibility> "Сумісність пакета Common").

:::

Установіть пакет через [Composer](<https://getcomposer.org>):

```bash
composer require laravel-lang/common:^6.9
```

:::warning

Якщо ви використовуєте Laravel 10, вручну вкажіть версію пакета `laravel-lang/lang` для встановлення:

```bash
composer require --dev laravel-lang/lang:^15.39.1:^14.0
```

:::

## Використання {/* #usage */}

Тепер можна [оновити](<./usage-update-locales.mdx> "Оновлення локалей у застосунку Laravel") наявні локалі командою `lang:update`:

```bash
php artisan lang:update
```

Також рекомендуємо додати виклик до розділу `post-update-cmd` блоку `scripts` у файлі `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Так файли локалізації оновлюватимуться автоматично після оновлення залежностей. Виконувати `php artisan lang:update` вручну не потрібно.

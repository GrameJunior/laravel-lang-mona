## Установлення {/* #installation */}

:::note

Перегляньте [таблицю сумісності](<#compatibility> "Сумісність пакета Locales").

:::

Щоб установити пакет, виконайте команду:

```bash
composer require laravel-lang/locales:^2.11.0
```

## Використання {/* #usage */}

Для роботи з локалями можна використовувати фасад `LaravelLang\Locales\Facades\Locales`. Він надає дані у двох формах: список кодів локалей або масив об'єктів DTO.

### Об'єкти даних {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// Список доступних локалей.
Locales::available(): array // array<LocaleData>

// Список установлених локалей.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// Список невстановлених локалей.
Locales::notInstalled(): array // array<LocaleData>

// Отримує список захищених локалей.
Locales::protects(): array // array<LocaleData>

// Перевіряє, чи є мовні пакети для запитаної локалі.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// Перевіряє, чи встановлено мовний пакет.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// Перевіряє, чи захищено локаль.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// Перевіряє та повертає дійсну локаль.
// Для невстановленої локалі повертає поточну локаль застосунку.
Locales::get(mixed $locale): LocaleData

// Отримує назву типової локалі.
Locales::getDefault(): LocaleData

// Отримує назву резервної локалі.
Locales::getFallback(): LocaleData

// Отримує дані доступної локалі, інакше повертає дані поточної локалі застосунку.
Locales::info(mixed $locale): LocaleData
```

### Приклади {/* #examples */}

```php
use LaravelLang\LocaleList\Direction;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\CountryData;
use LaravelLang\Locales\Data\CurrencyData;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// config('app.locale') // de

return Locales::getDefault(withCountry: true, withCurrency: true);

// Без аліаса
LocaleData {
  +code: "de"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
  +country: CountryData {
    +code: "DE"
    +native: "Deutschland"
    +localized: "Allemagne"
  }
  +currency: CurrencyData {
    +code: "EUR"
    +numeric: 978
    +native: "Euro"
    +localized: "euro"
  }
  +direction: Direction {
    +name: "LeftToRight"
    +value: "ltr"
  }
  +locale: Locale {
    +name: "German"
    +value: "de"
  }
}

// З аліасом
```

## Сумісність {/* #compatibility */}

| Laravel | PHP | Пакет | Стан |
| --- | --- | --- | --- |
| 10, 11, 12, 13 | 8.1, 8.2, 8.3, 8.4, 8.5 | `^2.0` | <span className="compatibility-status compatibility-status--supported">підтримується</span> |
| 10 | 8.1, 8.2, 8.3 | `^1.0` | <span className="compatibility-status compatibility-status--not-supported">не підтримується</span> |

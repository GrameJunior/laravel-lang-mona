---

Щоб оновити файли, виконайте команду:

```bash
php artisan lang:update
```

Це все 🙂

Команда визначає локалі, встановлені в застосунку, та оновлює файли.

:::tip

У деяких мінорних версіях Laravel ключі можуть зникнути з репозиторіїв, а отже, і з застосунку. Це трапляється дуже рідко.

Команда оновлення локалей лише додає нові фрази перекладу або оновлює наявні. Щоб видалити невикористані фрази, виконайте команду [`php artisan lang:reset`](<./usage-reset-locales.mdx> "Скидання локалей у застосунку Laravel").

:::

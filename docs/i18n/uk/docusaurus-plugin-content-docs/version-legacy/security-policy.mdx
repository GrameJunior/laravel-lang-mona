## Повідомлення про вразливість {/* #reporting_a_vulnerability */}

:::warning

Сайт, з якого ви перейшли на цю сторінку, захищено Cloudflare. Адреси електронної пошти на ньому приховано від шкідливих ботів.

Якщо під час переходу за посиланням під цим блоком ви бачите повідомлення, перезавантажте сторінку в браузері.

:::

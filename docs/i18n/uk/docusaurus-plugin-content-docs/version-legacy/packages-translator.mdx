Проєкт `Translator` перебуває на етапі <strong>альфа-тестування</strong>.

До випуску стабільної версії не рекомендуємо використовувати пакет у виробничому середовищі.

:::

## Установлення {/* #installation */}

:::note

Перегляньте [таблицю сумісності](<#compatibility> "Сумісність пакета Translator").

:::

Щоб установити пакет, виконайте команду:

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Типові налаштування можна [змінити](<./configuration.mdx#translator>), відредагувавши файл `config/localization.php`.

## Використання {/* #usage */}

:::tip

За потреби вкажіть облікові дані провайдерів у файлі `config/localization.php`. Без них платні сервіси не працюватимуть належним чином.

:::

### Послідовний переклад {/* #cyclical_translation */}

Не всі сервіси API підтримують усі потрібні локалі. Пакет може вибрати сервіс, який перекладе текст одним викликом.

Наприклад, маємо такі налаштування:

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

У налаштуваннях активовано Google Translate та DeepL Translate і вимкнено Yandex.Translate. Параметр `enabled` діє лише для послідовного перекладу.

Припустімо, Google Translate може перекладати лише французькою, а DeepL Translate — лише німецькою. Тоді можливі три сценарії:

1. Перевіряємо, чи підтримує DeepL Translate цю мову. Ні, тому переходимо до наступного сервісу.

#### Через фасад {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Через впровадження залежностей {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Прямий переклад {/* #direct_translate */}

#### Через Google Translate {/* #via_google */}

:::note

Під час прямого перекладу через [Google Translate](<https://translate.google.com>) параметр `enabled` ігнорується.

:::

Для прямого перекладу використовуйте фасад `LaravelLang\Translator\Facades\Translate` або впровадьте сервіс `LaravelLang\Translator\Services\Translate` як залежність.

<Tabs>

<TabItem value="tab-1" label={"Через фасад"}>

```php

use LaravelLang\Translator\Facades\Translate;

// Повертає рядок

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// Повертає масив

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// Повертає масив

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// Повертає масив
```

</TabItem>

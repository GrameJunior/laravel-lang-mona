:::warning

Ця команда видаляє весь каталог локалі з усіма файлами. Типова та резервна локалі є винятками.

:::

Щоб видалити локалі, виконайте команду `php artisan lang:rm <locale>`, передавши коди локалей:

```bash
php artisan lang:rm fr de de_AT de_CH vi zh_CN
```

Якщо виконати команду без аргументів, у консолі з'явиться інтерактивний запит для вибору з доступних локалей.

```bash
php artisan lang:rm
```

За замовчуванням під час спроби видалити захищену локаль команда повертає повідомлення про помилку.

Захищені локалі — це коди, задані параметрами `locale` і `fallback_locale` у файлі `config/app.php`.

Щоб примусово видалити захищену локаль, використовуйте параметр `force`:

```bash
php artisan lang:rm en --force
```

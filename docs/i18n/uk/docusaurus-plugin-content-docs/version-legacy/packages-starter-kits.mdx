Це дає змогу легко локалізувати й ці елементи.

## Установлення {/* #installation */}

:::note

Перегляньте [таблицю сумісності](<#compatibility> "Сумісність пакета Starter Kits").

:::

Щоб установити пакет, виконайте команду:

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## Використання {/* #usage */}

:::note

Щоб ключі перекладів [стартових наборів Laravel](<https://laravel.com/starter-kits>) публікувалися коректно, не змінюйте назву застосунку в ключі `name` файла `composer.json`. Інакше переклади стартових наборів не встановляться.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

Тепер можна [оновити](<./usage-update-locales.mdx> "Оновлення локалей у застосунку Laravel") наявні локалі командою `lang:update`:

```bash
php artisan lang:update
```

Також рекомендуємо додати виклик до розділу `post-update-cmd` блоку `scripts` у файлі `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Так файли локалізації оновлюватимуться автоматично після оновлення залежностей. Виконувати `php artisan lang:update` вручну не потрібно.

---

:::note

Також можна переглянути списки доступних [офіційних плагінів](<./plugins-official.mdx>) і [плагінів спільноти](<./plugins-community.mdx>).

:::

Щоб підключити пакет до Publisher, виконайте такі дії:

1. Установіть пакет у застосунок. Наприклад, виконайте `composer require --dev laravel-lang/lang:^15.39.1` або встановіть інший пакет.
1. Це все 😊

Тепер під час виконання `php artisan lang:update` Publisher перевірить зазначені пакети й автоматично оновить файли застосунку.

Якщо різні пакети містять однойменні файли, наприклад `custom.php`, під час обробки об'єднаються ключі з усіх цих файлів.

:::tip

Для зручності розробки скористайтеся готовим [шаблоном перекладів](<https://github.com/Laravel-Lang/translations-template>).

:::

Вдалого користування! 😊

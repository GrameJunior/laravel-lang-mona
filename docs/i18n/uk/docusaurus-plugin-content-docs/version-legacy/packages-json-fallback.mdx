## Установлення {/* #installation */}

:::note

Перегляньте [таблицю сумісності](<#compatibility> "Сумісність пакета JSON Fallback").

:::

За замовчуванням Laravel <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">не підтримує</a> резервні переклади ключів JSON. Наприклад, виклик `__('Remember Me')` поверне `Remember Me` замість `Se souvenir de moi` для французької резервної локалі.

Щоб установити пакет, виконайте команду:

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Використання {/* #usage */}

:::note

У Laravel 11 у файлі конфігурації `config/app.php` немає розділу `providers`. Ви можете додати його вручну.

:::

Після встановлення додайте посилання на сервіс-провайдер до розділу `providers` у файлі налаштувань `config/app.php`:

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // інші сервіс-провайдери
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Тепер для ключів JSON повертається правильне значення з огляду на вибрану локаль.

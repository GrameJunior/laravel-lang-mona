## Схема версіювання {/* #versioning_scheme */}

Усі наші пакети дотримуються [семантичного версіювання](<https://semver.org>). Основні випуски проєкту додають можливості, які порушують зворотну сумісність, або припиняють підтримку [застарілих версій](<https://laravel.com/docs/releases>) Laravel чи інших його офіційних пакетів. Мінорні випуски та випуски виправлень не мають містити несумісних змін.

## Політика підтримки {/* #support_policy */}

Для всіх проєктів Lang ми дотримуємося [політики підтримки Laravel](<https://laravel.com/docs/releases#support-policy>).

Оскільки пакети `Lang` не мають містити коду, що впливає на безпеку проєкту, ми орієнтуємося на [заплановані дати завершення підтримки](<https://laravel.com/docs/releases#support-policy>) проєктів Laravel і мінорних версій [PHP](<https://www.php.net>).

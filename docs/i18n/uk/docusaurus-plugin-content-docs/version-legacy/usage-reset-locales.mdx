Щоб повернути файли до початкового стану, виконайте команду:

```bash
php artisan lang:reset
```

З усіх цільових файлів буде вилучено ключі, які не визначені пакетами <strong>Laravel Lang</strong> або встановленими [сторонніми плагінами](<./plugins-community.mdx>).

:::note

Перегляньте [список доступних кодів локалей](<./available-locales-list.mdx>).

Список містить 128 кодів локалей.

:::

Щоб установити потрібні локалі, виконайте команду `php artisan lang:add <locale>`, передавши їй один або кілька кодів локалей, розділених пробілами:

```bash
php artisan lang:add fr de de_AT de_CH vi zh_CN
php artisan lang:add fr
```

Якщо цільові файли вже існують, команда запитає, чи пропустити встановлення, чи замінити файли.

Якщо ці файли містять додані вами ключі, рекомендуємо пропустити їх. Команда `php artisan lang:update` може оновити файли, не видаляючи вашого коду.

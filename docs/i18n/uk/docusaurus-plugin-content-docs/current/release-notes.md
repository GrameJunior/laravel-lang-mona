## Версії та сумісність {#versioning-and-compatibility}

Laravel-Lang дотримується семантичного версіювання. Несумісні зміни й припинення підтримки платформ належать до мажорних релізів. Офіційні пакети мають спільний номер версії. [Семантичне версіювання](https://semver.org/)

Поточна версія потребує PHP `^8.3` і підтримує Laravel 12 та 13. Ваша версія Laravel може потребувати новішої версії PHP. Залежності Common також потребують розширень `intl` і `json`.

Теги релізів і примітки до виправлень доступні у [релізах Mona](https://github.com/Laravel-Lang/mona/releases). Терміни підтримки наведено в [політиці підтримки Laravel](https://laravel.com/docs/releases#support-policy).

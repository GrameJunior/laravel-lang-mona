## Версії та сумісність {#versioning-and-compatibility}

Laravel-Lang дотримується семантичного версіювання. Несумісні зміни й припинення підтримки платформ належать до основних випусків. Офіційні пакети мають спільну версію випуску. [Семантичне версіювання](https://semver.org/)

Поточний випуск потребує PHP `^8.3` і підтримує Laravel 12 та 13. Ваша версія Laravel може потребувати новішої версії PHP. Залежності Common також потребують розширень `intl` і `json`.

Теги випусків і примітки до виправлень доступні у [випусках Mona](https://github.com/Laravel-Lang/mona/releases). Терміни підтримки наведено в [політиці підтримки Laravel](https://laravel.com/docs/releases#support-policy).

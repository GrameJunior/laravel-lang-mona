---
title: Localidades disponíveis
description: Consulte os códigos canônicos de localidade compatíveis com o Laravel-Lang Mona.
---

Use os códigos abaixo com o [Artisan](./translations.md) e nas configurações de localidade do Laravel. Por exemplo, execute `php artisan lang:add pt_BR` para instalar o português do Brasil. A entrada aceita um [alias configurado](./configure.md#locale-aliases), e os arquivos gerados usam o código canônico.

No código, consulte a lista com [`Locale::values()`](./locales.md#find-supported-and-installed-locales). A cobertura da tradução varia de acordo com o pacote e a localidade.

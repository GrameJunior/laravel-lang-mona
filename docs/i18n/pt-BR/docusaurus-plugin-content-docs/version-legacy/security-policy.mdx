## Reportar uma vulnerabilidade {/* #reporting_a_vulnerability */}

:::warning

O site que trouxe você a esta página é protegido pelo Cloudflare. Os endereços de e-mail nessa página foram ocultados para impedir o acesso por bots maliciosos.

Se aparecer uma mensagem ao clicar em um link do texto abaixo, recarregue a página no navegador.

:::

Se descobrir uma vulnerabilidade de segurança em produtos <strong>Laravel Lang</strong>, envie um e-mail a [Andrey Helldar e Fred Delrieu](<mailto:helldar@dragon-code.pro;caouecs@caouecs.net>). Todas as vulnerabilidades de segurança serão tratadas prontamente.

Entre em contato por e-mail.

## Instalação {/* #installation */}

:::note

Consulte a [tabela de compatibilidade](<#compatibility> "Compatibilidade do pacote JSON Fallback").

:::

Por padrão, o Laravel <a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">não permite</a> traduções de fallback para chaves JSON. Por exemplo, quando você chama `__('Remember Me')`, obtém `Remember Me` em vez de `Se souvenir de moi` com francês como idioma de fallback.

Para instalar, execute o comando abaixo.

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## Uso {/* #usage */}

:::note

No Laravel 11, a seção `providers` não está presente no arquivo de configuração `config/app.php`. Você pode adicioná-la manualmente.

:::

Depois de instalar, adicione uma referência ao provedor de serviços na seção `providers` do arquivo `config/app.php`.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // outros provedores de serviços
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

Agora as chaves JSON retornam o valor correto conforme a localidade selecionada.

Este pacote inclui a localização da interface dos kits iniciais do Laravel.

Assim, você também pode traduzir essa interface com facilidade!

:::

## Instalação {/* #installation */}

:::note

Consulte a [tabela de compatibilidade](<#compatibility> "Compatibilidade do pacote Starter Kits").

:::

Para instalar, execute o comando abaixo.

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## Uso {/* #usage */}

:::note

Para que a publicação das chaves de tradução dos [kits iniciais do Laravel](<https://laravel.com/starter-kits>) funcione corretamente, preserve o nome da aplicação na chave `name` de `composer.json`. Caso contrário, as traduções dos kits iniciais não serão instaladas.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

Agora você pode [atualizar](<./usage-update-locales.mdx> "Como atualizar localidades em uma aplicação Laravel") as localidades existentes com o comando `lang:update`.

```bash
php artisan lang:update
```

Também recomendamos adicionar a chamada à seção `post-update-cmd` do bloco `scripts` no arquivo `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Assim, os arquivos de localização são atualizados automaticamente depois das dependências, sem precisar executar `php artisan lang:update` manualmente.

## Instalação {/* #installation */}

:::note

Consulte a [tabela de compatibilidade](<#compatibility> "Compatibilidade do pacote Publisher").

:::

Para instalar, execute o comando abaixo.

```bash
composer require --dev laravel-lang/publisher:^16.9.0
```

## Uso {/* #usage */}

Agora você pode [atualizar](<./usage-update-locales.mdx> "Como atualizar localidades em uma aplicação Laravel") as localidades existentes com o comando `lang:update`.

```bash
php artisan lang:update
```

Também recomendamos adicionar a chamada à seção `post-update-cmd` do bloco `scripts` no arquivo `composer.json`.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

Assim, os arquivos de localização são atualizados automaticamente depois das dependências, sem precisar executar `php artisan lang:update` manualmente.

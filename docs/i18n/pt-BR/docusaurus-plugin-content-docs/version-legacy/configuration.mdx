## Publicar {/* #publish */}

Para publicar o arquivo de configuração, use o comando abaixo.

```bash
php artisan vendor:publish --tag="localization"
```

Este é o conteúdo do arquivo `config/localization.php` publicado.

## Inline {/* #inline */}

A opção `inline` determina quais arquivos são usados ao atualizar os arquivos de idioma.

- `true` usa arquivos inline.
- `false` usa arquivos padrão.

O exemplo abaixo mostra a diferença entre eles.

```text
The :attribute must be accepted. // default
This field must be accepted. // inline
```

A opção fica no arquivo `config/localization.php`.

```php
return [
    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),
];
```

## Alinhamento {/* #alignment */}

A opção `align` define o alinhamento relativo entre os valores ao processar arquivos de localização.

Ao atualizar os arquivos, todos os comentários dos arquivos resultantes são removidos automaticamente. A função [var\_export](<https://www.php.net/manual/en/function.var-export.php>) não preserva comentários.

Veja um exemplo de arquivo.

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | Mensagens de autenticação
    |--------------------------------------------------------------------------
    |
    | As traduções abaixo são usadas durante a autenticação para
    | exibir várias mensagens ao usuário. Você pode modificar
    | essas traduções conforme as necessidades da aplicação.
    |
    */
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

O arquivo atualizado fica conforme o exemplo abaixo.

```php
declare(strict_types=1);

return [
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

Veja também um exemplo do arquivo `validation.php`.

## Aliases {/* #aliases */}

Para usar códigos diferentes, como `de-DE` no lugar de `de` ou `de-CH` no lugar de `de_CH`, defina `aliases` no [arquivo de configuração](<./configuration.mdx#aliases>).

Depois disso, as operações de adição, atualização e exclusão usam automaticamente os aliases definidos em `config/localization.php`.

```php
declare(strict_types=1);

use LaravelLang\LocaleList\Locale;

return [
    'aliases' => [
        Locale::German->value            => 'de-DE',
        Locale::GermanAustria->value     => 'de-AT',
        Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

Se o arquivo `config/localization.php` já existir, você pode adicionar a chave `aliases` e informar os aliases desejados em um array.

Depois disso, você pode, por exemplo, adicionar novas localidades pelo código principal ou pelo alias.

```bash
php artisan lang:add de de_CH
```

As localidades instaladas usam os aliases informados como nomes de pastas para traduções PHP e nomes de arquivos para traduções JSON.

```text
lang
de-CH
de-DE
```

A opção fica no arquivo `config/localization.php`.

```php
return [
    'aliases' => [
        // \LaravelLang\LocaleList\Locale::German->value => 'de-DE',
        // \LaravelLang\LocaleList\Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

## Pontuação tipográfica {/* #smart_punctuation */}

Ao atualizar as chaves de tradução, você também pode ativar a conversão de aspas, travessões e reticências ASCII para os caracteres Unicode correspondentes.

Veja um exemplo.

```json
{
    "Some": "\"It's super-configurable... you can even use additional extensions to expand its capabilities -- just like this one!\""
}
```

A operação gera os seguintes arquivos.

```json
{
    "Some": "“It’s super-configurable… you can even use additional extensions to expand its capabilities – just like this one!”"
}
```

A opção fica no arquivo `config/localization.php`.

## Rotas {/* #routes */}

Ao usar o pacote de [rotas](<./packages-routes.mdx> "Como localizar rotas de forma simples e rápida"), você pode sobrescrever os valores padrão dos nomes das chaves.

Ative a opção no arquivo `config/localization.php`.

```php
use LaravelLang\Config\Constants\RouteName;

return [
    'routes' => [
        'names' => [
            'parameter' => RouteName::Parameter,
            'header'    => RouteName::Header,
            'cookie'    => RouteName::Cookie,
            'session'   => RouteName::Session,
            'column'    => RouteName::Column,
        ],

        'name_prefix' => env('LOCALIZATION_NAME_PREFIX', 'localized.'),
        'redirect_default' => (bool) env('LOCALIZATION_REDIRECT_DEFAULT', false),
        'hide_default' => (bool) env('LOCALIZATION_HIDE_DEFAULT', false),

        'group' => [
            'middlewares' => [
                'default' => [
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
                'prefix' => [
                    LaravelLang\Routes\Middlewares\LocalizationByParameterPrefix::class,
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
            ],
        ],
    ],
];
```

## Modelos {/* #models */}

Você pode definir valores padrão para os parâmetros ao usar o pacote [Models](<./packages-models.mdx> "Como localizar modelos de forma simples e rápida").

A opção fica no arquivo `config/localization.php`.

```php
return [
    'models' => [
        'suffix' => 'Translation',
        'filter' => [
            'enabled' => (bool) env('LOCALIZATION_FILTER_ENABLED', true),
        ],
        'helpers' => env('VENDOR_PATH', base_path('vendor/_laravel_lang')),
    ],
];
```

O parâmetro `suffix` indica o sufixo dos modelos aos quais o repositório de traduções pertence.

Veja um exemplo.

```text
App\Models\Post::class
App\Models\PostTranslation::class
```

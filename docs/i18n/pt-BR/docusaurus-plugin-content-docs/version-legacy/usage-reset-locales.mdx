---
title: "Restaurar localidades"
slug: /usage-reset-locales.html
description: "Como restaurar as localidades de uma aplicação Laravel"
---

Para restaurar os arquivos ao estado padrão, execute o comando abaixo.

```bash
php artisan lang:reset
```

A operação remove de todos os arquivos de destino as chaves que não foram definidas pelos pacotes <strong>Laravel Lang</strong> nem por [plugins de terceiros](<./plugins-community.mdx>) instalados.

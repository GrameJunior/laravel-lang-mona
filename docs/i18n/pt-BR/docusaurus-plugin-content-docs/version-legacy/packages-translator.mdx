## Instalação {/* #installation */}

:::note

Consulte a [tabela de compatibilidade](<#compatibility> "Compatibilidade do pacote Translator").

:::

Para instalar, execute o comando abaixo.

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

Você também pode [alterar](<./configuration.mdx#translator>) as configurações padrão no arquivo `config/localization.php`.

## Uso {/* #usage */}

:::tip

Se necessário, informe os dados de autenticação dos provedores em `config/localization.php`. Sem esses dados, os serviços pagos não funcionam corretamente.

:::

### Tradução cíclica {/* #cyclical_translation */}

A cobertura de localidades varia entre as APIs de tradução. Quando um serviço aceita a localidade necessária, ele pode traduzir todo o texto em uma só chamada.

Veja uma configuração de exemplo.

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

Na configuração, ativamos Google Translate e DeepL Translate e desativamos Yandex.Translate. O parâmetro `enabled` só se aplica à tradução cíclica.

Suponha que o Google Translate só traduza para o francês e que o DeepL Translate só traduza para o alemão. Isso resulta nos três casos abaixo.

<Tabs>

<TabItem value="tab-1" label={"Para o francês"}>

<span id={"procedure-tif"} />

1. Verificamos se o Google Translate pode traduzir para esse idioma. Nesse caso, ele pode.

Retornamos a tradução do Google Translate.

</TabItem>

<TabItem value="tab-2" label={"Para o alemão"}>

<span id={"procedure-tig"} />

1. Verificamos se o Google Translate pode traduzir para esse idioma. Como ele não pode, passamos ao próximo tradutor.
1. Verificamos se o DeepL Translate pode traduzir para esse idioma. Nesse caso, ele pode.

Retornamos a tradução do DeepL Translate.

</TabItem>

<TabItem value="tab-3" label={"Para um idioma sem suporte"}>

<span id={"procedure-tiu"} />

1. Verificamos se o Google Translate pode traduzir para esse idioma. Como ele não pode, passamos ao próximo tradutor.
1. Verificamos se o DeepL Translate pode traduzir para esse idioma. Como ele não pode, passamos ao próximo tradutor.

Retornamos o texto original sem tradução.

</TabItem>

</Tabs>

#### Pela fachada {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### Por injeção de dependência {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### Tradução direta {/* #direct_translate */}

#### Pelo Google Translate {/* #via_google */}

:::note

A tradução direta com o [Google Translate](<https://translate.google.com>) ignora o parâmetro `enabled`.

:::

Para traduzir diretamente, use a fachada `LaravelLang\Translator\Facades\Translate` ou injete a classe de serviço `LaravelLang\Translator\Services\Translate`.

<Tabs>

<TabItem value="tab-1" label={"Pela fachada"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// retorna uma string

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// retorna um array

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// retorna um array

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// retorna um array
```

</TabItem>

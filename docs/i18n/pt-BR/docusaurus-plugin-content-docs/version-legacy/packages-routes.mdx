## Instalação {/* #installation */}

:::note

Consulte a [tabela de compatibilidade](<#compatibility> "Compatibilidade do pacote Routes").

:::

Para instalar, execute o comando abaixo.

```bash
composer require laravel-lang/routes:^1.11.0
```

Você também pode [alterar](<./configuration.mdx#routes>) as configurações padrão no arquivo `config/localization.php`.

:::note

Compatibilidade total com o [cache de rotas](<https://laravel.com/docs/routing#route-caching>).

```bash
php artisan route:cache
```

:::

Assista ao vídeo curto sobre como instalar e usar [Routes](<./packages-routes.mdx#usage> "Informações de uso do pacote Routes") e [Models](<./packages-models.mdx#usage> "Informações de uso do pacote Models") na mesma aplicação ([ver no YouTube](<https://youtu.be/mH76pGbpVu0>)).

Suponha que uma aplicação tenha duas localidades instaladas, francês e alemão.

A configuração da aplicação fica assim.

```php
// config/app.php
use LaravelLang\LocaleList\Locale;

return [
    'locale' => Locale::French->value,

    'fallback_locale' => Locale::German->value,
];
```

Também definimos valores para francês e alemão.

```json
{
    "Foo": "Toutes les données ont été chargées."
}
```

```json
{
    "Foo": "Alle Ressourcen geladen."
}
```

### Diretamente {/* #direct */}

Você pode referenciar o middleware diretamente, sem adicionar aliases.

```php
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('some/{locale}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByParameterWithRedirect::class)
    ->get('some/{locale?}', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByHeader::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByCookie::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationBySession::class)
    ->get('some', fn () => view('welcome'));

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('some', fn () => view('welcome'));
```

### Aliases {/* #aliases */}

Para usar aliases de middleware, registre-os na aplicação.

<Tabs>

<TabItem value="tab-1" label={"Laravel 11"}>

```php
// bootstrap/app.php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Middleware;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

return Application::configure(basePath: dirname(__DIR__))
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'localization.parameter' => LocalizationByParameter::class,
            'localization.redirect'  => LocalizationByParameterWithRedirect::class,
            'localization.header'    => LocalizationByHeader::class,
            'localization.cookie'    => LocalizationByCookie::class,
            'localization.session'   => LocalizationBySession::class,
            'localization.model'     => LocalizationByModel::class,
        ]);
    });
```

</TabItem>

<TabItem value="tab-2" label={"Laravel 10"}>

```php
// app/Http/Kernel.php

use Illuminate\Foundation\Http\Kernel as HttpKernel;
use LaravelLang\Routes\Middlewares\LocalizationByCookie;
use LaravelLang\Routes\Middlewares\LocalizationByHeader;
use LaravelLang\Routes\Middlewares\LocalizationByModel;
use LaravelLang\Routes\Middlewares\LocalizationByParameter;
use LaravelLang\Routes\Middlewares\LocalizationByParameterWithRedirect;
use LaravelLang\Routes\Middlewares\LocalizationBySession;

class Kernel extends HttpKernel
{
    protected $middlewareAliases = [
        // ...

        'localization.parameter' => LocalizationByParameter::class,
        'localization.redirect'  => LocalizationByParameterWithRedirect::class,
        'localization.header'    => LocalizationByHeader::class,

        'localization.session'   => LocalizationBySession::class,
        'localization.model'     => LocalizationByModel::class,
    ];
}
```

</TabItem>

### Por parâmetro da URL {/* #via_url_parameter */}

:::tip

Para começar, informe o parâmetro `{locale}` em qualquer lugar na URL das rotas.

Você pode mudar o nome do parâmetro na seção `routes` do arquivo `config/localization.php`.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByParameter;

app('router')
    ->middleware(LocalizationByParameter::class)
    ->get('foo/{locale}/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Se a localidade informada for inválida ou estiver ausente, a página será exibida na localidade principal configurada na aplicação.

### Por modelo {/* #via_model */}

:::tip

Define a localidade de acordo com o valor da coluna <abbr title={"Esse nome pode ser alterado na seção \"routes\" do arquivo \"config/localization.php\"."}>locale</abbr>.

:::

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class)
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Esse método permite definir a localidade de qualquer cliente autenticado. Para isso, verifique se o modelo contém o atributo <abbr title={"Esse nome pode ser alterado na seção \"routes\" do arquivo \"config/localization.php\"."}>"locale"</abbr>.

Se a tabela de usuários ainda não tiver essa coluna, adicione-a conforme necessário ou crie um método dinâmico na classe do modelo.

Veja um exemplo.

```php
use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Foundation\Auth\User as Authenticatable;
use LaravelLang\LocaleList\Locale;

class User extends Authenticatable
{
    protected function locale(): Attribute
    {
        return Attribute::make(
            get: fn () => Locale::French
        );
    }
}
```

Quando o usuário for autenticado por middleware ou manualmente, por exemplo, com `Auth::login($user)`, a aplicação retornará informações no idioma escolhido pelo usuário.

Se o usuário for autenticado com um guard específico, informe-o depois de dois-pontos na chamada ao middleware.

Veja um exemplo.

```php
use LaravelLang\Routes\Middlewares\LocalizationByModel;

app('router')
    ->middleware(LocalizationByModel::class . ':guard_name')
    ->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
```

Para obter uma instância do usuário, o middleware usa o código abaixo.

```php
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;

class LocalizationByModel extends Middleware
{
    public function __construct(
        protected ?string $guard = null,
    ) {}

    protected function user(Request $request): ?Model
    {
        return $request->user($this->guard);
    }
}
```

### Com um grupo de localização {/* #via_localization_group */}

:::note

Quando o auxiliar `localizedRoute` é chamado sem um <abbr title={"Os métodos disponíveis são \"app('router')->localizedGroup()\", \"Route::localizedGroup()\" e \"LocalizationRoute::group\"."}>grupo de rotas</abbr>, a localidade é informada como parâmetro de consulta. Veja o exemplo abaixo.

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

Você pode alterar o nome do parâmetro, o prefixo do nome e a opção de redirecionamento na seção `routes` do arquivo `config/localization.php`.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

Esse método facilita o gerenciamento dos prefixos de grupos que usam rotas localizadas.

Além do middleware principal desse grupo, `LocalizationByParameterPrefix`, participam `LocalizationByCookie`, `LocalizationByHeader` e `LocalizationBySession`.

Você pode usar uma das três formas abaixo.

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

A aplicação registra dois tipos de rota, com e sem o prefixo `{locale}`. Veja os exemplos.

| URL | Padrão | Nome |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

Você pode alterar o prefixo do nome na seção `routes` de `config/localization.php`.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

Esse recurso é compatível com [Laravel Idea](<https://laravel-idea.com/>), um plugin para [PhpStorm](<https://www.jetbrains.com/phpstorm/>).

## Eventos {/* #events */}

:::note

O evento está disponível na versão `1.1` ou posterior do pacote `laravel-lang/routes`.

:::

Ao informar um parâmetro de localidade para defini-la na aplicação, o evento é disparado.

```php
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

LocaleHasBeenSetEvent::dispatch($locale);
```

A propriedade `$locale` do evento é do tipo `LaravelLang\Locales\Data\LocaleData`.

Se necessário, adicione um ouvinte para esse evento. Veja o exemplo abaixo.

```php
use Illuminate\Support\Facades\Event;
use Illuminate\Support\Facades\Log;
use Illuminate\Support\ServiceProvider;
use LaravelLang\Routes\Events\LocaleHasBeenSetEvent;

class AppServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        Event::listen(static function (LocaleHasBeenSetEvent $event) {
            Log::info('Locale set to: ' . $event->locale->code);
        });
    }
}
```

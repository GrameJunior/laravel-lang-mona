title: 可用语言区域
description: 查阅 Laravel-Lang Mona 支持的规范语言区域代码。
---

在 [Artisan](./translations.md) 和 Laravel 的语言区域设置中使用以下代码。例如，运行 `php artisan lang:add pt_BR` 安装巴西葡萄牙语。输入可以使用[已配置的别名](./configure.md#locale-aliases)，但输出的文件使用规范代码。

可通过 [`Locale::values()`](./locales.md#find-supported-and-installed-locales) 在代码中获取此列表。译文覆盖范围因翻译包和语言区域而异。

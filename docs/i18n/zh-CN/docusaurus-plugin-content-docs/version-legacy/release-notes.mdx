## 版本管理规则 {/* #versioning_scheme */}

我们的所有软件包都遵循[语义化版本规范](<https://semver.org>)。添加不向后兼容的功能，或停止支持 Laravel 及其其他官方软件包的[弃用版本](<https://laravel.com/docs/releases>)时，会发布新的主版本。次版本和补丁版本不应包含破坏性更改。

## 支持政策 {/* #support_policy */}

所有 Lang 项目均遵循 [Laravel 支持政策](<https://laravel.com/docs/releases#support-policy>)。

由于 `Lang` 项目的软件包预计不会包含影响项目安全性的代码，我们按 Laravel 项目的[计划维护截止日期](<https://laravel.com/docs/releases#support-policy>)和 [PHP](<https://www.php.net>) 的次版本确定支持范围。

## 安装 {/* #installation */}

:::note

请参阅[兼容性表](<#compatibility> "Starter Kits 软件包的兼容性表")。

:::

要安装软件包，请运行以下控制台命令。

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## 用法 {/* #usage */}

:::note

为了正常发布 [Laravel 入门套件](<https://laravel.com/starter-kits>)的译文，请勿更改 `composer.json` 中 `name` 键指定的应用名称。否则将不会安装入门套件的译文。

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

现在可以使用控制台命令 `lang:update` [更新](<./usage-update-locales.mdx> "更新 Laravel 应用中的语言区域")已有的译文。

```bash
php artisan lang:update
```

也建议将该命令添加到 `composer.json` 文件 `scripts` 下的 `post-update-cmd` 中。

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

这样，每次更新依赖后，翻译文件都会自动更新，无需手动运行 `php artisan lang:update`。

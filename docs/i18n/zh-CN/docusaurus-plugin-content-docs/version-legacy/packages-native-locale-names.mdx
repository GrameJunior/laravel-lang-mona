## 安装 {/* #installation */}

:::note

请参阅[兼容性表](<#compatibility> "Native Locale Names 软件包的兼容性表")。

:::

要安装软件包，请运行以下控制台命令。

```bash
composer require laravel-lang/native-locale-names:^2.10.0
```

## 用法 {/* #usage */}

### 本地化名称 {/* #localized_names */}

```php
use LaravelLang\NativeLocaleNames\LocaleNames;
use LaravelLang\LocaleList\Locale;

return LocaleNames::get('bn');
// 或者
return LocaleNames::get(Locale::Bengali);
```

### 本地名称 {/* #native_names */}

不带参数调用 `get` 方法也可获取名称列表。传入无效值或空值时，结果相同。

```php
use LaravelLang\NativeLocaleNames\LocaleNames;

return LocaleNames::get();
// 或者
return LocaleNames::get('');
// 或者
return LocaleNames::get(null);
// 或者
return LocaleNames::get('foo');
```

### 排序 {/* #sorting */}

要按键或值对结果排序，请传入相应的 `SortBy` 枚举项。

默认按值排序。

#### 按键排序 {/* #sort_by_keys */}

```php
use LaravelLang\NativeLocaleNames\LocaleNames;
use LaravelLang\NativeLocaleNames\Enums\SortBy;

return LocaleNames::get('en', SortBy::Key);
```

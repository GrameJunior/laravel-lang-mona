## 安装 {/* #installation */}

:::note

请参阅[兼容性表](<#compatibility> "Translator 软件包的兼容性表")。

:::

要安装软件包，请运行以下控制台命令。

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

可编辑 `config/localization.php` 文件来[更改](<./configuration.mdx#translator>)默认设置。

## 用法 {/* #usage */}

:::tip

如有需要，请在 `config/localization.php` 配置文件中指定服务提供商的认证信息。缺少这些信息时，付费服务无法正常运行。

:::

### 依次尝试各翻译服务 {/* #cyclical_translation */}

并非所有 API 服务都支持所需的全部语言区域。可以依次检查各服务，选择支持目标语言的服务发起一次翻译请求。

以下面这份配置为例。

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

配置启用了 Google Translate 和 DeepL Translate，并停用了 Yandex.Translate。`enabled` 参数仅影响依次尝试各翻译服务的流程。

假设 Google Translate 只能翻译成法语，DeepL Translate 只能翻译成德语，则有三种情况。

<Tabs>

<TabItem value="tab-1" label={"译成法语"}>

<span id={"procedure-tif"} />

1. 检查 Google Translate 是否支持目标语言。它支持法语。

返回 Google Translate 的译文。

</TabItem>

<TabItem value="tab-2" label={"译成德语"}>

<span id={"procedure-tig"} />

1. 检查 Google Translate 是否支持目标语言。它不支持德语，因此尝试下一个翻译服务。
1. 检查 DeepL Translate 是否支持目标语言。它支持德语。

返回 DeepL Translate 的译文。

</TabItem>

<TabItem value="tab-3" label={"译成不受支持的语言"}>

<span id={"procedure-tiu"} />

1. 检查 Google Translate 是否支持目标语言。它不支持，因此尝试下一个翻译服务。
1. 检查 DeepL Translate 是否支持目标语言。它也不支持，因此继续尝试其他服务。

由于没有可用服务，返回原文。

</TabItem>

</Tabs>

#### 通过门面调用 {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### 通过依赖注入调用 {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### 直接调用翻译服务 {/* #direct_translate */}

#### 使用 Google Translate {/* #via_google */}

:::note

直接使用 [Google Translate](<https://translate.google.com>) 翻译时，将忽略配置中的 `enabled` 参数。

:::

要直接调用翻译，可使用 `LaravelLang\Translator\Facades\Translate` 门面，或通过依赖注入获取 `LaravelLang\Translator\Services\Translate` 服务。

<Tabs>

<TabItem value="tab-1" label={"通过门面"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// 返回字符串

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// 返回数组

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// 返回数组

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// 返回数组
```

</TabItem>

<TabItem value="tab-2" label={"通过依赖注入获取 Translator"}>

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate;

class Example
{
    public function __construct(
        protected Translate $translator
    ) {}

    public function fromString(): string
    {
        return $this->translator->viaGoogle('some text', Locale::French);
    }

    public function fromArray1(): array
    {
        return $this->translator->viaGoogle([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function fromArray2(): array
    {
        return $this->translator->viaGoogle([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function fromCollection(): array
    {
        return $this->translator->viaGoogle(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

</TabItem>

## 安装 {/* #installation */}

:::note

请参阅[兼容性表](<#compatibility> "JSON Fallback 软件包的兼容性表")。

:::

Laravel 的默认行为<a href={"https://github.com/laravel/framework/issues/41565#issuecomment-1073572954"} target="_blank" rel="noopener noreferrer">不支持</a> JSON 键的回退译文。例如，回退语言为法语时，调用 `__('Remember Me')` 得到的仍是 `Remember Me`，而不是 `Se souvenir de moi`。

要安装软件包，请运行以下控制台命令。

```bash
composer require laravel-lang/json-fallback:^2.3.0
```

## 用法 {/* #usage */}

:::note

Laravel 11 的 `config/app.php` 配置文件没有 `providers` 部分，可以手动添加。

:::

安装后，需要在 `config/app.php` 配置文件的 `providers` 部分注册服务提供者。

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // 其他服务提供者
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

此时，JSON 键会根据所选的语言区域正确返回对应的值。

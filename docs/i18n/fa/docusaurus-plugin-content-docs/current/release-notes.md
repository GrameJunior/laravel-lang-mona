## نسخه‌بندی و سازگاری {#versioning-and-compatibility}

Laravel-Lang از نسخه‌بندی معنایی پیروی می‌کند. تغییرات ناسازگار و پایان پشتیبانی از پلتفرم‌ها در انتشارهای اصلی اعمال می‌شوند. همهٔ بسته‌های رسمی شمارهٔ انتشار یکسانی دارند. [نسخه‌بندی معنایی](https://semver.org/)

انتشار فعلی به PHP با قید نسخهٔ `^8.3` نیاز دارد و از Laravel 12 و 13 پشتیبانی می‌کند. نسخهٔ Laravel شما ممکن است به PHP جدیدتری نیاز داشته باشد. وابستگی‌های Common نیز به افزونه‌های `intl` و `json` نیاز دارند.

برچسب‌ها و یادداشت‌های اصلاحات در [انتشارهای Mona](https://github.com/Laravel-Lang/mona/releases) در دسترس‌اند. برای تاریخ‌های نگه‌داری Laravel به [سیاست پشتیبانی Laravel](https://laravel.com/docs/releases#support-policy) مراجعه کنید.

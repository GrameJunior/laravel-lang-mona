## نصب {/* #installation */}

:::note

جدول سازگاری را [اینجا](<#compatibility> "جدول سازگاری بستهٔ Translator") ببینید.

:::

برای نصب، فرمان زیر را اجرا کنید.

```bash
composer require laravel-lang/translator:^1.0-alpha6
```

می‌توانید با ویرایش فایل `config/localization.php` تنظیمات پیش‌فرض را نیز [تغییر دهید](<./configuration.mdx#translator>).

## کاربرد {/* #usage */}

:::tip

در صورت نیاز داده‌های احراز هویت ارائه‌دهندگان را در فایل تنظیمات `config/localization.php` وارد کنید. سرویس‌های پولی بدون آن درست کار نمی‌کنند.

:::

### ترجمهٔ چرخه‌ای {/* #cyclical_translation */}

همهٔ سرویس‌های API زبان‌های منطقه‌ای مورد نیاز برای ترجمه را پوشش نمی‌دهند. با این حال، می‌توان سرویسی پیدا کرد که متن را در یک فراخوانی ترجمه کند.

برای نمونه، تنظیمات زیر را در نظر بگیرید.

```php
use LaravelLang\Translator\Integrations\Deepl;
use LaravelLang\Translator\Integrations\Google;
use LaravelLang\Translator\Integrations\Yandex;

return [
    'translators' => [
        'channels' => [
            'google' => [
                'translator' => Google::class,
                'enabled'    => true,
            ],

            'deepl' => [
                'translator' => Deepl::class,
                'enabled'    => true,

                'credentials' => [
                    'key' => 'deepl-secret-key',
                ],
            ],

            'yandex' => [
                'translator' => Yandex::class,
                'enabled'    => false,

                'credentials' => [
                    'key'    => 'yandex-secret-key',
                    'folder' => 'yandex-folder-id',
                ],
            ],
        ],
    ],
];
```

در تنظیمات، Google Translate و DeepL Translate را به‌عنوان مترجم فعال مشخص کرده‌ایم و Yandex.Translate را غیرفعال کرده‌ایم. پارامتر `enabled` فقط بر ترجمهٔ چرخه‌ای اثر دارد.

فرض کنید Google Translate فقط به فرانسوی و DeepL Translate فقط به آلمانی ترجمه می‌کند. در این صورت سه حالت پیش می‌آید.

#### از طریق نما {/* #via_facade */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Facades\Translate;

$translated1 = Translate::text(
    text: 'some text',
    to  : Locale::French
);

$translated2 = Translate::text([
    'some text 1',
    'some text 2',
], Locale::French);

$translated3 = Translate::text([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
```

#### از طریق تزریق وابستگی {/* #via_dependency_injection */}

```php
use Illuminate\Support\Collection;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Translator\Services\Translate as TranslateService;

class Example
{
    public function __construct(
        protected TranslateService $translate
    ) {}

    public function get1(): string
    {
        return $this->translate->text('some text', Locale::French);
    }

    public function get2(): array
    {
        return $this->translate->text([
            'some text 1',
            'some text 2',
        ], Locale::French);
    }

    public function get3(): array
    {
        return $this->translate->text([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ], Locale::French);
    }

    public function get4(): array
    {
        return $this->translate->text(new Collection([
            'foo1' => 'some text 1',
            'foo2' => 'some text 2',
        ]), Locale::French);
    }
}
```

### ترجمهٔ مستقیم {/* #direct_translate */}

#### با Google Translate {/* #via_google */}

:::note

هنگام ترجمهٔ مستقیم متن با [Google Translate](<https://translate.google.com>)، پارامتر تنظیمات `enabled` نادیده گرفته می‌شود.

:::

برای فراخوانی ترجمهٔ مستقیم می‌توانید از نمای `LaravelLang\Translator\Facades\Translate` یا کلاس سرویس `LaravelLang\Translator\Services\Translate` از طریق تزریق وابستگی استفاده کنید.

<Tabs>

<TabItem value="tab-1" label={"از طریق نما"}>

```php
use Illuminate\Support\Collection;

use LaravelLang\Translator\Facades\Translate;

$translate1 = Translate::viaGoogle('some text', Locale::French);
// رشته برمی‌گرداند

$translate2 = Translate::viaGoogle([
    'some text 1',
    'some text 2',
], Locale::French);
// آرایه برمی‌گرداند

$translate3 = Translate::viaGoogle([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
], Locale::French);
// آرایه برمی‌گرداند

$translate3 = Translate::viaGoogle(new Collection([
    'foo1' => 'some text 1',
    'foo2' => 'some text 2',
]), Locale::French);
// آرایه برمی‌گرداند
```

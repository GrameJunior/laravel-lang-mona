## به‌روزرسانی وابستگی‌ها {/* #updating_dependencies */}

وابستگی زیر را در فایل `composer.json` برنامه به‌روز کنید.

- `"laravel-lang/json-fallback-hotfix": "^1.0"` را با `"laravel-lang/json-fallback": "^2.0"` جایگزین کنید.

سپس فرمان به‌روزرسانی وابستگی‌ها را اجرا کنید.

```bash
composer update
```

## تغییر فضای نام {/* #change_namespace */}

فضای نام را در فایل `config/app.php` تغییر دهید.

```php
LaravelLang\JsonFallbackHotfix\TranslationServiceProvider
```

فضای نام جایگزین

```php
LaravelLang\JsonFallback\TranslationServiceProvider
```

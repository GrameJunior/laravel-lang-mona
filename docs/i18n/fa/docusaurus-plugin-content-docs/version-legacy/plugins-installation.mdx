:::note

فهرست افزونه‌های موجودِ [رسمی](<./plugins-official.mdx>) و ساخته‌شده توسط [انجمن](<./plugins-community.mdx>) را نیز می‌توانید ببینید.

:::

برای استفاده از مدیر بومی‌سازی مراحل زیر را انجام دهید.

1. بسته را در برنامهٔ خود نصب کنید، برای نمونه با `composer require --dev laravel-lang/lang:^15.39.1` یا بسته‌ای دیگر.
1. همین کافی است 😊

اکنون هنگام اجرای `php artisan lang:update`، مدیر بسته‌های مشخص‌شده را بررسی می‌کند و فایل‌های برنامه را خودکار به‌روز می‌کند.

اگر بسته‌های مختلف فایل‌های هم‌نام، مانند `custom.php`، داشته باشند، هنگام پردازش، کلیدهای همهٔ فایل‌ها در نظر گرفته می‌شوند.

:::tip

برای توسعهٔ آسان‌تر، از [الگوی آمادهٔ ترجمه](<https://github.com/Laravel-Lang/translations-template>) استفاده کنید.

:::

از آن لذت ببرید! 😊

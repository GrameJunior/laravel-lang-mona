:::note

فهرست کدهای زبان منطقه‌ای موجود [اینجا](<./available-locales-list.mdx>) در دسترس است.

این فهرست 128 کد زبان منطقه‌ای دارد.

:::

برای نصب زبان‌های منطقه‌ای مورد نیاز، فرمان `php artisan lang:add <locale>` را با یک یا چند کد جداشده با فاصله فراخوانی کنید.

```bash
php artisan lang:add fr de de_AT de_CH vi zh_CN
php artisan lang:add fr
```

اگر فایل‌های مقصد وجود داشته باشند، از شما پرسیده می‌شود که از نصب بگذرید یا فایل‌ها را جایگزین کنید.

اگر این فایل‌ها کلیدهایی دارند که خودتان افزوده‌اید، پیشنهاد می‌شود از جایگزینی بگذرید. فرمان `php artisan lang:update` می‌تواند فایل‌ها را بدون حذف کد شما به‌روز کند.

## نصب {/* #installation */}

بسته را با فرمان زیر نصب کنید.

```bash
composer require laravel-lang/common:^6.9
```

## مدیریت زبان‌های منطقه‌ای {/* #managing_locales */}

### افزودن زبان‌های منطقه‌ای {/* #add_locales */}

:::note

فهرست زبان‌های منطقه‌ای موجود [<strong>اینجا</strong>](<./available-locales-list.mdx>) در دسترس است.

:::

اکنون می‌توانید با فرمان `lang:add` زبان منطقه‌ای جدیدی [اضافه کنید](<./usage-add-locales.mdx> "افزودن زبان‌های منطقه‌ای به برنامهٔ Laravel").

```bash
php artisan lang:add <locale>
```

### به‌روزرسانی زبان‌های منطقه‌ای {/* #update_locales */}

اکنون می‌توانید زبان‌های منطقه‌ای موجود را با فرمان `lang:update` [به‌روز کنید](<./usage-update-locales.mdx> "به‌روزرسانی زبان‌های منطقه‌ای در Laravel").

```bash
php artisan lang:update
```

پیشنهاد می‌کنیم فراخوانی را به بخش `post-update-cmd` در بلوک `scripts` فایل `composer.json` هم اضافه کنید.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

با این کار، فایل‌های بومی‌سازی پس از به‌روزرسانی وابستگی‌ها خودکار به‌روز می‌شوند و نیازی به اجرای دستی `php artisan lang:update` نیست.

## مسیرها {/* #routes */}

### از طریق گروه بومی‌سازی {/* #via_localization_group */}

:::note

اگر تابع کمکی `localizedRoute` را بدون <abbr title={"روش‌های موجود app('router')->localizedGroup()، Route::localizedGroup() و LocalizationRoute::group هستند."}>گروه‌بندی</abbr> مسیر فراخوانی کنید، زبان منطقه‌ای به‌عنوان پارامتر پرس‌وجو تعیین می‌شود. نمونه را در ادامه ببینید.

```bash
https://example.com/foo?locale=fr
```

:::

:::tip

نام پارامتر، پیشوند نام و گزینهٔ هدایت را می‌توان در بخش `routes` فایل `config/localization.php` تغییر داد.

:::

```php
use Illuminate\Support\Facades\Route;

app('router')->localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});

Route::localizedGroup(function () {
    app('router')->get('foo/{bar}', function (string $bar) {
        return response()->json([
            $bar => __('Foo'),
        ]);
    });
});
```

با این روش می‌توانید پیشوندهای گروه را با مسیرهای بومی‌شده به‌آسانی مدیریت کنید.

علاوه بر میان‌افزار اصلی این گروه، `LocalizationByParameterPrefix`، میان‌افزارهای `LocalizationByCookie`، `LocalizationByHeader` و `LocalizationBySession` نیز دخیل‌اند.

می‌توانید از یکی از سه روش زیر استفاده کنید.

```php
use Illuminate\Support\Facades\Route;
use LaravelLang\Routes\Facades\LocalizationRoute;

app('router')->localizedGroup(fn () => ...)

Route::localizedGroup(fn () => ...)

LocalizationRoute::group(fn () => ...)
```

The final application will register two types of routes - with and without the `{locale}` prefix. نمونه‌ای در ادامه آمده است.

| URL | الگو | نام |
| --- | --- | --- |
| https://example.com/fr/foo/show | `{locale}/foo/{bar}` | `localized.show` |
| https://example.com/foo/show | `foo/{bar}` | `show` |

پیشوند نام را می‌توان در بخش `routes` فایل `config/localization.php` تغییر داد.

:::note

```php
localizedRoute('show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

localizedRoute('localized.show', ['bar' => 'show']);
// https://example.com/fr/foo/show

localizedRoute('localized.show', ['bar' => 'show', 'locale' => 'de']);
// https://example.com/de/foo/show

route('localized.show', ['bar' => 'show', 'locale' => app()->getLocale()]);
// https://example.com/fr/foo/show
```

افزونهٔ [Laravel Idea](<https://laravel-idea.com/>) برای [PhpStorm](<https://www.jetbrains.com/phpstorm/>) از این قابلیت پشتیبانی می‌کند.

## مدل‌ها {/* #models */}

### دریافت ترجمه {/* #get_translation */}

:::tip

همهٔ مخزن‌های داده پرچم [بارگذاری پیشاپیش](<https://laravel.com/docs/eloquent-relationships#eager-loading>) را خودکار به مدل والد منتقل می‌کنند، بنابراین نیازی به انجام دستی آن نیست.

رابطه به‌طور پیش‌فرض تنها ردیف‌های زبان منطقه‌ای جاری و جایگزین را دارد. در صورت نیاز می‌توانید با تغییر [تنظیمات فیلتر](<./configuration.mdx#models>) همهٔ ردیف‌ها را بارگذاری کنید.

```php
// config/localization.php
config(['localization.models.filter.enabled' => false]);
```

```ini
; .env
LOCALIZATION_FILTER_ENABLED=false
```

در این حالت همهٔ زبان‌های منطقه‌ای موجود برای موارد بارگذاری می‌شوند.

:::

To get the value of a property for the current localization, simply make a call to the model property. نمونه‌ای در ادامه آمده است.

```php
use App\Models\Article;

$page = Article::first();

$page->title;
```

اگر مقدار <abbr title={"مقدار پارامتر app.locale در فایل config/app.php."}>زبان منطقه‌ای اصلی</abbr> موجود نباشد، متد مقدار <abbr title={"مقدار پارامتر app.fallback_locale در فایل config/app.php."}>زبان منطقه‌ای جایگزین</abbr> را برمی‌گرداند.

می‌توانید از متد `getTranslation` نیز استفاده کنید.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title');
```

To get a value for a specific locale, pass the localization code as the second argument. نمونه‌ای در ادامه آمده است.

```php
use App\Models\Article;

$page = Article::first();

$page->getTranslation('title', 'fr');
// یا
$page->getTranslation('title', Locale::French);
```

:::tip

این متدها حتی اگر تغییرات مدل هنوز در پایگاه داده نوشته نشده باشند، همان مقدار را برمی‌گردانند.

:::

### تنظیم ترجمه‌ها {/* #set_translations */}

#### یک مقدار {/* #single_value */}

To add or update a translation to your application's current locale, simply assign a value to the model property. نمونه‌ای در ادامه آمده است.

```php
use App\Models\Article;

$page = Article::first();

$page->title = 'New value';
```

می‌توانید مقدار جدیدی را با متد `setTranslation` هم تنظیم کنید.

```php
use App\Models\Article;

$page = Article::first();

$page->setTranslation('title', 'New value');
```

These methods will set a new value to the currently active locale. To set the value to a specific locale, pass its code as the third parameter in this method. نمونه‌ای در ادامه آمده است.

```php
use App\Models\Article;
use LaravelLang\LocaleList\Locale;

$page = Article::first();

$page->setTranslation('title', 'New value', 'fr');
// یا
$page->setTranslation('title', 'New value', Locale::French);
```

انتساب گروهی هم ممکن است.

```php
use App\Models\Article;

$page = Article::first();

$page->fill([
    'title' => 'New value',
]);
```

:::note

Please note that despite calling these methods, the new values will be stored to the model objects. To write changes to the database, simply call the `save` method on the parent model. نمونه‌ای در ادامه آمده است.

```php
$page->save();
```

:::

Of course, filling can also be done when creating the model. نمونه‌ای در ادامه آمده است.

```php
use App\Models\Article;

$page = Article::first();

Article::create([
    'title' => 'New value',
]);
```

#### چند مقدار {/* #plural_value */}

برای پر کردن سریع ویژگی با ترجمه‌های چند زبان منطقه‌ای می‌توانید از هر یک از روش‌های زیر استفاده کنید.

```php
use App\Models\Article;
use Illuminate\Database\Eloquent\Model;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Models\HasTranslations;

/** @var Model|HasTranslations $post */
$post = Article::first();

$titles = [
    'fr' => 'Mettre à jour & continuer à éditer',
    'en' => 'Update & Continue Editing',
    'de' => 'Aktualisieren & Weiterbearbeiten',
];

$descriptions = collect([
    Locale::French->value => 'Met à jour les informations et continue d\'éditer le message',
    Locale::German->value => 'Aktualisiert die Informationen und bearbeitet den Beitrag weiter',
]);

// گزینهٔ 1
foreach ($titles as $locale => $value) {
    $post->setTranslation('title', $value, $locale);
}

foreach ($descriptions as $locale => $value) {
    $post->setTranslation('description', $value, $locale);
}

// گزینهٔ 2
$post->setTranslations('title', $titles);
$post->setTranslations('description', $descriptions);
```

You can also assign `iterable` objects when bulk populating. نمونه‌ای در ادامه آمده است.

```php
$post->fill([
    'title'       => $titles,
    'description' => $descriptions,
]);

Article::create([
    'title'       => $titles,
    'description' => $descriptions,
]);
```

لازم نیست زبان‌های منطقه‌ای همهٔ فیلدها دقیقاً یکسان باشد. برای نمونه، در مثال بالا فیلد `title` برای فرانسوی، انگلیسی و آلمانی پر می‌شود، ولی فیلد `description` فقط برای فرانسوی و آلمانی مقدار می‌گیرد.

## ترجمهٔ جایگزین JSON {/* #json_fallback */}

:::note

در Laravel 11 بخش `providers` در فایل پیکربندی `config/app.php` وجود ندارد. می‌توانید آن را دستی اضافه کنید.

:::

پس از نصب، باید ارجاع ارائه‌دهندهٔ سرویس را در بخش `providers` فایل تنظیمات `config/app.php` اضافه کنید.

```php
<?php

declare(strict_types=1);

use Illuminate\Support\ServiceProvider;
use Illuminate\Translation\TranslationServiceProvider as BaseTranslation;
use LaravelLang\JsonFallback\TranslationServiceProvider as JsonTranslation;

return [
    'providers' => ServiceProvider::defaultProviders()->merge([
        // سایر ارائه‌دهندگان سرویس
    ])->replace([
        BaseTranslation::class => JsonTranslation::class,
    ])->toArray(),
];
```

اکنون کلیدهای JSON مقدار درستِ مربوط به زبان منطقه‌ای انتخاب‌شده را برمی‌گردانند.

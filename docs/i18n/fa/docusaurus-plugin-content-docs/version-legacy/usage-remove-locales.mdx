:::warning

این فرمان کل پوشهٔ زبان منطقه‌ای را با تمام فایل‌هایش حذف می‌کند. زبان‌های منطقه‌ای پیش‌فرض و جایگزین مستثنا هستند.

:::

برای حذف زبان‌های منطقه‌ای، فرمان `php artisan lang:rm <locale>` را با کدهای حرفی فراخوانی کنید.

```bash
php artisan lang:rm fr de de_AT de_CH vi zh_CN
```

اگر آرگومانی مشخص نکنید، کنسول پرسشی تعاملی برای انتخاب از میان زبان‌های منطقه‌ای موجود نمایش می‌دهد.

```bash
php artisan lang:rm
```

به‌طور پیش‌فرض، هنگام تلاش برای حذف زبان منطقه‌ای محافظت‌شده، فرمان پیام خطا برمی‌گرداند.

زبان‌های منطقه‌ای محافظت‌شده کدهایی هستند که در پارامترهای `locale` و `fallback_locale` فایل `config/app.php` تنظیم شده‌اند.

برای حذف اجباری زبان منطقه‌ای محافظت‌شده، از گزینهٔ `force` استفاده کنید.

```bash
php artisan lang:rm en --force
```

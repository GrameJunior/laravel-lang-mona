برای بازنشانی فایل‌ها به حالت پیش‌فرض، فرمان زیر را اجرا کنید.

```bash
php artisan lang:reset
```

کلیدهایی که بسته‌های <strong>Laravel Lang</strong> یا [افزونه‌های شخص ثالث](<./plugins-community.mdx>) نصب‌شده تعریف نکرده‌اند، از همهٔ فایل‌های مقصد پاک می‌شوند.

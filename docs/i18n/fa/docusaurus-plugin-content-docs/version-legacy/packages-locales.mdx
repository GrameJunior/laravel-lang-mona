## نصب {/* #installation */}

:::note

جدول سازگاری را [اینجا](<#compatibility> "جدول سازگاری بستهٔ Locales") ببینید.

:::

برای نصب، فرمان زیر را اجرا کنید.

```bash
composer require laravel-lang/locales:^2.11.0
```

## کاربرد {/* #usage */}

برای کار با زبان‌های منطقه‌ای می‌توانید از نمای `LaravelLang\Locales\Facades\Locales` استفاده کنید. این نما اطلاعات را به دو شکل می‌دهد، یکی فهرست کدها و دیگری آرایه‌ای از اشیای انتقال داده (DTO).

### اشیای داده {/* #data_objects */}

```php
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// فهرست زبان‌های منطقه‌ای موجود.
Locales::available(): array // array<LocaleData>

// فهرست زبان‌های منطقه‌ای نصب‌شده.
Locales::installed(bool $withProtects = true): array // array<LocaleData>

// فهرست زبان‌های منطقه‌ای نصب‌نشده.
Locales::notInstalled(): array // array<LocaleData>

// دریافت فهرست زبان‌های منطقه‌ای محافظت‌شده.
Locales::protects(): array // array<LocaleData>

// بررسی وجود بستهٔ زبان برای زبان منطقه‌ای درخواستی.
Locales::isAvailable(LocaleData|Locale|string|null $locale): bool

// بررسی نصب بستهٔ زبان.
Locales::isInstalled(LocaleData|Locale|string|null $locale): bool

// بررسی محافظت‌شدن زبان منطقه‌ای.
Locales::isProtected(LocaleData|Locale|string|null $locale): bool

// اعتبارسنجی و بازگرداندن زبان منطقه‌ای درست.
// اگر زبان منطقه‌ای درخواست‌شده نصب نباشد، زبان فعلی برنامه برمی‌گردد.
Locales::get(mixed $locale): LocaleData

// دریافت نام زبان منطقه‌ای پیش‌فرض.
Locales::getDefault(): LocaleData

// دریافت نام زبان منطقه‌ای جایگزین.
Locales::getFallback(): LocaleData

// اطلاعات زبان منطقه‌ای موجود یا در غیر این صورت زبان فعلی برنامه را برمی‌گرداند.
Locales::info(mixed $locale): LocaleData
```

### نمونه‌ها {/* #examples */}

```php
use LaravelLang\LocaleList\Direction;
use LaravelLang\LocaleList\Locale;
use LaravelLang\Locales\Data\CountryData;
use LaravelLang\Locales\Data\CurrencyData;
use LaravelLang\Locales\Data\LocaleData;
use LaravelLang\Locales\Facades\Locales;

// config('app.locale') // de

return Locales::getDefault(withCountry: true, withCurrency: true);

// بدون نام مستعار
LocaleData {
  +code: "de"
  +regional: "de_DE"
  +type: "Latn"
  +native: "Deutsch"
  +localized: "Allemand"
  +country: CountryData {
    +code: "DE"
    +native: "Deutschland"
    +localized: "Allemagne"
  }
  +currency: CurrencyData {
    +code: "EUR"

    +native: "Euro"
    +localized: "euro"
  }

    +name: "LeftToRight"
    +value: "ltr"
  }
  +locale: Locale {
    +name: "German"
    +value: "de"
```

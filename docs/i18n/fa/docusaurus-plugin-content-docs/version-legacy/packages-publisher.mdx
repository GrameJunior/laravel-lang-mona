## نصب {/* #installation */}

:::note

جدول سازگاری را [اینجا](<#compatibility> "جدول سازگاری بستهٔ Publisher") ببینید.

:::

برای نصب، فرمان زیر را اجرا کنید.

```bash
composer require --dev laravel-lang/publisher:^16.9.0
```

## کاربرد {/* #usage */}

اکنون می‌توانید زبان‌های منطقه‌ای موجود را با فرمان `lang:update` [به‌روز کنید](<./usage-update-locales.mdx> "به‌روزرسانی زبان‌های منطقه‌ای در Laravel").

```bash
php artisan lang:update
```

پیشنهاد می‌کنیم فراخوانی را به بخش `post-update-cmd` در بلوک `scripts` فایل `composer.json` هم اضافه کنید.

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

با این کار، فایل‌های بومی‌سازی پس از به‌روزرسانی وابستگی‌ها خودکار به‌روز می‌شوند و نیازی به اجرای دستی `php artisan lang:update` نیست.

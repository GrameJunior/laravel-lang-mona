## شیوهٔ نسخه‌بندی {/* #versioning_scheme */}

همهٔ بسته‌های ما از [نسخه‌بندی معنایی](<https://semver.org>) پیروی می‌کنند. انتشارهای اصلیِ پروژه زمانی ارائه می‌شوند که قابلیتی ناسازگار با نسخهٔ قبل اضافه یا پشتیبانی از [نسخه‌های منسوخ](<https://laravel.com/docs/releases>) Laravel یا سایر بسته‌های رسمی آن حذف شود. انتشار فرعی و اصلاحی هرگز نباید تغییر ناسازگار داشته باشد.

## سیاست پشتیبانی {/* #support_policy */}

برای همهٔ پروژه‌های Lang از [سیاست پشتیبانی Laravel](<https://laravel.com/docs/releases#support-policy>) پیروی می‌کنیم.

انتظار نمی‌رود بسته‌های پروژهٔ `Lang` کدی داشته باشند که امنیت پروژه را تحت تأثیر قرار دهد. بنابراین، مبنا را [تاریخ‌های زمان‌بندی‌شدهٔ پایان نگه‌داری](<https://laravel.com/docs/releases#support-policy>) پروژه‌های Laravel و نسخه‌های فرعی [PHP](<https://www.php.net>) قرار می‌دهیم.

برای به‌روزرسانی فایل‌ها، فرمان زیر را اجرا کنید.

```bash
php artisan lang:update
```

همین کافی است 🙂

این فرمان کنسول زبان‌های منطقه‌ای نصب‌شده در برنامه را شناسایی و فایل‌ها را به‌روز می‌کند.

:::tip

بعضی نسخه‌های فرعی Laravel ممکن است کلیدهایی را از مخزن خود حذف کنند و باعث ناپدید شدن آن‌ها از برنامه شوند. این حالت بسیار نادر است، اما رخ می‌دهد.

فرمان به‌روزرسانی بومی‌سازی فقط عبارت‌های جدید را اضافه یا عبارت‌های موجود را به‌روز می‌کند. برای حذف عبارت‌های استفاده‌نشده، فرمان [`php artisan lang:reset`](<./usage-reset-locales.mdx> "بازنشانی زبان‌های منطقه‌ای در برنامهٔ Laravel") را اجرا کنید.

:::

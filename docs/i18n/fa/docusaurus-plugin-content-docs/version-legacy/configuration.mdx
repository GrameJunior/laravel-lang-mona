## انتشار فایل پیکربندی {/* #publish */}

در صورت تمایل می‌توانید فایل پیکربندی را با فرمان زیر منتشر کنید.

```bash
php artisan vendor:publish --tag="localization"
```

محتوای فایلِ منتشرشدهٔ `config/localization.php` به این صورت است.

## ترجمهٔ درون‌خطی {/* #inline */}

گزینهٔ `inline` تعیین می‌کند هنگام به‌روزرسانی فایل‌های زبان از کدام نوع فایل استفاده شود.

- `true` یعنی از فایل‌های درون‌خطی استفاده شود.
- `false` یعنی از فایل‌های پیش‌فرض استفاده شود.

تفاوت این دو در نمونهٔ زیر دیده می‌شود.

```text
The :attribute must be accepted. // default
This field must be accepted. // inline
```

این گزینه در فایل `config/localization.php` در دسترس است.

```php
return [
    'inline' => (bool) env('LOCALIZATION_INLINE', env('LANG_PUBLISHER_INLINE')),
];
```

## هم‌ترازی {/* #alignment */}

گزینهٔ `align` هنگام پردازش فایل‌های بومی‌سازی، هم‌ترازی مقادیر نسبت به یکدیگر را تعیین می‌کند.

هنگام به‌روزرسانی، همهٔ توضیحات از فایل‌های نهایی خودکار حذف می‌شوند، چون [var\_export](<https://www.php.net/manual/en/function.var-export.php>) از توضیحات پشتیبانی نمی‌کند.

نمونهٔ فایل شما

```php
declare(strict_types=1);

return [
    /*
    |--------------------------------------------------------------------------
    | عبارت‌های زبان احراز هویت
    |--------------------------------------------------------------------------
    |
    | عبارت‌های زیر هنگام احراز هویت
    | برای پیام‌هایی به کار می‌روند که باید به کاربر نمایش داده شوند.
    | می‌توانید آن‌ها را مطابق نیازهای برنامه تغییر دهید.
    |
    */
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

شکل فایل پس از به‌روزرسانی

```php
declare(strict_types=1);

return [
    'failed'   => 'These credentials do not match our records 123456.',
    'throttle' => 'Too many login attempts. Please try again in :seconds seconds.',
    'foo'      => 'bar',
];
```

نمونهٔ فایل `validation.php`

## نام‌های مستعار {/* #aliases */}

اگر می‌خواهید کدها را به‌شکل دیگری بنامید، مانند `de-DE` به‌جای `de` یا `de-CH` به‌جای `de_CH`، می‌توانید `aliases` را در [فایل پیکربندی](<./configuration.mdx#aliases>) تعریف کنید.

پس از آن، تمام عملیات افزودن، به‌روزرسانی و حذف خودکار از نام‌های مستعار مشخص‌شده در فایل `config/localization.php` استفاده می‌کنند.

```php
declare(strict_types=1);

use LaravelLang\LocaleList\Locale;

return [
    'aliases' => [
        Locale::German->value            => 'de-DE',
        Locale::GermanAustria->value     => 'de-AT',
        Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

اگر فایل `config/localization.php` از پیش وجود دارد، می‌توانید کلید `aliases` را به آن اضافه کنید و نام‌های مستعار دلخواه را در یک آرایهٔ داده بنویسید.

سپس برای نمونه می‌توانید با تعیین کد اصلی و نام مستعارش زبان منطقه‌ای جدید اضافه کنید.

```bash
php artisan lang:add de de_CH
```

زبان‌های منطقه‌ای نصب‌شده از نام‌های مستعار مشخص‌شده برای نام پوشهٔ ترجمه‌های PHP و نام فایل ترجمه‌های JSON استفاده می‌کنند.

```text
lang
de-CH
de-DE
```

این گزینه در فایل `config/localization.php` در دسترس است.

```php
return [
    'aliases' => [
        // \LaravelLang\LocaleList\Locale::German->value => 'de-DE',
        // \LaravelLang\LocaleList\Locale::GermanSwitzerland->value => 'de-CH',
    ],
];
```

## نشانه‌گذاری هوشمند {/* #smart_punctuation */}

هنگام به‌روزرسانی کلیدهای ترجمه می‌توانید تبدیل هوشمند گیومه‌ها، خط تیره‌ها و سه‌نقطه‌های ASCII به همتاهای Unicode آن‌ها را نیز فعال کنید.

نمونه‌ای در ادامه آمده است.

```json
{
    "Some": "\"It's super-configurable... you can even use additional extensions to expand its capabilities -- just like this one!\""
}
```

فایل‌های حاصل به این صورت خواهند بود.

```json
{
    "Some": "“It’s super-configurable… you can even use additional extensions to expand its capabilities – just like this one!”"
}
```

## مسیرها {/* #routes */}

هنگام استفاده از بستهٔ [مسیریابی](<./packages-routes.mdx> "روش آسان و سریع بومی‌سازی مسیرها")، می‌توانید مقادیر پیش‌فرض نام کلیدها را بازنویسی کنید.

این گزینه در فایل `config/localization.php` فعال می‌شود.

```php
use LaravelLang\Config\Constants\RouteName;

return [
    'routes' => [
        'names' => [

            'header'    => RouteName::Header,

        'name_prefix' => env('LOCALIZATION_NAME_PREFIX', 'localized.'),
        'redirect_default' => (bool) env('LOCALIZATION_REDIRECT_DEFAULT', false),
        'hide_default' => (bool) env('LOCALIZATION_HIDE_DEFAULT', false),

        'group' => [
            'middlewares' => [
                'default' => [
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,
                    LaravelLang\Routes\Middlewares\LocalizationBySession::class,
                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,
                ],
                'prefix' => [
                    LaravelLang\Routes\Middlewares\LocalizationByParameterPrefix::class,
                    LaravelLang\Routes\Middlewares\LocalizationByCookie::class,
                    LaravelLang\Routes\Middlewares\LocalizationByHeader::class,

                    LaravelLang\Routes\Middlewares\LocalizationByModel::class,

            ],
        ],
    ],
];
```

## مدل‌ها {/* #models */}

هنگام استفاده از بستهٔ [Models](<./packages-models.mdx> "روش آسان و سریع بومی‌سازی مدل‌ها")، می‌توانید مقادیر پیش‌فرض پارامترها را تعیین کنید.

این تنظیم در فایل `config/localization.php` در دسترس است.

```php
return [
    'models' => [
        'suffix' => 'Translation',
        'filter' => [
            'enabled' => (bool) env('LOCALIZATION_FILTER_ENABLED', true),
        ],
        'helpers' => env('VENDOR_PATH', base_path('vendor/_laravel_lang')),
    ],
];
```

پارامتر `suffix` پسوند مدل‌هایی را مشخص می‌کند که مخزن ترجمه به آن‌ها تعلق دارد.

نمونه‌ای در ادامه آمده است.

```text
App\Models\Post::class
App\Models\PostTranslation::class
```

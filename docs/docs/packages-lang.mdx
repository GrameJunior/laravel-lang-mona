This package contains translations of all official keys from Laravel projects:

[Laravel Framework](<https://laravel.com>), [Jetstream](<https://jetstream.laravel.com/>), [Fortify](<https://github.com/laravel/fortify>), [Cashier](<https://laravel.com/docs/billing>), [Breeze](<https://github.com/laravel/breeze>), [Nova (also Dusk Suite and Log Viewer)](<https://nova.laravel.com/>), [Nova](<https://nova.laravel.com/>) (also [Dusk Suite](<https://github.com/laravel/nova-dusk-suite>), [Log Viewer](<https://github.com/laravel/nova-log-viewer>) ) and [UI](<https://github.com/laravel/ui>)

:::

## Installation {/* #installation */}

:::note

The compatibility table can be viewed [here](<#compatibility> "Compatibility table for the Lang package").

:::

To install, run the console command:

```bash
composer require --dev laravel-lang/lang:^15.39.1
```

## Usage {/* #usage */}

Now you can [update](<./usage-update-locales.mdx> "Updating locales to a Laravel application") existing localizations using the `lang:update` console command:

```bash
php artisan lang:update
```

We also recommend adding the call code to the `post-update-cmd` section of the `scripts` block in the `composer.json` file:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

This allows localization files to be automatically updated after dependency updates, rather than manually running the `php artisan lang:update` console command.

This package includes the localization of the Starter Kits interface.

So, you can easily localize the translation of them too!

:::

## Installation {/* #installation */}

:::note

The compatibility table can be viewed [here](<#compatibility> "Compatibility table for the Starter Kits package").

:::

To install, run the console command:

```bash
composer require --dev laravel-lang/starter-kits:^1.17.2
```

## Usage {/* #usage */}

:::note

For [Laravel Starter Kits](<https://laravel.com/starter-kits>) translation key publishing to work properly, do not rename the application name specified in the \`name\` key of the \`composer.json\` file. Otherwise, Starter Kits translations will not be installed.

- `laravel/livewire-starter-kit`
- `laravel/react-starter-kit`
- `laravel/vue-starter-kit`

:::

Now you can [update](<./usage-update-locales.mdx> "Updating locales to a Laravel application") existing localizations using the `lang:update` console command:

```bash
php artisan lang:update
```

We also recommend adding the call code to the `post-update-cmd` section of the `scripts` block in the `composer.json` file:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan vendor:publish --tag=laravel-assets --ansi --force",
            "@php artisan lang:update"
        ]
    }
}
```

This allows localization files to be automatically updated after dependency updates, rather than manually running the `php artisan lang:update` console command.

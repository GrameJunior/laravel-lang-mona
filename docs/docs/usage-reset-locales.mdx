---
title: "Reset Locales"
slug: /usage-reset-locales.html
description: "Resetting locales to a Laravel application"
---

To reset files to default state, use the console command:

```bash
php artisan lang:reset
```

As a result, all target files will be cleared of those keys that are not defined by <strong>Laravel Lang</strong> packages or installed [third-party plugins](<./plugins-community.mdx>).
